# HOME → Banners

Il arrive que vous souhaitiez que chaque question soit précédée d'une diapositive affichant le numéro et le texte de la question qui suit. Cela peut se faire dans QuizXpress Studio avec la commande ‘Generate Question Banners’, que l'on trouve dans le menu ‘Edit’. Cette commande génère automatiquement une diapositive de quiz de type ‘Billboard’ avant chaque diapositive de quiz de type ‘Question’. Chaque diapositive Billboard générée contient le texte suivant : Question \<numéro de la question suivante> : \<texte de la question suivante>.
