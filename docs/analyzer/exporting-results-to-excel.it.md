# Esportare i risultati in Excel

I risultati possono essere esportati in Excel richiamando il comando ‘Export to Excel’ dal menu ‘File’. Il file Excel risultante conterrà al massimo quattro fogli di lavoro:

- Score: mostra la classifica dei punteggi

- Response: mostra tutte le domande, con, per ciascuna domanda, le risposte, i punti ottenuti e il totale dei punti per squadra

- Demographic Scores (se sono presenti gruppi demografici): mostra la classifica dei punteggi per gruppo

- Demographic Responses: mostra, per ciascuna domanda, tutte le risposte per gruppo per risposta.
