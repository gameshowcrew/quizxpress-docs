# The countdown screen

After the keypad registration screen, a countdown video is shown to build some suspense. If you do not want to see this video before the quiz starts, please uncheck the ‘Show 3-2-1 Quiz countdown screen’ on the ‘Screens’ page of Quiz Setup. You can end the screen by pressing the spacebar during the video.
