# Schermata del grafico

Al termine di una domanda, premendo ‘C’ viene mostrato un grafico delle risposte scelte, con il numero di persone che hanno scelto ciascuna risposta.

![](../../assets/images/image433.webp){ width="605" loading=lazy }

Se il pubblico è suddiviso in gruppi, è possibile premere ‘G’ per mostrare un grafico con i punteggi di gruppo della domanda corrente. Si noti che l’aspetto del grafico può essere personalizzato completamente con lo [skinning](../../advanced/skinning/index.md).
