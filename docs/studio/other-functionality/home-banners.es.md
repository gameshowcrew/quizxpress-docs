# HOME → Banners

A veces querrá que cada pregunta vaya precedida de una diapositiva que muestre el número y el texto de la pregunta que sigue. Esto se puede hacer en QuizXpress Studio con el comando ‘Generate Question Banners’, que se encuentra en el menú ‘Edit’. Este comando genera automáticamente una diapositiva de quiz de tipo ‘Billboard’ antes de cada diapositiva de quiz de tipo ‘Question’. Cada diapositiva Billboard generada contiene el siguiente texto: Question \<número de la pregunta siguiente>: \<texto de la pregunta siguiente>.
