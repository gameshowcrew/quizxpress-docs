# Buzzer Fleetwood Reply

Procedere come segue per installare i buzzer Fleetwood Reply e configurare QuizXpress per l'uso con tali buzzer.

1.  Accendere il PC/laptop

2.  Inserire il CD dei driver Reply nel lettore CD/DVD-ROM

3.  Inserire il ricevitore USB Reply in una porta USB

4.  Apparirà una finestra che indica che è stato rilevato un nuovo hardware. Indicare che Windows deve cercare automaticamente i driver.

5.  Windows installerà automaticamente i driver.

6.  Ora è possibile configurare QuizXpress per l'uso dei buzzer Reply. Avviare Quiz Setup (vedere anche [Sistemi di buzzer a scelta multipla](../setup/configuring-your-hardware-the-buzzers-tab-page.md#sistemi-di-buzzer-a-scelta-multipla)).

7.  Nella pagina della scheda ‘Buzzers’ di Quiz Setup, selezionare Fleetwood Reply CRS 940/941.

8.  Scegliere ora il canale che il ricevitore Reply usa per ascoltare le pulsantiere Reply (buzzer). Per selezionare il canale corretto, guardare sul retro di una delle pulsantiere che verranno utilizzate — il canale su cui opera è indicato lì (nota: tutti i buzzer utilizzati devono operare su questo canale).

9.  Chiudere ora Quiz Setup e avviare QuizXpress Buzzer Test, che si trova nel menu Start sotto QuizXpress. Premendo uno dei buzzer, la casella numerata corrispondente dovrebbe illuminarsi sullo schermo e mostrare la risposta scelta.

10. Quando i passaggi precedenti sono stati eseguiti con successo, QuizXpress Live è pronto a funzionare con i buzzer Reply.

!!! note

    I buzzer Fleetwood Reply funzionano con batterie a bottone al litio di tipo CR2032. Si consigliano batterie a bottone al litio Sony CR2032.
