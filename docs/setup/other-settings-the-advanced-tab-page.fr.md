# Autres paramètres – l'onglet Advanced

L'onglet Advanced contient plusieurs paramètres avancés :

![](../assets/images/image344.webp){ width="598" loading=lazy }

**Full screen slides**

Cette option affiche chaque diapositive en plein écran. Par défaut, les diapositives ‘flottent’ à l'écran, avec des marges de tous les côtés.

En cliquant sur l'option plein écran, les diapositives sont affichées en plein écran. L'arrière-plan est étendu pour remplir tout le bureau, et la taille des éléments de la diapositive (question, réponses) est également légèrement augmentée.

!!! note

    lorsque vous cliquez sur l'option Full screen slides, une seconde option, ‘Legacy mode’, apparaît. Elle prend en charge l'ancien paramètre Full screen, qui fonctionnait légèrement différemment. Auparavant, l'option de diapositive plein écran faisait chevaucher la barre d'horloge et le texte de la question. Pour corriger cela, les éléments des diapositives (le texte de la question ainsi que les réponses) devaient être déplacés vers le bas pour s'adapter à l'affichage plein écran. Si vous avez des quiz dont la mise en page a été conçue pour l'ancienne option Full screen, cochez la case ‘Legacy mode’.

**Show 3-2-1 Quiz countdown screen**

Indique si une animation de compte à rebours est affichée avant le début du quiz.

**Show individual feedback during voting (\<20 players)**

Lorsque cette option est cochée, chaque vote individuel est affiché pour les questions dont le vote est défini sur ‘True’. Si cette option n'est pas cochée, seul un compteur affichant le nombre total de votes reçus est montré. Pour un exemple, voir les images présentées à la fin de 5.4.5. Cela ne s'applique que lorsqu'il y a moins de 20 joueurs.

**Show top three teams using space on end score screen:**

Lorsque cette option est activée, l'écran de score final n'affiche pas automatiquement les 3 premiers joueurs mais attend que la barre d'espace soit pressée. Appuyer plusieurs fois sur la barre d'espace affiche tour à tour la 3<sup>e</sup>, la 2<sup>e</sup> et la 1<sup>re</sup> place. Ensuite, le classement complet est affiché.

**Use remote control**

Indique si une télécommande d'animateur de quiz est utilisée (pour le système de buzzers QuizXpress, cette option est toujours activée car ce système inclut une télécommande spéciale).

**Show correct answer**

Si cette option est cochée (par défaut), la bonne réponse (indiquée par une coche verte) est affichée lorsqu'une question à choix multiples est évaluée. Si elle est décochée, la bonne réponse n'est pas affichée, ce qui vous permet d'annoncer vous-même la bonne réponse au public. Vous pouvez aussi utiliser une forme pour remplacer ce comportement par défaut et indiquer vous-même la bonne réponse — par exemple, en affichant une grande flèche rouge pointant vers la bonne réponse.

**Randomize Questions**

Lorsque cette option est cochée, les questions d'un quiz sont affichées dans un ordre aléatoire. Lorsque des manches sont présentes, les questions de chaque manche sont mélangées. En indiquant un pourcentage, vous pouvez demander à QuizXpress de n'afficher qu'une partie des questions (dans un ordre aléatoire). La façon dont les diapositives sont mélangées est contrôlée par l'option ‘Shuffle mode’, que vous pouvez définir par diapositive.

** Show Quizmaster Hints**

Lors de l'exécution d'un jeu télévisé dans QuizXpress Live, plusieurs commandes sont disponibles à différents moments — par exemple, afficher des graphiques, passer à la diapositive suivante, afficher les aperçus des scores ou juger des questions. Toutes ces commandes ont des raccourcis clavier (ou peuvent être pilotées avec une télécommande d'animateur de quiz).

Pour guider les utilisateurs débutants, des indications pour l'animateur de quiz peuvent être affichées pendant un quiz, présentant toutes les commandes disponibles au fur et à mesure qu'elles deviennent applicables. Une fois que l'animateur de quiz est à l'aise avec le système, il peut désactiver ce paramètre (dans Quiz Setup) pour que le public ne voie plus les indications. Par défaut, les indications pour l'animateur de quiz sont **activées**.

**Enable QuizXpress Director**

Lorsque cette option est cochée, Director s'ouvre immédiatement au démarrage de QX Live. Si cette option n'est pas activée, vous pouvez toujours ouvrir Director à tout moment avec la touche ‘D’ *(remarque : cette option n'est disponible que dans l'édition Ultimate)*.

**Automatically advance to the next question**

Avec cette option, vous pouvez faire passer Live à la question suivante sans intervention. Ainsi, si vous avez une série de questions à choix multiples à présenter à votre public sans être présent, c'est l'option à utiliser. Vous pouvez également définir le temps entre les questions.

**Automatically disable players that don’t respond**

Lorsque cette option est activée, le système désactive automatiquement les joueurs qui n'ont pas répondu pendant un certain nombre de questions (ce qui signifie qu'ils ont probablement quitté le quiz).

**Automatically register all keypads**

Normalement, le public doit s'inscrire au début d'une session. Ainsi, le système sait quels keypads participent et peut terminer une question une fois toutes les réponses reçues. Si ce processus d'inscription est gênant, vous pouvez activer cette option, et le système ignorera l'écran d'inscription et inscrira tous les keypads configurés. Par exemple, si vous avez défini la configuration des appareils sur ‘1-100’, les keypads 1 à 100 seront tous inscrits.

**Allow the next in line to answer**

Lorsque cette option est activée, le système permet successivement à tous les joueurs qui ont répondu à une question ouverte (dans les 2 secondes suivant la première réponse) de donner une réponse, jusqu'à ce qu'une bonne réponse ait été donnée. Si elle n'est pas activée, seul le premier joueur peut répondre, après quoi le système rouvre la main à tous les joueurs (sauf ceux qui ont déjà donné une mauvaise réponse).

**Automatically restart the quiz**

Cette option permet de redémarrer automatiquement le quiz un certain nombre de secondes après avoir atteint l'écran de score final, ce qui vous permet de créer un quiz autonome ne nécessitant pas la présence d'un animateur de quiz.

**Highlight the correct answer in the response chart**

Si vous ne souhaitez pas que la bonne réponse soit mise en évidence dans le graphique des réponses, désactivez ce paramètre. Cela peut être utile, par exemple, lorsque vous voulez d'abord vérifier avec le public combien de réponses il y a eu pour chaque réponse, sans mettre en évidence la bonne.

**Always run the countdown timer for the full time**

Si vous souhaitez que l'horloge tourne pendant toute la durée spécifiée, que tout le monde ait déjà répondu ou non, cochez cette option (lorsque l'option est désactivée, l'horloge s'arrête dès que tout le monde a répondu). Si vous préférez une durée de compte à rebours constante, cochez cette option.

**Allow players to revise their answer**

Lorsque vous cochez cette option, les joueurs peuvent modifier leur réponse tant que le compte à rebours est en cours.

**Do not reveal points onscreen during question**

Par défaut, le système affiche les points gagnés ou perdus pour les questions de type doigt le plus rapide. Pour créer plus de suspense, vous pouvez activer cette option afin que les points d'un joueur ne soient connus qu'à l'affichage du classement.

**Use ‘?’ button on remote to toggle with Microsoft PowerPoint**

Pour les utilisateurs qui souhaitent mélanger QuizXpress et des présentations PowerPoint, cette fonction permet de basculer entre l'écran PowerPoint et QuizXpress à l'aide du bouton ‘?’ de la télécommande de présentation.

**Remove top panel when answering to avoid overlapping**

Dans certaines situations (question ouverte, vote avec retour individuel), la diapositive remonte lorsqu'un joueur buzze, ce qui la fait chevaucher le panneau supérieur. Ce paramètre fait temporairement disparaître le panneau supérieur pour éviter ce chevauchement.
