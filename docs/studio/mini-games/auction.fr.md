# Auction

Avec ce plugin, vous pouvez mettre des objets aux enchères pendant un quiz pendant que le public enchérit avec ses terminaux portables — idéal pour les collectes de fonds !

Pendant la vente, à mesure que le montant de l'enchère augmente, les joueurs se retirent lorsqu'ils ne sont plus intéressés.

Les options de configuration disponibles sont :

- Item under sale : image de l'objet mis aux enchères

- Description : description de l'objet mis aux enchères. La description s'affiche en haut de l'écran de la vente aux enchères.

- Background : image d'arrière-plan de l'écran de la vente aux enchères.

- Background fill color : vous pouvez également définir une couleur d'arrière-plan unie pour l'écran de la vente aux enchères.

- Currency : devise affichée avant le montant actuel de l'enchère

- Show cents : inclure les centimes dans le montant de l'enchère

- Start bid at : définit le prix de départ de l'objet mis aux enchères

- Bid step : définit l'incrément de hausse du prix de l'enchère

- Step timer : définit l'intervalle après lequel le montant de l'enchère augmente

- Start the auction manually : démarre la vente uniquement lorsque vous appuyez sur Next (sinon, elle démarre immédiatement)

- Bidders must register for the auction : par défaut, tout le monde participe et les enchérisseurs se retirent lorsqu'ils ne sont plus intéressés par l'objet. Cochez ce paramètre si vous souhaitez que chaque enchérisseur indique explicitement s'il souhaite participer avant le début de la vente.

- Bidding music : musique jouée pendant la vente (aucune musique, un fichier musical ou un dossier contenant des fichiers musicaux)

- Winner music : définit la musique jouée lorsque l'objet est vendu

- Auction title text : le titre de la vente s'affiche sur l'image de l'objet mis aux enchères (ou seul, sous forme de texte, si aucune image n'est définie).

- Auction title text color : la couleur du texte du titre de la vente.

- Remove left bidders from the grid : lorsque ce paramètre est coché, les joueurs qui se sont retirés de la vente sont supprimés du panneau des enchérisseurs.

- Bidder grid panel color : définit la couleur des panneaux de la grille des enchérisseurs.
