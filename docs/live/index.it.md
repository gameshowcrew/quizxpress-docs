# Condurre lo show con QuizXpress Live

Per condurre uno show con QuizXpress è possibile usare dispositivi fisici come i keypad o i buzzer QuizXpress, oppure usare i telefoni cellulari per permettere ai giocatori di partecipare tramite Wi-Fi locale o Internet. Se si gioca tramite Internet con giocatori in sedi remote, è possibile trasmettere il quiz in streaming tramite un servizio come YouTube o Zoom. Per saperne di più sullo streaming dei quiz, consultare la guida QuizXpress Online Streaming, disponibile sul nostro sito web.

È inoltre possibile usare una soluzione ibrida con keypad/buzzer e l’app QuizXpress Smart Buzzer.
