# Animer le show avec QuizXpress Live

Pour animer un show avec QuizXpress, vous pouvez utiliser des appareils physiques tels que les keypads ou buzzers QuizXpress, ou utiliser des téléphones mobiles pour permettre aux joueurs de participer via le Wi-Fi local ou Internet. Si vous jouez via Internet avec des joueurs situés à distance, vous pouvez diffuser le quiz via un service de streaming, comme YouTube ou Zoom. Vous pouvez en savoir plus sur la diffusion de quiz en streaming dans le guide QuizXpress Online Streaming, disponible sur notre site web.

Il est également possible d’utiliser une solution hybride avec des keypads/buzzers ainsi que l’application QuizXpress Smart Buzzer.
