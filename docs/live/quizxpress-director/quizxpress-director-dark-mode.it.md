# Modalità scura di QuizXpress Director

Per ridurre l’affaticamento visivo quando si usa QuizXpress in un locale spesso buio, Director può essere impostato in Modalità Scura. A tal fine, fare clic con il pulsante destro del mouse sul pannello a sinistra di Director e selezionare ‘Modalità scura’:

![](../../assets/images/image467.webp){ loading=lazy }

!!! note

    sarà necessario riaprire Director affinché questa impostazione abbia effetto.
