# Het aftelscherm

Na het keypadregistratiescherm wordt een aftelvideo getoond om wat spanning op te bouwen. Als u deze video niet voor de start van de quiz wilt zien, schakelt u ‘3-2-1 Quiz aftelscherm tonen’ uit op de pagina ‘Schermen’ van Quiz Setup. U kunt het scherm beëindigen door tijdens de video op de spatiebalk te drukken.
