# Claviers et buzzers QuizXpress

![](../assets/images/image482.webp){ width="148" loading=lazy }

Veuillez procéder comme suit pour installer le récepteur QuizXpress et configurer QuizXpress pour qu'il fonctionne avec les buzzers.

Pour installer le récepteur QuizXpress, branchez-le sur un port USB disponible. Windows installera le récepteur automatiquement lors de sa première utilisation. Vous verrez les messages suivants dans la barre des tâches de Windows.

![](../assets/images/image483.webp){ width="264" loading=lazy }![](../assets/images/image484.webp){ width="261" loading=lazy }

Vous pouvez maintenant configurer QuizXpress pour utiliser les buzzers QuizXpress (voir également [Claviers de base QuizXpress](../setup/configuring-your-hardware-the-buzzers-tab-page.md#keypads-quizxpress-de-base)).

- Démarrez Quiz Setup

- Sur la page de l'onglet ‘Buzzers’ de Quiz Setup, sélectionnez *QuizXpress Keypad*.

- Lorsque le récepteur est branché, vous pouvez appuyer sur le bouton ‘Test’, après quoi une connexion est établie. Une coche verte apparaît en cas de succès.

- Fermez maintenant Quiz Setup et démarrez QuizXpress Buzzer Test, que vous trouverez dans le menu Démarrer sous QuizXpress. Lorsque vous appuyez sur un des buzzers, la case numérotée correspondante doit s'allumer à l'écran et afficher la réponse choisie.

- Lorsque les étapes précédentes ont été exécutées avec succès, QuizXpress Live est prêt à fonctionner avec les buzzers QuizXpress.

!!! note

    Les claviers QuizXpress fonctionnent avec deux piles AAA.

Le récepteur QuizXpress possède trois LED. La rouge indique s'il est alimenté, la jaune indique la communication et la verte indique l'activité d'interrogation RF. Pendant le quiz, la verte doit clignoter. Si ce n'est pas le cas, vous devez redémarrer l'appareil avec F12.
