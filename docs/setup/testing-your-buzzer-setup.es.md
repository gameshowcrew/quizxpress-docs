# Probar la configuración de los pulsadores

Puede utilizar la aplicación Buzzer Test, que se encuentra en el menú Inicio de Windows bajo QuizXpress, para comprobar que los pulsadores están conectados y configurados correctamente. Esta aplicación muestra una cuadrícula de indicadores; cuando se recibe un evento de un pulsador, muestra información sobre el botón pulsado. Esta aplicación también es útil para probar el alcance de los pulsadores en una sala grande.

![](../assets/images/image347.webp){ loading=lazy }

Para salir de la aplicación Buzzer Test, pulse la tecla *Escape* o utilice la combinación de teclas estándar de Windows *Alt+F4*. Buzzer Test también está disponible en el menú *Tools* de QuizXpress Studio. Durante el inicio de Buzzer Test, el fondo es gris oscuro mientras se conecta con el hardware de los pulsadores; cuando la conexión se establece correctamente, el fondo se vuelve blanco, y si hay un problema con el hardware, el fondo se vuelve rojo.

También puede utilizar Buzzer Test para comprobar el nivel de batería de los pulsadores.

![](../assets/images/image348.webp){ width="315" loading=lazy }

En el formulario de opciones, pulse el botón **Check battery level** y, a continuación, encienda cada pulsador presionando el botón grande en forma de cúpula. El nivel de batería se mostrará en la cuadrícula de pulsadores.
