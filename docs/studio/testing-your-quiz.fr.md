# Tester votre quiz

Lorsque vous avez terminé de concevoir le contenu du quiz, vous pouvez commencer à le tester. Pour lancer le lecteur de quiz depuis Studio, activez l’onglet de ruban QUIZ SHOW :

![](../assets/images/image306.webp){ width="390" loading=lazy }

Comme vous pouvez le voir, il existe ici trois options pour démarrer le lecteur de quiz :

**Test :** exécute le quiz entier en mode test, avec les options définies dans la section *Test Options*

**Test Current Question :** démarre le quiz en mode test à partir de la question en cours.

**Run Production : démarre le quiz en mode production. Dans ce mode, les Test Options sont ignorées, et les paramètres d’écran, etc. sont ceux configurés globalement dans Quiz Setup. Utilisez toujours ce mode lorsque vous présentez votre quiz à un public.**

En mode test, vous pouvez gagner du temps en ignorant l’écran de bienvenue et la vidéo de compte à rebours grâce à la case Quickstart. Et si vous ne souhaitez pas animer le quiz vous-même, vous pouvez utiliser Simulate Keypads pour exécuter automatiquement le quiz entier, comme s’il y avait un public et un animateur de quiz. Il vous suffit de vous détendre et de vérifier que chaque diapositive du quiz se comporte et s’affiche comme vous l’aviez prévu.

!!! note

    N’exécutez jamais votre quiz de production avec l’un des modes de test. Seul le mode production utilise une fonction de récupération spéciale pour rétablir votre quiz dans l’état où il se trouvait lorsqu’un problème est survenu, comme un plantage de l’ordinateur ou du programme.*
