# Le module Randomizer

Le Randomizer de QuizXpress permet de tirer au sort un ou plusieurs joueurs/équipes dans le public, par exemple pour tirer au sort un lot, organiser un concours de karaoké, lancer un jeu, ou tout ce qui peut compléter votre soirée de jeu télévisé.

Au lieu de sélectionner des joueurs, vous pouvez aussi demander au Randomizer de sélectionner un ou plusieurs nombres dans une plage, dans une liste séparée par des virgules ou dans un fichier texte : vous pouvez donc tirer au sort pratiquement n'importe quoi !

Lorsque vous tirez au sort des joueurs, vous pouvez également leur faire gagner un nombre de points déterminé.

Vous pouvez indiquer combien d'éléments tirer à chaque passage, ainsi que le nombre de passages que le Randomizer effectuera. Lorsque plusieurs passages sont effectués, vous pouvez choisir d'exclure les éléments déjà tirés. Vous pouvez également afficher à l'écran une liste des éléments tirés précédemment.

Lorsqu'il tourne, le Randomizer affiche d'abord une animation (deux styles configurables sont disponibles) de tous les noms d'équipes, puis tire au sort et présente les résultats sur ordre de l'animateur de quiz (barre d'espace, ou à l'aide de la télécommande de l'animateur de quiz). Vous pouvez tirer au sort parmi un sous-ensemble du public (au moyen d'une boîte de dialogue de sélection) ou inclure tout le public (aucune sélection manuelle nécessaire)

Dans la section ‘Appearance’, vous pouvez configurer l'image d'arrière-plan à afficher. La section ‘Music’ vous permet de définir différents sons pour l'animation et pour le moment où la sélection a été faite.
