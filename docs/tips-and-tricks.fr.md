# Trucs et astuces

Ce chapitre contient des conseils généraux, réflexions et recommandations pour créer et animer avec succès vos quiz (dans le désordre).

**Connaissez votre système**

Vous ne voulez pas vous retrouver devant un public de 150 personnes mal préparé. Sachez donc comment fonctionne le système, comment l’utiliser, quelles sont ses limites et que faire si les choses ne se passent pas comme prévu.

**Testez votre quiz**

Avec les nombreuses options disponibles, il est facile d’oublier de régler une option particulière, ce qui donne une diapositive de quiz qui se comporte différemment de ce qui était prévu. Vous pouvez tester votre quiz avec l’option de simulation de télécommandes de Studio : installez-vous confortablement et regardez votre quiz se dérouler pendant que le système se comporte comme s’il y avait un vrai public. Assurez-vous également d’avoir défini la bonne ‘correct answer’ sur les diapositives à choix multiples — vous ne voulez pas discuter avec le public de ce qu’était la bonne réponse. Si vous faites tout de même une erreur, vous pouvez toujours annuler la dernière question dans QuizXpress Director !

**Organisez votre quiz en manches de questions similaires**

Créer différentes manches avec le même type de questions est plus facile à suivre pour votre public. Voici quelques idées de manches :

- Une manche ‘Get the picture’ avec des questions dont les images sont partiellement masquées par l’un des effets

- Une manche ‘Guess the artist’ où vous jouez un extrait de chanson sur chaque diapositive et où le public doit deviner l’artiste (remarque : pour rendre la tâche moins facile, vous pouvez ne donner que les premières lettres des artistes dans les réponses)

- Une manche ‘True/False’, avec des affirmations que le public doit valider.

- Une manche Trivia Ladder

- Une manche Last Man Standing où les participants sont éliminés jusqu’à ce qu’il n’en reste qu’un

Il vaut également mieux ne pas mélanger questions ouvertes et questions à choix multiples dans une même manche, car chaque type de question a une façon différente de saisir les réponses (différentes touches sur la télécommande), ce qui peut dérouter votre public si chaque question est différente.

**Gardez votre quiz léger en conservant les fichiers multimédias en externe (ou utilisez la fonction Pack)**

Avec QX4, vous pouvez conserver vos fichiers son et vidéo en externe. Cela garde vos fichiers de quiz légers et faciles à gérer. Vous pouvez laisser les fichiers à leur emplacement d’origine, ou les stocker dans le dossier où se trouve le fichier de quiz lui-même. Lorsque vous copiez votre quiz sur un autre ordinateur, vous devrez copier aussi tous les fichiers externes (auquel cas vous voudrez probablement toujours placer les fichiers dans le dossier du fichier de quiz), ou utiliser la [fonction ‘Pack’](studio/other-functionality/packing-and-unpacking-a-quiz.md) pour créer un quiz distribuable avec tous les médias intégrés, découpés aux seules parties qui sont lues. Au démarrage de QuizXpress Live, il vérifie que tous les fichiers externes sont accessibles et affiche un avertissement dans le cas contraire.

**Prévoyez un système de secours**

Pour un événement critique, vous pouvez envisager de mettre en place un environnement de secours. Cela signifie disposer d’un second ordinateur et/ou d’un second récepteur RF avec son câble, programmé avec le même ID que votre récepteur principal. C’est nécessaire car chaque télécommande est appairée à un seul récepteur ; normalement, vous ne pouvez donc pas simplement échanger votre récepteur. Nous pouvons toutefois vous fournir un récepteur ayant exactement le même ID que votre récepteur principal. Ainsi, vous pouvez simplement échanger le récepteur s’il tombe en panne, ou passer sur un autre ordinateur sans reprogrammer vos télécommandes. Contactez-nous pour plus de détails.

**Connaissez votre appareil cible**

QuizXpress prend en charge trois formats d’image différents pour les diapositives : 4:3, 16:9 et 16:10. Pour un vidéoprojecteur standard, vous devez utiliser le 4:3 ; en revanche, si vous projetez votre quiz sur un téléviseur grand écran, vous préférerez le 16:9, car le rendu sera bien meilleur, sans grandes zones inutilisées sur les côtés. Depuis QX5, vous pouvez modifier le format d’image à la volée dans Studio. Veillez toutefois à vérifier ensuite vos diapositives.

**Expliquez le système à votre public**

Commencez votre quiz par quelques diapositives expliquant comment fonctionne le système, comment utiliser les télécommandes, comment vous avez configuré votre système de score (par exemple avec des points dégressifs), etc. Vous pouvez ensuite insérer quelques questions de test qui n’affecteront pas les scores mais se comporteront comme de vraies questions.

**Utilisez des formes et du texte**

Dans QuizXpress, vous pouvez ajouter à votre diapositive du texte (ou une image) qui devient visible une fois la question terminée (tout le monde a répondu, ou le temps est écoulé). Par exemple, pour une question ‘ouverte’, vous pouvez ainsi afficher la bonne réponse sous forme de texte.
