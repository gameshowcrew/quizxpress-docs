# Il modulo Message Broker

Message Broker è un plugin opzionale di QuizXpress che collega il quiz a dispositivi e applicazioni esterni. Gli eventi di QuizXpress possono attivare messaggi MIDI, ad esempio per cambiare l’illuminazione DMX quando una risposta è corretta. Anche programmi esterni possono controllare il quiz o rimanere in ascolto degli eventi del quiz tramite UDP, TCP o Telnet.

![Come Message Broker collega QuizXpress a dispositivi esterni](../assets/images/mb-overview-diagram.webp){ loading=lazy }

Message Broker si configura da QuizXpress Director mentre un quiz è in esecuzione: premere 'D' e aprire la scheda 'Extensions'.

Per la documentazione completa, vedere [Message Broker](../advanced/message-broker/index.md) nella sezione Avanzate.
