# Configurer le jeu télévisé avec QuizXpress Setup

Le chapitre précédent décrivait comment concevoir un quiz dans QuizXpress Studio. L'étape suivante consiste à ‘lancer’ le quiz dans QuizXpress Live. Avant cela, toutefois, certains aspects du jeu télévisé peuvent nécessiter des modifications — par exemple, le type de matériel utilisé, les noms des équipes, les sons des buzzers, les légendes de l'écran d'accueil, les images du diaporama, etc.

Le programme Quiz Setup se trouve dans le menu Démarrer de Windows ou dans le menu External Tools de Studio (ruban Home).

Quiz Setup permet de gérer plusieurs fichiers de paramètres. Dans la liste à gauche de l'interface, vous voyez les fichiers de configuration disponibles. Celui en **gras** est le fichier actif, c'est-à-dire que ces paramètres seront utilisés lors du lancement d'un quiz en production. Vous pouvez changer le fichier actif en cliquant dessus avec le bouton droit et en sélectionnant ‘Activate’ dans le menu contextuel. Pour charger un fichier en vue de le modifier, double-cliquez dessus ou sélectionnez ‘Load’ dans le menu contextuel.

![](../assets/images/image307.webp){ width="605" loading=lazy }

En cliquant sur ‘Reset’, le système revient à la configuration par défaut. Notez que vous devrez toujours sélectionner un système de buzzers avant de pouvoir utiliser une fonctionnalité.

En cliquant sur le bouton Save, le fichier de paramètres actuel est enregistré sur le disque.

En cliquant sur le bouton **Save As…**, le fichier de paramètres actuel peut être enregistré sous un autre nom.

Les boutons Import et Export permettent d'exporter (enregistrer) les paramètres actuellement chargés dans un fichier. Ce fichier peut ensuite être importé dans QuizXpress Setup sur un autre ordinateur, ce qui permet un transfert simple et fiable des paramètres. Veuillez noter que tous les dossiers référencés dans le fichier de paramètres doivent exister sur l'ordinateur qui importe les paramètres (sinon, des avertissements s'afficheront au démarrage d'un jeu télévisé avec les paramètres importés).
