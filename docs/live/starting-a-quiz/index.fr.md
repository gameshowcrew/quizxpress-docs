# Démarrer un quiz

Il existe trois façons de lancer votre quiz :

1)  Démarrez votre quiz depuis QuizXpress Studio (ruban QUIZ SHOW -> Run Production)

2)  Démarrez QuizXpress Live en faisant un clic droit sur le fichier de quiz dans l’Explorateur Windows (fichiers portant l’extension *.qx*) et en sélectionnant « Play » dans le menu.

3)  Cliquez sur l’icône QuizXpress Live dans le menu Démarrer ; il vous sera alors demandé de sélectionner un fichier de quiz à charger.

Dans QuizXpress Live, plusieurs écrans sont décrits dans les sections suivantes.
