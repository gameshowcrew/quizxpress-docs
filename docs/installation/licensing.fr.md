# Licences

La suite logicielle QuizXpress est protégée par une clé de licence. La version de démonstration, téléchargeable sur notre site web, dispose d'un mode d'essai de 2 semaines pleinement fonctionnel. La clé de licence contient des informations sur le nombre d'appareils (buzzers/claviers/appareils mobiles) que vous pouvez utiliser et sur la date d'expiration de la licence.

## Activation

La boîte de dialogue d'activation s'affiche automatiquement au démarrage de QuizXpress Studio si la licence a expiré ou n'est pas présente. Vous pouvez aussi ouvrir la boîte de dialogue manuellement depuis l'onglet HOME en cliquant sur ‘Info’ puis sur ‘Activate’.

![](../assets/images/image3.webp){ width="324" loading=lazy }

QuizXpress peut être activé en ligne comme hors ligne. L'activation en ligne est simple ; saisissez la clé reçue après votre achat dans la zone de texte ‘Activation key’ et cliquez sur ‘Activate’. Si l'activation réussit, la boîte de dialogue affiche ce qui suit :

![](../assets/images/image4.webp){ width="313" loading=lazy }

Après l'activation, ce formulaire indique ce qui est inclus dans votre licence (les mini-jeux pris en charge et le matériel supplémentaire tel que les tableaux des scores et les appareils Galaxy RGB)

Pour l'activation *hors ligne* (si votre PC n'est pas connecté à Internet), vous devez envoyer votre ‘Computer ID’ et votre ‘Computer key’ à Game Show Crew ; vous recevrez alors par e-mail une clé d'activation hors ligne à saisir dans la zone de texte d'activation hors ligne.

## Désactiver et transférer des licences

Il est possible de transférer une licence vers un autre ordinateur. Pour cela, assurez-vous d'abord d'avoir une copie de votre clé. Dans QuizXpress Studio, appuyez sur la touche F1, puis cliquez sur le bouton ‘Deactivate/Move’ et confirmez le message :

![](../assets/images/image5.webp){ width="283" loading=lazy }

Vous pouvez maintenant vous rendre sur votre autre machine et activer QuizXpress avec la même clé. Selon le type de licence, les clés d'activation peuvent être utilisées sur plusieurs machines.

## Informations sur la licence

Pour voir où votre licence est utilisée (sur quels ordinateurs), appuyez sur F1, puis ouvrez l'onglet **Info** et cliquez sur le bouton **License Details** :

![](../assets/images/image6.webp){ loading=lazy }

Cela ouvrira un nouveau navigateur web (vous devez être en ligne) et affichera une page présentant les détails de votre clé de licence, y compris les ordinateurs sur lesquels la clé est actuellement utilisée.
