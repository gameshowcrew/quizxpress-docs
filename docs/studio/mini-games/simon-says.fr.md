# Simon Says

Dans le mini-jeu Simon Says, le public participe à un jeu qui met les joueurs au défi de reproduire une séquence de lumières de plus en plus longue. Options de configuration disponibles :

![](../../assets/images/image154.webp){ width="323" loading=lazy }

- **Game Mode**. Il existe 2 modes de jeu : Rounds et Last Man Standing. En mode Rounds, le jeu se termine après un nombre défini de manches. En mode Last Man Standing, le jeu se termine lorsqu'il ne reste plus personne ou exactement une personne.

- **Points**. Il existe 2 façons de gagner des points en tant que joueur. Les points pour les survivants (Points for survivors) sont gagnés par les joueurs qui ont survécu à toutes les manches définies dans ‘number of rounds’ ou qui sont le dernier joueur en lice. Les points définis dans ‘Points for every right answer’ sont attribués aux joueurs qui survivent à une manche.

- **Sequence length lights to start with.** Indique combien de lumières s'allument au début du jeu.

- **Sequence Speed**. Indique la vitesse à laquelle les lumières s'allument.

- **Voting Speed**. Indique de combien de temps les joueurs disposent pour saisir leurs votes après l'affichage d'une séquence de lumières.

- **Background Image**. Définit l'image d'arrière-plan du jeu.

- **Show letters on lights**. Indique s'il faut afficher les lettres (A-F) sur les lumières.

- **Hide expelled players**. Masque automatiquement les joueurs qui ont perdu.

- **Number of lights**. Définit le nombre de lumières du jeu. Ce nombre peut aller de 2 à 6.

- **Light Sounds**. Les sons émis par chaque lumière lorsqu'elle s'allume peuvent être configurés. Chaque son de lumière (1-6) peut être défini individuellement.

- **Voting music**. Définit la musique jouée pendant le vote.

- **Use custom texts**. Modifie les messages par défaut affichés pendant le jeu.

  - Round start : le texte affiché au début d'une manche.

  - Winner : le texte affiché lorsqu'un ou plusieurs joueurs ont gagné.

  - All out : le texte affiché lorsque tout le monde a perdu.

Le but du jeu est que, pendant qu'une séquence de lumières est jouée, les joueurs doivent la mémoriser.

![](../../assets/images/image155.webp){ loading=lazy }

Lorsque la séquence est terminée, les joueurs saisissent la séquence sur leur keypad / buzzer / téléphone

![](../../assets/images/image156.webp){ loading=lazy }

Ensuite, le système évalue les réponses et affiche les joueurs gagnants et perdants. Une lumière aléatoire est alors ajoutée à la séquence et la séquence est rejouée. Le jeu devient ainsi de plus en plus difficile au fil du temps.

Dans ce jeu (mode Last Man Standing), seule la réponse du joueur 1 était correcte. Le joueur 1 remporte la partie.
