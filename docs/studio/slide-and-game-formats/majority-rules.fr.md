# Majority Rules

Pour ce type de question, la bonne réponse dépend de ce que la majorité du public a choisi. Ainsi, un joueur ne gagne des points que s'il a choisi la même réponse que la majorité du public. Si plusieurs réponses ont le même nombre de votes, toutes ces réponses sont considérées comme correctes. Lorsque la question est terminée, QuizXpress affiche sur la diapositive la ou les bonnes réponses (les plus choisies).
