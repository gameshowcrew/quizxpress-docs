# Opdrachtregelopties

De volgende opdrachtregelopties zijn beschikbaar bij het starten van QuizXpress Live:

| Opdrachtregel                    | Uitleg                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \-*nosnapshot*                   | Voor herstel houdt QuizXpress Live allerlei gegevens bij die tijdens een quiz ontstaan (keuzes van teams, scores, huidige vraag, enzovoort). Deze verzameling gegevens heet een ‘snapshot’. Als een quiz om een onvoorziene reden wordt afgebroken, leest QuizXpress Live bij het herstarten alle gegevens uit de snapshot van die quiz, zodat de quiz kan doorgaan vanaf het punt waar hij werd afgebroken. Met de opdrachtregelinstelling –nosnapshot wordt er geen snapshotbestand geschreven. |
| \-*quickstart*                   | Het welkomstscherm en het aftelscherm overslaan                                                                                                                                                                                                                                                                                                                                                                                                                              |
| *-windowed*                      | De toepassing in een gewoon venster starten, zodat u nog andere toepassingen kunt gebruiken                                                                                                                                                                                                                                                                                                                                                                                 |
| *-noborder*                      | Gebruiken in combinatie met –windowed; draait in vensterweergave maar zonder titelbalk/rand, zodat het eruitziet als exclusieve volledig-schermmodus terwijl het in werkelijkheid in een gewoon venster draait. U kunt deze modus ook inschakelen door tijdens de show op de M-toets te drukken.                                                                                                                                                                              |
| \-*showfps*                      | Het aantal beeldjes per seconde tonen (voor prestatiemetingen)                                                                                                                                                                                                                                                                                                                                                                                                              |
| \-*singleuser*                   | QuizXpress Live starten in eenpersoonsmodus; deze optie wordt gebruikt bij het starten van de show vanuit QuizXpress Solo                                                                                                                                                                                                                                                                                                                                                   |
| \-*scorefile=\<file>*           | Bestandsnaam voor het scorebestand, waarin alle relevante quizgegevens worden opgeslagen (keuzes per team, scores per team, timinginformatie, enzovoort)                                                                                                                                                                                                                                                                                                                    |
| *-startwith=\<0..n>*            | De quiz starten met de opgegeven vraag, bijvoorbeeld –startwith=5 om met de 5e vraag te beginnen                                                                                                                                                                                                                                                                                                                                                                            |
| *-autorun*                       | Een publiek simuleren                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| *-autoexit*                      | De toepassing automatisch afsluiten na het scorescherm (gebruiken in combinatie met *–autorun*)                                                                                                                                                                                                                                                                                                                                                                             |
| *-screen=\<devicename>*         | De toepassing starten op het opgegeven uitvoerapparaat                                                                                                                                                                                                                                                                                                                                                                                                                      |
| *-settingsfile=\<settingsfile>* | Instellingen laden uit het opgegeven instellingenbestand. Zo kunt u eenvoudig wisselen tussen verschillende configuraties (zoals teamopstellingen)                                                                                                                                                                                                                                                                                                                          |
| *-preload*                       | Optie (geavanceerd) om bij het opstarten alle dia’s vooraf te laden en te renderen. Alleen nodig als u vertragingen ervaart tijdens uw quiz en uw pc voldoende geheugen heeft                                                                                                                                                                                                                                                                                              |

Om QuizXpress Live bijvoorbeeld te starten in een venster dat het volledige scherm vult, kunt u de volgende opdracht gebruiken (te starten vanuit een batchbestand of opdrachtvenster):

“Quiz Show.exe” –windowed –noborder c:\myquizzes\quiz1.qx
