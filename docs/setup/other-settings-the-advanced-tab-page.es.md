# Otros ajustes – la pestaña Advanced

La pestaña Advanced contiene varios ajustes avanzados:

![](../assets/images/image344.webp){ width="598" loading=lazy }

**Full screen slides**

Esta opción muestra cada diapositiva en modo de pantalla completa. De forma predeterminada, las diapositivas ‘flotan’ en la pantalla, con márgenes en todos los lados.

Al hacer clic en la opción de pantalla completa, las diapositivas se muestran a pantalla completa. El fondo se extiende para ocupar todo el escritorio, y el tamaño de los elementos de la diapositiva (pregunta, respuestas) también aumenta ligeramente.

!!! note

    al hacer clic en la opción Full screen slides, aparece una segunda opción, ‘Legacy mode’. Esta admite el antiguo ajuste de pantalla completa, que funcionaba de forma ligeramente distinta. Anteriormente, la opción de diapositivas a pantalla completa hacía que la barra del reloj se superpusiera al texto de la pregunta. Para solucionarlo, había que desplazar hacia abajo los elementos de las diapositivas (el texto de la pregunta y las respuestas) para adaptarse a la visualización a pantalla completa. Si tiene quizzes con un diseño pensado para la antigua opción de pantalla completa, marque la casilla ‘Legacy mode’.

**Show 3-2-1 Quiz countdown screen**

Indica si se muestra una animación de cuenta atrás antes de que comience el quiz.

**Show individual feedback during voting (\<20 players)**

Cuando esta opción está marcada, se mostrará cada voto individual en las preguntas en las que la votación está establecida en ‘True’. Si no está marcada, solo se mostrará un contador con el número total de votos recibidos. Para ver un ejemplo, consulte las imágenes mostradas al final de 5.4.5. Esto solo se aplica cuando hay menos de 20 jugadores.

**Show top three teams using space on end score screen:**

Cuando está activada, la pantalla de puntuación final no muestra automáticamente a los 3 primeros jugadores, sino que espera a que se pulse la barra espaciadora. Al pulsar varias veces la barra espaciadora se muestran, por turno, el 3<sup>.er</sup>, el 2<sup>.º</sup> y el 1<sup>.er</sup> puesto. Después se muestra la clasificación completa.

**Use remote control**

Indica si se utiliza un mando a distancia para el presentador del quiz (en el sistema de pulsadores QuizXpress esta opción siempre está habilitada, ya que este sistema incluye un mando a distancia especial).

**Show correct answer**

Si está marcada (valor predeterminado), la respuesta correcta (indicada con una marca de verificación verde) se muestra cuando se evalúa una pregunta de opción múltiple. Si no está marcada, la respuesta correcta no se muestra, de modo que usted mismo puede decir al público cuál es la respuesta correcta. Como alternativa, puede utilizar una forma para anular este comportamiento predeterminado e indicar usted mismo la respuesta correcta; por ejemplo, mostrando una gran flecha roja que apunte a la respuesta correcta.

**Randomize Questions**

Cuando está marcada, las preguntas de un quiz se muestran en orden aleatorio. Cuando hay rondas, se mezclan las preguntas dentro de cada ronda. Indicando un porcentaje, puede indicar a QuizXpress que muestre solo una parte de las preguntas (en orden aleatorio). La forma en que se mezclan las diapositivas se controla con la opción ‘Shuffle mode’, que puede establecer por diapositiva.

** Show Quizmaster Hints**

Al ejecutar un concurso en QuizXpress Live, hay varios comandos disponibles en diferentes momentos; por ejemplo, mostrar gráficos, avanzar a la siguiente diapositiva, mostrar resúmenes de puntuaciones o juzgar preguntas. Todos estos comandos tienen teclas de acceso rápido en el teclado (o pueden manejarse con un mando a distancia del presentador del quiz).

Para guiar a los usuarios principiantes, durante un quiz pueden mostrarse las Quizmaster hints, que muestran todos los comandos disponibles a medida que son aplicables. Cuando el presentador del quiz se sienta seguro manejando el sistema, puede desactivar este ajuste (en Quiz Setup) para que el público ya no vea las sugerencias. De forma predeterminada, las quizmaster hints están **habilitadas**.

**Enable QuizXpress Director**

Cuando esta opción está marcada, Director se abre inmediatamente al iniciarse QX Live. Si no está marcada, aún puede abrir Director en cualquier momento con la tecla ‘D’ *(nota: esta opción solo está disponible en la edición Ultimate)*.

**Automatically advance to the next question**

Con esta opción, puede hacer que Live avance a la siguiente pregunta sin intervención. Así, si tiene una serie de preguntas de opción múltiple para ejecutar ante su público sin estar presente, esta es la opción que debe utilizar. También puede establecer el tiempo entre preguntas.

**Automatically disable players that don’t respond**

Cuando está habilitada, el sistema deshabilita automáticamente a los jugadores que no han respondido durante un cierto número de preguntas (lo que significa que probablemente han abandonado el quiz).

**Automatically register all keypads**

Normalmente, el público debe registrarse al principio de una sesión. De este modo, el sistema sabe qué mandos participan y puede finalizar una pregunta una vez recibidas todas las respuestas. Si este proceso de registro resulta incómodo, puede activar este indicador y el sistema omitirá la pantalla de registro y registrará todos los mandos configurados. Por ejemplo, si ha establecido la configuración del dispositivo en ‘1-100’, se registrarán todos los mandos del 1 al 100.

**Allow the next in line to answer**

Cuando está habilitada, el sistema permite de forma secuencial que todos los jugadores que respondieron a una pregunta abierta (en los 2 segundos siguientes a la primera respuesta) den una respuesta, hasta que se dé una respuesta correcta. Si no está habilitada, solo el primer jugador puede responder, tras lo cual el sistema vuelve a ceder la palabra a todos los jugadores (excepto a los que ya dieron una respuesta incorrecta).

**Automatically restart the quiz**

Esta opción permite que el quiz se reinicie automáticamente unos segundos después de llegar a la pantalla de puntuación final, lo que le permite crear un quiz autónomo que no necesita la presencia de un presentador del quiz.

**Highlight the correct answer in the response chart**

Si no desea que la respuesta correcta aparezca resaltada en el gráfico de respuestas, desactive este ajuste. Esto puede ser útil, por ejemplo, cuando primero desea comprobar con el público cuántas respuestas hubo para cada opción, sin resaltar la correcta.

**Always run the countdown timer for the full time**

Si desea que el reloj corra durante todo el tiempo especificado, independientemente de si todos ya han respondido, marque esta opción (cuando la opción está desactivada, el reloj se detiene en cuanto todos han respondido). Si prefiere un tiempo de cuenta atrás constante, marque esta opción.

**Allow players to revise their answer**

Al marcar esta opción, los jugadores pueden revisar su respuesta mientras el reloj de cuenta atrás está en marcha.

**Do not reveal points onscreen during question**

De forma predeterminada, el sistema muestra los puntos ganados o perdidos en las preguntas de fastest finger. Para crear más suspense, puede activar este indicador de modo que los puntos de un jugador no se conozcan hasta que se muestre la clasificación.

**Use ‘?’ button on remote to toggle with Microsoft PowerPoint**

Para los usuarios que deseen combinar QuizXpress con presentaciones de PowerPoint, esta función le permite alternar entre la pantalla de PowerPoint y QuizXpress mediante el botón ‘?’ del mando a distancia del presentador.

**Remove top panel when answering to avoid overlapping**

En determinadas situaciones (pregunta abierta, votación con respuesta individual), la diapositiva se desplaza hacia arriba cuando un jugador pulsa, lo que hace que se superponga con el panel superior. Este ajuste hace que el panel superior desaparezca temporalmente para evitar la superposición.
