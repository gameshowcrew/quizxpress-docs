# Lucky Marbles

Los jugadores pueden conseguir puntos en esta emocionante variante del clásico juego de canicas Plinko. Tras elegir el cubo en el que creen que caerá la canica —y, opcionalmente, votar o competir para seleccionar el punto de lanzamiento—, la canica cae y rebota por el tablero, guiada por una simulación física realista. Con varios diseños de tablero y un *vórtice* giratorio opcional que puede devolver la canica a una posición inicial aleatoria, cada ronda está llena de suspense y sorpresas.

El juego tiene las siguientes opciones de configuración:

![](../../assets/images/image167.webp){ width="331" loading=lazy }

- Number of rounds: cuántas rondas se juegan

- Allow players to vote on where to drop the marble: si está activada, el juego comienza con el público eligiendo dónde se suelta la canica. El público puede seguir cambiando su elección hasta que el presentador decida soltar la canica

- Random initial spin: cuánto gira la canica al soltarse

- Marble restitution: cuánto rebota la canica

- Allow vortex pin: muestra un vórtice en el centro que absorbe la canica y la devuelve a la parte superior

- En las pestañas de ronda, puede configurar los siguientes ajustes por ronda:

  - Number of buckets: número de cubos de destino en la parte inferior de la pantalla

  - Points: puntos que se ganan por cada cubo

  - Peg board layout: elija entre varios diseños disponibles

  - Drop zone: indica desde dónde se suelta la canica (solo está activo cuando el ajuste *Allow players to vote on where to drop the marble* no está activado).

La pestaña Text settings le permite cambiar el texto que se muestra en la pantalla y en el teléfono móvil. En la pestaña Audio, puede seleccionar la música que suena durante el juego.
