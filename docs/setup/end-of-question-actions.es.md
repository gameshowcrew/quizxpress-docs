# Acciones de fin de pregunta

En esta pestaña puede definir las acciones que se ejecutan (y en qué orden) cuando termina una pregunta (se han recibido todas las respuestas, o se ha dado una respuesta correcta en una pregunta abierta).

![](../assets/images/image345.webp){ width="604" loading=lazy }

Normalmente, si no se modifican las acciones, se ejecuta una secuencia estándar de acciones, como resaltar la respuesta correcta y mostrar estadísticas en el panel de información, etc. Cuando se anulan las acciones estándar, las acciones configuradas se ejecutan una por una en el orden establecido cada vez que se pulsa el botón OK del mando a distancia del presentador del quiz, se pulsa la barra espaciadora en Live o se hace clic en el botón ‘Next’ en Director.

Puede configurar las siguientes acciones:

**Show correct answer**

Esta acción resalta la respuesta correcta en la diapositiva y muestra un indicador, normalmente una marca de verificación, aunque puede variar según el estilo de su diapositiva. Puede omitir esta acción si desea mostrar la respuesta correcta de otra forma (por ejemplo, con una forma o un elemento de texto en la diapositiva).

**Show correct, incorrect, not answered bar**

Muestra el gráfico de respuestas en la barra de información superior.

![](../assets/images/image346.webp){ width="457" loading=lazy }

**Show intermediate scores**

Abre la clasificación (resumen de los 20 primeros, que normalmente se abre con la tecla ‘S’)

**Show response chart**

Muestra la pantalla del gráfico de barras de respuestas.

**Go to next slide**

Avanza a la siguiente diapositiva; esta acción siempre está activada y siempre se ejecuta en último lugar.
