# Módulo de reloj y presentación de imágenes

Este módulo puede mostrar un reloj digital (con cuenta atrás), una presentación de imágenes con vistosos efectos de transición, o una combinación de ambos.

Opciones de configuración:

En la primera página puede configurar si se muestra el reloj, la presentación de imágenes o ambos (en cuyo caso el reloj se muestra a un intervalo configurable durante un tiempo determinado)

Para el reloj puede configurar las siguientes opciones:

- Announcement: texto que se muestra en pantalla encima del reloj

- Mode – Clock: la hora se muestra en pantalla

- Mode – Timer: un temporizador cuenta atrás desde el tiempo indicado hasta 00:00:00

- Background Image: imagen que se muestra de fondo

- Timer expires sound: suena cuando el temporizador llega a cero

- Clock ticking sound: suena mientras el reloj hace tictac o,

- A playlist folder: la carpeta de la que el módulo reproduce archivos MP3 al azar mientras el reloj hace tictac. (Tenga en cuenta que, al usar el reloj *integrado en* el quiz, esta carpeta también debe existir en el PC en el que ejecuta su quiz.)

En la última página puede configurar la presentación de imágenes seleccionando una carpeta de la que se toman las imágenes, junto con la información de tiempos.
