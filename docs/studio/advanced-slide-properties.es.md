# Propiedades avanzadas de la diapositiva

En este cuadro de diálogo puede configurar algunas propiedades más avanzadas de la pregunta actual:

![](../assets/images/image280.webp){ width="177" loading=lazy }

**Show correct answer mode**

Ajuste que indica si la respuesta correcta debe mostrarse una vez terminada la pregunta. De forma predeterminada se utiliza el ajuste definido en QuizXpress Setup.

**Countdown timer mode**

Ajuste que indica cómo debe comportarse la cuenta atrás en esta pregunta. De forma predeterminada se utiliza el ajuste definido en QuizXpress Setup.

**Lock-out mode for fastest finger question**

Normalmente, un jugador que da una respuesta incorrecta queda excluido de la pregunta. Con este ajuste puede cambiar ese comportamiento para que los jugadores puedan volver a intentarlo con otra respuesta. Solo está disponible si la diapositiva es una diapositiva de fastest finger.

**Shuffle mode**

QuizXpress permite mezclar las preguntas de un quiz cuando se juega en QuizXpress Live!. Como quizá desee mantener algunas diapositivas en su sitio (por ejemplo, los Billboards que anuncian rondas) o mantenerlas unidas a la diapositiva anterior o siguiente (por ejemplo, cuando la información de una diapositiva se aplica a la siguiente o a la anterior, o en el caso de las apuestas), este ajuste ofrece justamente esa posibilidad. Indica qué debe ocurrir con la diapositiva cuando QuizXpress Live selecciona un subconjunto mezclado de las preguntas del archivo de quiz (configurado en Quiz Setup, donde puede elegir aleatorizar un porcentaje de las preguntas). Este ajuste es útil cuando desea ejecutar el mismo quiz varias veces, por ejemplo en una feria comercial. Nota: también se puede acceder a estas opciones desde la cuadrícula de propiedades (a nivel de diapositiva).
