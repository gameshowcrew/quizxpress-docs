# L’assistant Quiz Wizard

Pour vous aider à créer rapidement du nouveau contenu, Studio propose aussi un Quiz Wizard. Pour le lancer, dans l’onglet HOME du ruban, cliquez sur le bouton ‘Quiz Wizard’ dans la section ‘Magic’. Le Quiz Wizard peut vous aider à créer des diapositives individuelles ou des manches entières. Il vous guide à travers une série d’étapes, à l’issue desquelles il crée le contenu demandé. Il ne vous reste ensuite qu’à saisir les questions et réponses proprement dites dans les diapositives de quiz créées. Par exemple, pour créer un nouveau Trivia Board, l’assistant affiche l’écran de configuration suivant :

![](../../assets/images/image25.webp){ width="452" loading=lazy }

Vous précisez ici l’aspect de la grille du Trivia Board et le nombre de questions par points/catégorie.

Autre exemple d’utilisation de l’assistant : la possibilité de générer une manche entière de Disco Bingo à partir d’un dossier de fichiers mp3. Il lit les balises mp3 d’artiste/titre (lorsqu’elles sont présentes dans les fichiers mp3) pour générer automatiquement les bonnes réponses qui apparaîtront sur les cartes de bingo.
