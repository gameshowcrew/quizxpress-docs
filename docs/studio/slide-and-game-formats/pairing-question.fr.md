# Pairing question

Dans une Pairing Question, les joueurs associent des libellés de texte à des images (par exemple des pays à des drapeaux ou des marques à des logos). Voici ce que cela donne sur le buzzer mobile :

| ![](../../assets/images/image46.webp){ width="159" loading=lazy } | ![](../../assets/images/image47.webp){ width="161" loading=lazy } | ![](../../assets/images/image48.webp){ width="160" loading=lazy } |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------|

Pour créer ce type de question, sélectionnez un modèle comportant au moins *trois* emplacements d'image et définissez le type de question sur « Pairing Question ». Attribuez ensuite le libellé approprié à chaque image :

![](../../assets/images/image49.webp){ loading=lazy }

Vous pouvez également utiliser le Quiz Wizard.

![](../../assets/images/image50.webp){ width="390" loading=lazy }

Renseignez ensuite les libellés et sélectionnez les images correspondantes :

![](../../assets/images/image51.webp){ width="390" loading=lazy }

Cliquez sur **Next** et terminez l'assistant pour créer la pairing question.

## Hotspot questions

Avec ce type de question, le joueur doit marquer un point (ou plusieurs points) sur une image, et la réponse est correcte lorsque ce point (ou ces points) se trouve dans la zone marquée comme correcte par le concepteur du quiz.

Par exemple, si nous voulons que les joueurs trouvent la France sur une carte, nous choisissons un modèle comportant une seule image :

![](../../assets/images/image52.webp){ width="602" loading=lazy }

Définissez le type de saisie sur « Hotspot » :

![](../../assets/images/image53.webp){ width="251" loading=lazy }

Placez ensuite une image de carte dans l'emplacement d'image, puis modifiez la ou les zones hotspot avec l'**Hotspot Editor** (faites un clic droit sur l'image et sélectionnez **Edit Hotspots**) :

![](../../assets/images/image54.webp){ loading=lazy }Marquez maintenant la zone qui constitue la bonne réponse (ici en rouge). Les formes de zones prises en charge comprennent les zones rectangulaires, elliptiques et à main levée.

Plusieurs zones correctes peuvent être définies :![](../../assets/images/image55.webp){ width="602" loading=lazy }

Avec plusieurs zones, cela ressemble à ceci dans l'application Smart Buzzer :

![](../../assets/images/image56.webp){ width="185" loading=lazy }

Sur l'écran du quiz, l'image révélera la bonne réponse de cette manière :

![](../../assets/images/image57.webp){ loading=lazy }

!!! note

    lorsque plusieurs zones sont utilisées et que l'utilisateur marque plus de points qu'il n'y a de zones correctes, son score diminue (afin d'éviter les réponses au hasard avec de nombreux marqueurs).
