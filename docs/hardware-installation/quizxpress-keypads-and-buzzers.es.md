# Mandos y pulsadores QuizXpress

![](../assets/images/image482.webp){ width="148" loading=lazy }

Proceda de la siguiente manera para instalar el receptor QuizXpress y configurar QuizXpress para que funcione con los pulsadores.

Para instalar el receptor QuizXpress, conéctelo a un puerto USB disponible. Windows instalará el receptor automáticamente la primera vez que se utilice. Verá los siguientes mensajes en la barra de tareas de Windows.

![](../assets/images/image483.webp){ width="264" loading=lazy }![](../assets/images/image484.webp){ width="261" loading=lazy }

Ahora puede configurar QuizXpress para que utilice los pulsadores QuizXpress (consulte también [Mandos básicos de QuizXpress](../setup/configuring-your-hardware-the-buzzers-tab-page.md#mandos-basicos-de-quizxpress)).

- Inicie Quiz Setup

- En la pestaña ‘Buzzers’ de Quiz Setup, seleccione *QuizXpress Keypad*.

- Con el receptor conectado, puede pulsar el botón ‘Test’, tras lo cual se establece una conexión. Si tiene éxito, aparece una marca de verificación verde.

- Ahora cierre Quiz Setup e inicie QuizXpress Buzzer Test, que se encuentra en el menú Inicio, en QuizXpress. Al pulsar uno de los pulsadores, debería iluminarse la casilla numerada correspondiente en la pantalla y mostrarse la respuesta elegida.

- Cuando los pasos anteriores se hayan realizado correctamente, QuizXpress Live está listo para funcionar con pulsadores QuizXpress.

!!! note

    Los mandos QuizXpress funcionan con dos pilas AAA.

El receptor QuizXpress tiene tres LED. El rojo indica si recibe alimentación, el amarillo indica la comunicación y el verde indica la actividad de sondeo de RF. Durante el espectáculo del quiz, el verde debería parpadear. Si no es así, debe reiniciar el dispositivo con F12.
