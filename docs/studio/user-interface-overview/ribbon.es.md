# Cinta de opciones

La interfaz de usuario de QuizXpress Studio se basa en el concepto de cinta de opciones. La cinta de opciones se introdujo en Microsoft Office y mejora considerablemente la productividad del usuario y la facilidad para descubrir funciones. Haga clic [aquí](http://msdn.microsoft.com/en-us/library/windows/desktop/cc872782.aspx) para obtener más información general sobre el concepto de interfaz de usuario de la cinta de opciones de Microsoft.

La cinta de opciones de QuizXpress Studio se divide en varias secciones (pestañas de la cinta).

| **File**          | También denominado menú ‘backstage’. Acceso a las funciones globales y relacionadas con los archivos.      |
|-------------------|-------------------------------------------------------------------------------------------------|
| **Home**          | Elementos generales de formato y de control                                                     |
| **Insert**        | Añadir nuevos elementos, como sonido y texto, a su diapositiva de quiz                          |
| **Question**      | Configurar el comportamiento de una pregunta (puntos, tipo de pregunta, etc.)                   |
| **Design**        | Dar formato a su diapositiva con diferentes estilos y diseños                                   |
| **View**          | Seleccionar qué se muestra en la interfaz de usuario de QuizXpress Studio                       |
| **Quiz Show**     | ¡Iniciar el concurso!                                                                           |
| **Picture**       | Configurar imágenes (se muestra al seleccionar una imagen en una diapositiva)                   |
| **Shape**         | Configurar formas de imagen y de texto (se muestra al seleccionar una imagen o un texto insertado en una diapositiva) |
| **Speech**        | Configurar la voz (se muestra al seleccionar un elemento de voz en una diapositiva)             |
| **Chart**         | Configurar gráficos (se muestra al seleccionar un gráfico en una diapositiva)                   |
| **Audio**         | Configurar un fragmento de audio (se muestra al seleccionar audio en una diapositiva)           |
| **Video**         | Establecer las diversas propiedades de vídeo (se muestra al seleccionar un vídeo en una diapositiva) |
| **Trivia Board**  | Configurar una diapositiva Trivia Board (pestaña contextual)                                    |
| **Trivia Ladder** | Configurar una diapositiva Trivia Ladder (pestaña contextual)                                   |
| **Bingo**         | Configurar las propiedades de una ronda de Bingo                                                |
| **Word Game**     | Configurar las propiedades de un Word Game (pestaña contextual)                                 |
| **Trivia Feud**   | Configurar una diapositiva Trivia Feud (pestaña contextual)                                     |

Además de las pestañas globales de la cinta, que siempre están visibles, existen las llamadas ‘pestañas contextuales’. Su visibilidad depende del elemento seleccionado en el editor. Por ejemplo, al seleccionar un elemento de vídeo en la diapositiva, aparece la pestaña contextual VIDEO:
