# Contrôler le quiz

À différentes étapes d’un quiz, l’animateur de quiz doit effectuer (ou peut choisir d’effectuer) diverses actions, par exemple :

- Afficher un graphique

- Afficher un aperçu des scores/faire défiler les scores

- Passer à la question suivante

- Juger les réponses données (correctes/incorrectes)

Ces instructions peuvent être données à QuizXpress Live de plusieurs façons : au clavier, ou avec une télécommande sans fil telle qu’un présentateur sans fil PowerPoint ou la télécommande d’animateur de quiz QuizXpress.

À titre d’aide à l’apprentissage, des conseils pour l’animateur de quiz peuvent être affichés après chaque question, à configurer dans Quiz Setup. Vous pouvez en savoir plus sur ces conseils dans [Menu d’aide de l’animateur de quiz](#menu-daide-de-lanimateur-de-quiz).

## Menu d’aide de l’animateur de quiz

Lorsque vous animez un show de quiz dans QuizXpress Live, plusieurs commandes sont disponibles à différentes étapes — afficher des graphiques, passer à la diapositive suivante, afficher des aperçus de scores ou juger des questions. Comme vu dans les sections précédentes, toutes ces commandes ont des raccourcis clavier, et certaines peuvent aussi être commandées avec une télécommande d’animateur de quiz.

Pour guider les utilisateurs débutants, des conseils pour l’animateur de quiz peuvent être affichés pendant un quiz, présentant toutes les commandes disponibles au fur et à mesure qu’elles deviennent applicables. Dès que l’animateur de quiz est à l’aise avec le système, il peut désactiver ce paramètre pour que le public ne voie plus les conseils.

Par défaut, les conseils pour l’animateur de quiz sont activés (‘on’) dans l’onglet ‘Advanced’ de l’application Quiz Setup.

Voyez ci-dessous deux exemples de conseils pour l’animateur de quiz tels qu’ils s’affichent dans QuizXpress Live pendant un quiz.

![](../assets/images/image440.webp){ loading=lazy }

Dans l’écran de conseils pour l’animateur de quiz ci-dessus, affiché par exemple à la fin d’une question, nous voyons les boutons suivants avec les différentes commandes et leurs ‘raccourcis clavier’ facultatifs :

- **Advance \[Space\] : passer à la diapositive suivante**

- **Skip to End :** aller à la fin du quiz (l’écran des scores finaux)

- **Team Control \[E, R, T\] : afficher les aperçus des scores des équipes. Dans ces aperçus, les points des équipes peuvent être modifiés et les équipes peuvent être exclues.**

- **Exit \[Alt-F4\] : quitter QuizXpress Live**

- **Disconnect/Reconnect Base : déconnecter/reconnecter la station de base sans fil (récepteur)**

- **Chart \[C\] : afficher un graphique de toutes les réponses données (désactivé ici, car la question était une question de rapidité)**

- **Demographic Chart \[G\] : afficher les pourcentages de réponses pour tous les groupes (applicable uniquement si des groupes démographiques sont présents)**

- **Scores \[S\] : afficher l’écran des scores intermédiaires (top 20)**

!!! note

    Lorsque QuizXpress est ‘idle’ (en pause, fin de question ou en attente du compte à rebours), le menu Quizmaster Hints peut toujours être affiché en appuyant sur ‘F1’.
