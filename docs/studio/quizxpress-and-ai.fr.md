# QuizXpress et l'IA

QuizXpress vous donne accès à votre propre rédacteur de quiz virtuel alimenté par l'IA. Vous pouvez générer des questions, compléter des questions à choix multiples avec des options plausibles, créer des sondages Trivia Feud ou générer des images !

!!! tip
    Vous préférez une conversation ? Vous pouvez aussi laisser un assistant IA tel que Claude créer et modifier votre quiz dans Quiz Studio à votre place : consultez [Assistants IA](../advanced/ai-assistants/index.md).

## Générateur de quiz IA

Le générateur de quiz IA vous aide à générer différents types de questions. Vous pouvez le lancer en cliquant sur le bouton de l'onglet HOME.

![](../assets/images/image234.webp){ width="112" loading=lazy }

Après avoir cliqué sur le bouton, la fenêtre Trivia generator s'affiche.

![](../assets/images/image235.webp){ loading=lazy }

Dans le champ Topic, saisissez le sujet souhaité. Soyez le plus précis possible. Par exemple :

« Questions de musique » produira des questions de musique très générales, et poser plusieurs fois la même demande peut générer les mêmes questions. Essayez plutôt « Questions de musique sur le top 10 des tubes des années quatre-vingt-dix ».

Vous pouvez indiquer les types de questions que vous souhaitez générer :

- une question à choix multiples – vous pouvez indiquer le nombre de réponses

- une question ouverte

- une question Oui/Non

- une question Vrai/Faux

Vous pouvez également jouer avec les curseurs Creativity/Difficulty et Fun Factor qui, selon le sujet, ont plus ou moins d'influence.

Appuyez maintenant sur le bouton « Generate » et regardez les questions se générer pour vous, accompagnées de notes détaillées que l'animateur de quiz peut utiliser pendant l'animation du quiz.

Les questions générées sont présentées sous forme de liste, avec les réponses correspondantes. Dans le cas des questions à choix multiples, le système d'IA génère également des alternatives plausibles à la bonne réponse. Cette fonction simplifie la création de quiz et garantit que votre contenu est attrayant et complet.

## Complétion par IA pour les questions à choix multiples

Cette fonction vous aide à créer les options d'une question à choix multiples tout en gardant le contrôle de la question. Pour l'utiliser, saisissez la question comme d'habitude, faites un clic droit sur la diapositive et sélectionnez « Complete with AI » dans le menu contextuel. Les options à choix multiples seront remplies et la bonne réponse définie, accompagnée de notes expliquant la bonne réponse.

## Générateur d'images IA

Vous pouvez également utiliser le « QuizXpress AI co-pilot » pour générer des images de diapositive ou un arrière-plan de diapositive.

Par exemple, générez une image dans un emplacement d'image :![](../assets/images/image243.webp){ loading=lazy }

Une description détaillée et un contexte riche donnent de meilleures images. Vous pouvez également préciser le style souhaité, par exemple « 3D rendering », « abstract art », « comic », etc.

Dans l'exemple ci-dessous, quatre images de la tour Eiffel sous la neige sont générées.

![](../assets/images/image244.webp){ width="439" loading=lazy }

Choisissez l'une des quatre images générées, et elle sera insérée dans l'emplacement d'image.

![](../assets/images/image245.webp){ loading=lazy }

Vous pouvez faire de même pour les arrière-plans de diapositive. Faites un clic droit sur l'arrière-plan et choisissez « Generate with AI ». L'exemple ci-dessous génère un arrière-plan pour une manche de musique avec la description « female quizmaster announcing a music round, pointing towards the audience, with headphones, in front of a stage ».

![](../assets/images/image246.webp){ width="440" loading=lazy }

## Valider avec Google

Vous pouvez faire un clic droit sur n'importe quelle question ou réponse et lancer instantanément une recherche Google en ligne sur le texte de l'élément sélectionné. Un navigateur s'ouvre avec les résultats de la recherche, ce qui vous aide à vérifier le contenu généré par l'IA.

![](../assets/images/image247.webp){ loading=lazy }

## Roast par IA

Si vous avez envie de vous amuser, vous pouvez désormais laisser l'IA taquiner publiquement un joueur après une mauvaise réponse pendant un quiz. Cette option est disponible dans Director (bureau), dans l'onglet « Players / Teams ». Veuillez consulter [L'affichage Teams](../live/quizxpress-director/the-teams-view.md) pour plus d'informations.

## Paramètres généraux de l'IA

La fonction de complétion par IA possède quelques paramètres que vous trouverez dans HOME->Options :

![](../assets/images/image248.webp){ width="280" loading=lazy }

Comme l'IA actuelle a une certaine date limite de connaissances, elle ne sait rien de ce qui s'est passé récemment. Cependant, QuizXpress peut effectuer une recherche sur Internet à partir de la question donnée et envoyer les résultats à l'IA pour qu'elle les intègre à son raisonnement. Vous pouvez activer cette fonction dans le formulaire Options.
