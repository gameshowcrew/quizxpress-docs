# HOME → Banners

Sometimes you’ll want each question to have a preceding slide showing the question number and question text of the question that follows. This can be accomplished in QuizXpress Studio using the ‘Generate Question Banners’ command, found under the ‘Edit’ menu. This command automatically generates a quiz slide of type ‘Billboard’ before each quiz slide of type ‘Question’. Each generated billboard slide contains the following text: Question \<question number of the following question>: \<question text of the following question>.
