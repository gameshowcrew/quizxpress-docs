# Note per il Quizmaster

Le note possono essere inserite nella casella di testo ‘Note’. Se la sezione Note non è visibile, andare al menu VISTA e spuntare ‘Note’.

Le note possono essere utilizzate dal Quizmaster per fornire al pubblico alcune informazioni sulla domanda o sulle risposte. Possono far parte dell’esportazione PDF di un quiz. Vengono inoltre mostrate in QuizXpress Director e nell’app Director.
