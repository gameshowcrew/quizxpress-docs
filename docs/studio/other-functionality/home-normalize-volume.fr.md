# HOME → Normalize volume

La commande ‘Normalize volume’, disponible dans le groupe ‘Tools’ de l'onglet HOME, fait en sorte que tous les sons du quiz soient joués au même volume. QuizXpress mesure l'intensité sonore de chaque son et règle son gain vers une intensité cible que vous choisissez. Les fichiers audio eux-mêmes ne sont pas modifiés.

Voir [Normaliser le volume](../adding-multimedia-content/sound.md#normaliser-le-volume) pour une description complète, y compris la façon de normaliser un son individuel.
