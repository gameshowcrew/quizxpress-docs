# Notas del presentador del quiz

Las notas se pueden introducir en el cuadro de texto Notes. Si la sección Notes no se muestra, vaya al menú VIEW y marque la casilla ‘Notes’.

El presentador del quiz puede utilizar las notas para ofrecer al público alguna información sobre la pregunta o las respuestas. Pueden formar parte de la exportación a PDF de un quiz. También se muestran en QuizXpress Director y en la aplicación Director.
