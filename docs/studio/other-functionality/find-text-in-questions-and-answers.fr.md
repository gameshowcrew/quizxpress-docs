# Rechercher du texte dans les questions et les réponses

Vous pouvez rechercher du texte dans les questions ou les réponses en appuyant sur Ctrl+F (ou sur le bouton Find de l'onglet HOME).

![](../../assets/images/image291.webp){ width="301" loading=lazy }

En saisissant du texte et en appuyant sur ‘Find Next’, vous pouvez parcourir les éléments trouvés.
