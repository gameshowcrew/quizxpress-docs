# Guadagnare vendendo biglietti

È possibile utilizzare biglietti elettronici con l'app Smart Buzzer e il sito web buzzerpad per generare ricavi quando si organizzano quiz (online). La vendita di biglietti digitali al pubblico resta tuttavia una responsabilità dell'organizzatore. Esistono diversi plugin CMS per negozi online che consentono di vendere biglietti nel proprio negozio, oppure è possibile utilizzare piattaforme di biglietteria online come <https://www.tickettailor.com/>. Per QuizXpress è sufficiente un semplice file di testo con tutti i codici dei biglietti (un biglietto per riga, senza distinzione tra maiuscole e minuscole). Questo file di testo deve chiamarsi *tickets.txt* e deve essere salvato nella stessa cartella del quiz. All'avvio del quiz, i biglietti vengono inviati al server e, quando un giocatore si connette al quiz, gli viene richiesto un codice biglietto che deve corrispondere a una riga di *tickets.txt*. Ogni biglietto può essere utilizzato una sola volta alla volta, in modo che le persone non possano condividere i biglietti. È possibile aggiornare i biglietti anche mentre il quiz è in corso. A tale scopo, aprire la schermata Director sul PC, attivare la scheda Mobile e individuare il pulsante ‘Refresh Tickets’.
