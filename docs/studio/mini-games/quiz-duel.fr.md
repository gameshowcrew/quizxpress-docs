# Quiz Duel

Quiz Duel est un mini-jeu de ‘réflexes’ amusant, facile à utiliser et d'inspiration western. Avec ses graphismes amusants et ses effets sonores de western, ce jeu donnera à coup sûr une dimension supplémentaire à votre événement !

![](../../assets/images/image164.webp){ loading=lazy }

Le jeu propose les options de configuration suivantes :

![](../../assets/images/image165.webp){ width="316" loading=lazy }

- Il existe deux modes de jeu :

  - **Random Duel mode** : en mode Duel, deux joueurs sont tirés au hasard parmi tous les joueurs et affichés à l'écran sur deux poteaux indicateurs. Le joueur qui tire le premier abat l'autre joueur et gagne des points. Le joueur qui se fait abattre meurt, perd des points et ne peut plus jouer lors des manches suivantes. Si des joueurs du public qui ne sont pas sélectionnés tirent quand même, ils perdent eux aussi des points.

    - Le paramètre *Players that already dueled will not play in a next round* indique si les joueurs déjà apparus sur les poteaux sont exclus de la manche suivante. Cela garantit que chacun a son tour. Lorsque le nombre de joueurs est impair, le dernier joueur affronte un ‘bot cowboy’.

  - **Elimination Duel mode** : en mode Élimination, tous les joueurs doivent tirer le plus vite possible lorsque le message **Shoot!** apparaît à l'écran. Pour chaque joueur qui tire, le temps est enregistré, et le percentile de joueurs les plus lents est éliminé (par exemple, un percentile d'élimination de 50 % élimine les 50 % de joueurs les plus lents). Tirer trop tôt entraîne une défaite immédiate.

    - Le paramètre *Play until last man standing* poursuit le jeu jusqu'à ce qu'il ne reste qu'un seul joueur.

    - Le paramètre *Extra points for last man standing* indique combien de points gagne le dernier joueur resté en lice.

- Autres paramètres du jeu :

  - Points for winner of duel : points gagnés lorsque vous remportez un duel

  - Penalty for loser of duel : points perdus lorsque vous perdez un duel

  - Number of rounds : combien de manches du jeu souhaitez-vous jouer

  - Penalty for missed shots : points de pénalité pour les joueurs qui tirent sans avoir été sélectionnés sur les poteaux en mode Random Duel, ou pour avoir tiré trop tôt dans l'un ou l'autre mode de duel.

Les onglets Text settings et Audio settings permettent de personnaliser le texte et l'audio utilisés dans le mini-jeu.
