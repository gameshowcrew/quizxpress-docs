# HOME → Tabelloni

A volte si desidera che ogni domanda sia preceduta da una diapositiva che mostri il numero e il testo della domanda che segue. Questo può essere ottenuto in QuizXpress Studio con il comando ‘Genera Tabelloni’, che si trova nel menu ‘Modifica’. Questo comando genera automaticamente una diapositiva di quiz di tipo ‘Tabellone’ prima di ogni diapositiva di quiz di tipo ‘Question’. Ogni diapositiva Billboard generata contiene il testo seguente: Question \<numero della domanda successiva>: \<testo della domanda successiva>.
