# El módulo Randomizer

El Randomizer de QuizXpress puede utilizarse para sortear al azar uno o varios jugadores o equipos del público, por ejemplo, para rifar un premio, organizar un concurso de karaoke, jugar a un juego o hacer cualquier otra cosa que complete su noche de concurso.

En lugar de seleccionar jugadores, también puede hacer que el Randomizer seleccione uno o varios números de un intervalo, de una lista separada por comas o de un archivo de texto; es decir, ¡básicamente puede sortear cualquier cosa!

Al sortear jugadores, también puede hacer que los jugadores ganen una cantidad de puntos determinada.

Puede especificar cuántos elementos se sortean en cada ejecución, así como el número de ejecuciones que realizará el Randomizer. Al ejecutarlo más de una vez, puede elegir excluir los elementos sorteados anteriormente. También puede mostrar en pantalla una lista de los elementos sorteados anteriormente.

Al ejecutarse, el Randomizer muestra primero una animación (hay dos estilos configurables) con todos los nombres de los equipos y, a continuación, sortea y presenta los resultados cuando lo ordena el presentador del quiz (con la barra espaciadora o con el mando a distancia del presentador). Para la animación, puede elegir entre una cuadrícula estática y colorida o una animación de nombres de equipos flotantes:

Puede sortear entre un subconjunto de todo el público (mediante un cuadro de diálogo de selección) o incluir a todo el público (sin necesidad de selección manual)

En la sección ‘Appearance’, puede configurar la imagen de fondo que se muestra. La sección ‘Music’ le permite especificar sonidos diferentes para la animación y para cuando se ha realizado la selección.
