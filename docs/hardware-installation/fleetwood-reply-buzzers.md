# Fleetwood Reply buzzers

Please proceed as follows to install Fleetwood Reply buzzers and configure QuizXpress to work with the buzzers.

1.  Turn on the PC/laptop

2.  Insert the Reply drivers CD into the CD/DVD-ROM player

3.  Insert the Reply USB receiver into a USB slot

4.  A window will appear indicating that new hardware has been found. Please indicate that Windows needs to find drivers automatically.

5.  Windows will install the drivers automatically.

6.  Now we can configure QuizXpress to use the Reply buzzers. Start Quiz Setup (see also [Multiple choice buzzer systems](../setup/configuring-your-hardware-the-buzzers-tab-page.md#multiple-choice-buzzer-systems)).

7.  On the ‘Buzzers’ tab page of Quiz Setup, select Fleetwood Reply CRS 940/941.

8.  Now choose the channel that the Reply receiver is using to listen to the Reply keypads (buzzers). To select the correct channel, look at the back of one of the keypads that will be used — the channel it operates on is indicated there (note: all buzzers used must operate on this channel).

9.  Now close Quiz Setup and start QuizXpress Buzzer Test, which can be found on the Start menu under QuizXpress. Pressing one of the buzzers should now light up the corresponding numbered box on the screen and show the chosen answer.

10. When the preceding steps have been executed successfully, QuizXpress Live is ready to work with Reply Buzzers.

!!! note

    Fleetwood Reply buzzers work with lithium cell batteries of type CR2032. Sony CR2032 lithium cell batteries are recommended.
