# Cups and Balls

Dans le jeu des gobelets et de la balle, le public doit deviner sous quel gobelet se trouve une balle après le mélange des gobelets. Au départ, la balle est montrée. Ensuite, les gobelets sont mélangés et chaque joueur doit bien observer. Enfin, chaque joueur doit dire sous quel gobelet se trouve la balle. Ce jeu permet de gagner des points ou des prix.

Options de configuration disponibles :

![](../../assets/images/image134.webp){ width="436" loading=lazy }

- Round : vous pouvez définir jusqu'à quatre parties qui s'enchaîneront (par exemple avec une vitesse ou un nombre de gobelets croissants).

- Active : indique si une manche est active (si elle n'est pas active, elle est ignorée)

- Cups : le nombre de gobelets utilisés

- Duration : la durée du mélange des gobelets

- Speed : la vitesse du mélange

- Prize type : indique si l'on peut gagner un prix ou des points

- Points won : le nombre de points qu'un joueur gagne s'il a la bonne réponse (si le ‘Prize type’ est ‘Points’)

- Points won : le nombre de points qu'un joueur perd s'il se trompe (si le ‘Prize type’ est ‘Points’)

- Prize text : texte affiché lorsqu'un prix est gagné

- Prize image : image du prix gagné. Les images peuvent être sélectionnées ou supprimées à l'aide des deux boutons situés à côté de l'image.

- Participants : tous les joueurs peuvent jouer, seuls les joueurs les mieux classés peuvent jouer, ou seuls les joueurs sélectionnés peuvent jouer (la sélection se fait avant le début du jeu, sur l'écran du Director).

- Appearance tab : vous pouvez y sélectionner les images à afficher sur les gobelets (par exemple un logo d'entreprise), une image d'arrière-plan ainsi que la texture de la table sur laquelle sont posés les gobelets. Vous pouvez aussi choisir une autre musique de fond, jouée une fois que les gobelets sont mélangés

Pour passer d'une étape à l'autre du jeu (les gobelets sont chargés, la balle est montrée, les gobelets sont mélangés, les joueurs choisissent un gobelet, la balle est révélée), il suffit d'appuyer sur le bouton ‘Next’ dans le panneau de gauche.
