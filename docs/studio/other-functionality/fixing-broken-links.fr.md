# Réparer les liens rompus

Lorsque vous liez du contenu audio et vidéo, le quiz ne contient que le chemin d'accès au fichier externe. Si vous déplacez le fichier externe, QuizXpress ne pourra plus le localiser, ce qui entraîne un lien rompu. Après le chargement d'un quiz, Studio exécute une tâche en arrière-plan pour vérifier que tous les fichiers multimédias référencés sont toujours présents. Lorsqu'il détecte au moins un lien rompu, il présente un formulaire listant tous les liens manquants :

![](../../assets/images/image304.webp){ width="568" loading=lazy }

Dans ce formulaire, vous pouvez rapidement résoudre le problème (les fichiers liés doivent bien sûr toujours être disponibles quelque part sur l'ordinateur). Si tous les fichiers sont toujours disponibles sous un dossier racine, vous pouvez laisser le système les rechercher à l'aide du bouton Locate. Si les fichiers sont dispersés sur le disque, vous devrez les localiser manuellement, une entrée à la fois. Une fois tous les chemins corrigés, cliquez sur Apply pour appliquer les modifications aux diapositives.
