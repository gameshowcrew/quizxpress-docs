# Problemas de conexión de los pulsadores

Si en la pantalla de bienvenida de QuizXpress Live se muestra un pulsador/mando parpadeante, esto indica que los pulsadores no están conectados correctamente. Para solucionarlo:

- Abra la aplicación Quiz Setup y compruebe que el tipo de pulsador seleccionado en la página ‘Buzzers’ coincide con los pulsadores que está utilizando realmente. Para los pulsadores Fleetwood Reply, asegúrese de configurar el canal correcto de la estación base y los ID de los mandos utilizados.

Como se indicó anteriormente, puede utilizar la aplicación Buzzer Test, disponible en el menú Inicio de QuizXpress, para comprobar si los pulsadores se han configurado correctamente. Esta aplicación también es útil para probar el alcance de sus pulsadores mientras se encuentra en el lugar de producción.

!!! note

    Windows 7 con la última revisión de los pulsadores inalámbricos BuzzTM requiere un procedimiento especial. Póngase en contacto con nosotros si necesita ayuda. En Windows 7, esta revisión de los pulsadores se reconoce como un concentrador USB, cuando debería utilizar un USB HID (como un ratón o un teclado). Debe configurarlo manualmente.*

## Uso de los mandos Fleetwood Reply Systems

Para evitar problemas, siempre debe probar todo el sistema antes de usarlo. En salas grandes, debe obtener los planos con antelación y decidir la ubicación del equipo. Mantenga el equipo Reply alejado de otros dispositivos de radio, altavoces y objetos metálicos grandes. El receptor debe colocarse lo más alto posible en la sala para poder establecer una línea de visión despejada con los mandos. Las paredes pueden afectar al alcance de los mandos. Tenga en cuenta la presencia de enrutadores Wi-Fi en la sala, ya que pueden afectar al alcance de los dispositivos Reply. Para más información sobre cómo configurar correctamente este sistema de mandos, consulte el manual de usuario de Fleetwood Reply Mini, disponible en la sección de descargas de nuestro sitio.

## Uso de pulsadores con cable Sony en Windows Vista

La siguiente revisión de los pulsadores **con cable** Sony no funciona en Windows Vista: SCEH-0005. Póngase en contacto con nosotros si necesita ayuda con estos pulsadores.

Todas las versiones inalámbricas de los pulsadores Sony funcionan con Windows. Para Windows 7 y superiores, puede ser necesario seguir un procedimiento especial, según la revisión de sus pulsadores. Consulte el Apéndice C para conocer el procedimiento de instalación de la última revisión de los pulsadores Sony en Windows Vista y Windows 7.

## Configuraciones grandes con pulsadores Sony

Si es necesario, los receptores pueden colocarse lejos del ordenador mediante cables USB activos. De este modo se pueden crear ‘islas’ de personas alrededor de un receptor, lo que permite que participen grupos más grandes. QuizXpress se ha probado con hasta 12 pulsadores Sony BuzzTM, pero en la práctica se han utilizado hasta 20 pulsadores. Con pulsadores con cable no hay limitación: se ha utilizado QuizXpress con hasta 120 pulsadores BuzzTM con cable en una infraestructura USB estándar.
