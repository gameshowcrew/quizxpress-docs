# La vista Analyzer

QuizXpress Director mostra la cronologia completa di tutte le domande giocate finora. Per ogni domanda è possibile vedere, per ogni giocatore, la risposta data, se era corretta o errata e quanti punti sono stati vinti o persi — uno strumento molto utile per il conduttore del quiz per dimostrare di avere sempre ragione!
