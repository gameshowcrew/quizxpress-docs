# Imágenes

## Insertar una imagen

Hay varios formatos de diapositiva que contienen marcadores de posición para una imagen:

| ![](../../assets/images/image185.webp){ width="288" loading=lazy } | ![](../../assets/images/image186.webp){ width="291" loading=lazy } |
|---------------------------------------------------------------------------|---------------------------------------------------------------------------------|

Para rellenar el marcador de posición con una imagen ‘real’, haga clic en el marcador de posición para seleccionarlo. Aparecerá entonces la pestaña contextual ‘PICTURE’ de la cinta de opciones:

![](../../assets/images/image187.webp){ width="605" loading=lazy }

Aquí puede hacer clic en ‘Select Picture’ para abrir un explorador de archivos y seleccionar del disco cualquiera de los formatos de archivo de imagen admitidos. Después, puede establecer las propiedades de la imagen y aplicar efectos o transformaciones estáticas. También puede arrastrar y soltar imágenes (y vídeos) directamente desde el Explorador de Windows sobre un marcador de posición de imagen (o sobre el fondo de la diapositiva para establecer la imagen de fondo).

Las imágenes también pueden tener una representación textual en forma de etiqueta. Puede establecer la etiqueta haciendo clic con el botón derecho en la imagen y seleccionando “Set Label” en el menú. Un ejemplo de uso de esta etiqueta es cuando se presenta una pregunta con imagen en la aplicación Smart Buzzer. Si decide no mostrar las imágenes en el teléfono (para el modo Wi-Fi, véase 4.2.1 y para el modo servidor véase 5.7.8.3), en su lugar se mostrará la etiqueta en el teléfono.

Como alternativa, puede hacer clic con el botón derecho en el marcador de posición para mostrar las opciones:

Aquí puede elegir insertar una imagen, un vídeo o un gráfico. Cuando tiene un diseño con varias imágenes, estas también pueden actuar como respuestas a la pregunta. En ese caso, puede establecer una imagen como respuesta correcta, indicar el orden de las respuestas con imagen en una pregunta de respuestas ordenadas, o establecer el porcentaje de acierto en una pregunta con varias respuestas con imagen.

También puede generar imágenes con IA. Para obtener más información, consulte 3.8.4.

Para obtener más información sobre otros ajustes de las imágenes, consulte [Propiedades de la imagen](../user-interface-overview/advanced-properties-grid.md#propiedades-de-las-imagenes).

## Recortar

Al hacer clic con el botón derecho en una imagen, verá un comando ‘Crop…’ en el menú contextual. Este abre el editor **Crop Image**, que le permite seleccionar la sección de la imagen que se presentará en su quiz:

Tenga en cuenta que la imagen *original* no se conserva tras el recorte, pero si no le gusta el resultado, siempre puede deshacer el recorte (dentro de la misma sesión).

## Texto a imagen

Esto es especialmente útil al crear preguntas de emparejamiento o diseñar cartones de Bingo: puede generar imágenes a partir de texto directamente en Studio. Haga clic con el botón derecho en la imagen y seleccione ‘Text to Image’ en el menú contextual:

![](../../assets/images/image190.webp){ width="591" loading=lazy }

Puede dar formato al texto con diversas opciones y, cuando termine, hacer clic en OK para reemplazar el marcador de posición de imagen de su diapositiva por la imagen generada:

![](../../assets/images/image191.webp){ loading=lazy }

## Aplicar efectos

Una de las propiedades de una imagen dentro de una pregunta es ‘Effect’. Cuando se elige un valor para esta propiedad en la cuadrícula de propiedades, el efecto elegido se aplica a la imagen durante la duración de la pregunta. Cuando comienza la pregunta, el efecto se aplica con toda su intensidad, por lo que puede ser muy difícil ver lo que muestra la imagen. A medida que el tiempo de la pregunta se acerca a 0, la imagen vuelve lentamente a su estado original. Los efectos se pueden previsualizar seleccionando la imagen y haciendo clic en ‘Preview’.
