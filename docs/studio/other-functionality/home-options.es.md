# HOME → Options

El cuadro de diálogo de opciones de QuizXpress Studio se encuentra en Tools->Options. El cuadro de diálogo tiene tres páginas:

|---------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| Preferencias de diapositiva                                                     | Selección de idioma                                                             |
| ![](../../assets/images/image296.webp){ width="265" loading=lazy } | ![](../../assets/images/image297.webp){ width="261" loading=lazy } |
| Datos del autor del quiz                                                        | Otros ajustes                                                                   |

***Pestaña Slide preferences:***

Esta página le permite establecer varias propiedades que se usan como valores predeterminados para cada nueva diapositiva que cree. Por ejemplo, si aquí establece ‘Answer time’ en 40 segundos, el tiempo de respuesta de cada nueva diapositiva será de 40 segundos. Nota: ¡los cambios realizados aquí se aplican solo a las diapositivas nuevas, no a las existentes!

***Pestaña Language:***

Esta pestaña le permite establecer el idioma de la interfaz de usuario de QuizXpress Studio y de todas las demás herramientas de QuizXpress (se guarda en el archivo de configuración de QuizXpress).

***Pestaña Author*:**

Aquí puede establecer sus datos personales, que se incrustarán en el quiz como autor original del quiz.

***Pestaña Other:***

Aquí puede establecer los umbrales para incrustar o vincular contenido de audio y vídeo, cambiar entre tres estilos de interfaz de usuario distintos y activar una opción para que el panel de miniaturas muestre información adicional, como el número de pregunta tal como se muestra en QuizXpress Live.
