# Starting a quiz

There are three ways to run your quiz:

1)  Start your quiz from within QuizXpress Studio (ribbon QUIZ SHOW -> Run Production)

2)  Start QuizXpress Live by right-clicking the quiz file in Windows Explorer (files with the extension *.qx*) and selecting ‘Play’ from the menu.

3)  Click the QuizXpress Live icon in the Start menu; you will then be asked to select a quiz file to load.
