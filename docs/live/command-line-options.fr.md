# Options de ligne de commande

Les options de ligne de commande suivantes sont disponibles au démarrage de QuizXpress Live :

| Ligne de commande                | Explication                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \-*nosnapshot*                   | Pour permettre la récupération, QuizXpress Live conserve toutes sortes de données générées pendant un quiz (choix des équipes, scores, question en cours, etc.). Cet ensemble de données s’appelle un « snapshot ». Si un quiz est interrompu pour une raison imprévue, QuizXpress Live relit toutes les données du snapshot de ce quiz lors de son redémarrage, afin que le quiz puisse reprendre là où il a été interrompu. L’option de ligne de commande –nosnapshot n’écrit pas de fichier snapshot. |
| \-*quickstart*                   | Ignore les écrans de bienvenue et de compte à rebours                                                                                                                                                                                                                                                                                                                                                                                                                       |
| *-windowed*                      | Démarre l’application dans une fenêtre normale afin de pouvoir continuer à utiliser d’autres applications                                                                                                                                                                                                                                                                                                                                                                   |
| *-noborder*                      | À utiliser avec –windowed ; fonctionne en mode fenêtré mais sans barre de titre ni bordure, de sorte que l’affichage ressemble au mode plein écran exclusif alors qu’il s’agit en réalité d’un mode fenêtré normal. Vous pouvez aussi activer ce mode en appuyant sur la touche M pendant le show.                                                                                                                                                                          |
| \-*showfps*                      | Affiche le nombre d’images par seconde (pour mesurer les performances)                                                                                                                                                                                                                                                                                                                                                                                                      |
| \-*singleuser*                   | Démarre QuizXpress Live en mode mono-utilisateur ; cette option est utilisée lorsque le show est lancé depuis QuizXpress Solo                                                                                                                                                                                                                                                                                                                                               |
| \-*scorefile=\<file>*           | Nom du fichier de scores, qui stocke toutes les données utiles du quiz (choix par équipe, scores par équipe, informations de temps, etc.)                                                                                                                                                                                                                                                                                                                                   |
| *-startwith=\<0..n>*            | Démarre le quiz à la question indiquée, par ex. –startwith=5 pour démarrer à la 5e question                                                                                                                                                                                                                                                                                                                                                                                 |
| *-autorun*                       | Simule un public                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| *-autoexit*                      | Quitte automatiquement l’application après l’écran des scores (à utiliser avec *–autorun*)                                                                                                                                                                                                                                                                                                                                                                                  |
| *-screen=\<devicename>*         | Démarre l’application sur le périphérique de sortie indiqué                                                                                                                                                                                                                                                                                                                                                                                                                 |
| *-settingsfile=\<settingsfile>* | Charge les paramètres depuis le fichier de paramètres indiqué. Cela permet de passer facilement d’une configuration à une autre (comme des compositions d’équipes)                                                                                                                                                                                                                                                                                                          |
| *-preload*                       | Option (avancée) pour précharger/pré-calculer toutes les diapositives au démarrage. Nécessaire uniquement si vous constatez des ralentissements pendant votre quiz et que votre PC dispose de suffisamment de mémoire                                                                                                                                                                                                                                                       |

Par exemple, pour démarrer QuizXpress Live en mode fenêtré plein écran, vous pouvez utiliser la commande suivante (à lancer depuis un fichier batch ou une fenêtre de commande) :

“Quiz Show.exe” –windowed –noborder c:\myquizzes\quiz1.qx
