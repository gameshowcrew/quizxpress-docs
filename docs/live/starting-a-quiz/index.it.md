# Avviare un quiz

Esistono tre modi per eseguire il quiz:

1)  Avviare il quiz da QuizXpress Studio (barra multifunzione QUIZ SHOW -> Run Production)

2)  Avviare QuizXpress Live facendo clic con il pulsante destro del mouse sul file del quiz in Esplora risorse di Windows (file con estensione *.qx*) e selezionando ‘Play’ dal menu.

3)  Fare clic sull’icona di QuizXpress Live nel menu Start; verrà richiesto di selezionare un file di quiz da caricare.

All’interno di QuizXpress Live sono presenti diverse schermate, descritte nelle sezioni seguenti.
