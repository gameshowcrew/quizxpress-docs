# Audience Response

Este es un tipo de pregunta que se puede usar para sondear las opiniones del público. Las respuestas dadas a una pregunta de tipo audience response se registran, pero no tienen ningún impacto en las puntuaciones. Después de una pregunta de audience response, puede mostrar un gráfico con la tecla ‘C’ para ver la distribución de las respuestas dadas. Como alternativa, también puede insertar un Chart en la diapositiva que muestre el número de respuestas de cada respuesta ‘en tiempo real’ durante la cuenta atrás o, si lo prefiere, al final de la cuenta atrás.
