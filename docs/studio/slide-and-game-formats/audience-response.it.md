# Audience Response

Questo è un tipo di domanda che può essere usato per sondare le opinioni del pubblico. Le risposte date a una domanda di tipo audience response vengono registrate ma non hanno alcun effetto sui punteggi. Dopo una domanda audience response, è possibile mostrare un grafico con il tasto "C" per visualizzare la distribuzione delle risposte date. In alternativa, è possibile inserire un Chart nella diapositiva che mostra il numero di risposte per ciascuna risposta "in tempo reale" durante il conto alla rovescia oppure, in alternativa, al termine del conto alla rovescia.
