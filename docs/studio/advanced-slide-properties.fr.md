# Propriétés avancées de la diapositive

Dans cette boîte de dialogue, vous pouvez configurer quelques propriétés plus avancées pour la question en cours :

![](../assets/images/image280.webp){ width="177" loading=lazy }

**Show correct answer mode**

Paramètre indiquant si la bonne réponse doit être affichée une fois la question terminée. Par défaut, le paramètre défini dans QuizXpress Setup est utilisé.

**Countdown timer mode**

Paramètre indiquant comment le compte à rebours doit se comporter pour cette question. Par défaut, le paramètre défini dans QuizXpress Setup est utilisé.

**Lock-out mode for fastest finger question**

Normalement, un joueur qui donne une mauvaise réponse est exclu de la question. Ce paramètre permet de modifier ce comportement afin que les joueurs puissent réessayer avec une autre réponse. Disponible uniquement si la diapositive est une diapositive de type fastest finger.

**Shuffle mode**

QuizXpress permet de mélanger les questions d’un quiz lorsqu’il est joué dans QuizXpress Live! Comme vous pouvez vouloir conserver certaines diapositives à leur place (par exemple, les Billboards annonçant les manches) ou les garder associées à la diapositive précédente ou suivante (par exemple, lorsque les informations d’une diapositive s’appliquent à la suivante ou à la précédente, ou pour les mises), ce paramètre prend en charge précisément ces cas. Il indique ce qui doit arriver à la diapositive lorsque QuizXpress Live sélectionne un sous-ensemble mélangé parmi les questions du fichier de quiz (configuré dans Quiz Setup, où vous pouvez choisir de rendre aléatoire un pourcentage des questions). Ce paramètre est utile lorsque vous souhaitez jouer plusieurs fois le même quiz, par exemple lors d’un salon professionnel. Remarque : ces options sont également accessibles depuis la grille des propriétés (au niveau de la diapositive).
