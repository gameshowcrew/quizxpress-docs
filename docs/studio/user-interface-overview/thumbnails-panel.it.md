# Pannello delle miniature

Questo pannello offre una panoramica immediata di tutte le domande. È possibile passare a una domanda facendo clic sulla sua miniatura e spostarla trascinando la miniatura in una nuova posizione e rilasciandola lì. Il pannello delle miniature consente di selezionare più domande facendo clic su una miniatura tenendo premuto il tasto *Ctrl*, oppure usando la scorciatoia *Ctrl+A* per selezionare tutte le domande del quiz. È inoltre possibile selezionare un intervallo di domande facendo clic sulla prima miniatura dell’intervallo e poi sull’ultima, tenendo premuto il tasto *Maiusc*. Quando sono selezionate più domande, è possibile modificare le proprietà di tutte le domande contemporaneamente tramite la griglia delle proprietà (se la griglia delle proprietà non è visibile sul lato destro di QuizXpress Studio, fare clic su VIEW nella barra multifunzione e spuntare ‘Properties’). Questo consente anche di eliminare più diapositive del quiz in una sola volta.

Il pannello delle miniature dispone di un menu contestuale. Fare clic con il tasto destro sul pannello delle miniature per aprire questo menu:

![](../../assets/images/image14.webp){ width="228" loading=lazy }

Da qui è possibile copiare/incollare/eliminare una o più domande selezionate, selezionare tutte le diapositive, selezionare tutte le domande (i banner sono esclusi dalla selezione quando si usa ‘Select Questions’) o selezionare tutte le diapositive di un tipo specifico. Si noti che è anche possibile copiare e incollare diapositive del quiz tra due istanze di Studio, il che consente di creare “librerie” di domande da cui costruire i propri quiz specifici.

Nella finestra di dialogo Options (apribile dalla scheda HOME > pulsante Options) è possibile abilitare il pannello delle miniature per mostrare informazioni aggiuntive per ogni diapositiva, come l’effettivo numero della domanda (come mostrato in QuizXpress Live). Questa opzione si trova nella scheda ‘Other’ della finestra di dialogo Options:

**Comprimere/espandere i round**

È possibile comprimere o espandere l’elenco delle miniature a livello di round per vedere rapidamente la struttura del quiz caricato. Ciò è utile quando un quiz contiene molte diapositive e round. In cima al pannello si trova una barra degli strumenti con uno strumento **\[-\]** **Collapse All** / **\[+\]** **Expand All**. Facendo clic su **Collapse All** l’elenco viene compresso a livello di round:

![](../../assets/images/image15.webp){ width="602" loading=lazy }

Dopodiché si vedrà solo l’inizio di ciascun round del quiz (un round inizia alla prima diapositiva dopo una o più diapositive di fine round):

![](../../assets/images/image16.webp){ width="187" loading=lazy }

Facendo clic su \[+\] a sinistra della diapositiva del round, le diapositive di quel round riappaiono. Nella barra degli strumenti è possibile fare clic su \[+\] per espandere tutti i round. Se il quiz non contiene round, accanto alle diapositive non compariranno \[+\] né \[-\] e il controllo della barra degli strumenti sarà disabilitato.

**Zoom delle miniature**

Se si preferiscono miniature leggermente più grandi, è possibile ingrandire/ridurre con gli strumenti di zoom:

![](../../assets/images/image17.webp){ width="591" loading=lazy }

*Si noti che quando si esegue lo zoom, l’elenco delle miniature viene ridisegnato completamente alla nuova dimensione (l’ingrandimento richiede più dettaglio, e quindi un nuovo rendering), il che può richiedere un po’ di tempo a seconda delle dimensioni del quiz.*
