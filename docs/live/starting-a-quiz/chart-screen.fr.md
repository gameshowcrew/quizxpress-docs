# Écran du graphique

Une fois une question terminée, appuyer sur « C » affiche un graphique des réponses choisies, indiquant le nombre de personnes ayant choisi chaque réponse.

![](../../assets/images/image433.webp){ width="605" loading=lazy }

Si le public est réparti en groupes, vous pouvez appuyer sur « G » pour afficher un graphique des scores par groupe pour la question en cours. Notez que l’apparence du graphique peut être entièrement personnalisée grâce au [skinning](../../advanced/skinning/index.md).
