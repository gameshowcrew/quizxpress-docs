# Lucky Marbles

Les joueurs peuvent marquer des points dans cette variante palpitante du jeu de billes Plinko classique. Après avoir choisi le casier dans lequel ils pensent que la bille va tomber — et, en option, après avoir voté ou s'être affrontés pour sélectionner le point de lâcher — la bille tombe et rebondit jusqu'en bas du plateau, guidée par une simulation physique réaliste. Avec plusieurs dispositions de plateau et un *vortex* rotatif optionnel capable de renvoyer la bille à une position de départ aléatoire, chaque manche est pleine de suspense et de surprises.

Le jeu propose les options de configuration suivantes :

![](../../assets/images/image167.webp){ width="331" loading=lazy }

- Number of rounds : le nombre de manches jouées

- Allow players to vote on where to drop the marble : si cette option est activée, le jeu commence par un vote du public sur l'endroit où la bille est lâchée. Le public peut changer son choix jusqu'à ce que l'animateur décide de lâcher la bille

- Random initial spin : l'importance de la rotation de la bille lorsqu'elle tombe

- Marble restitution : le degré de rebond de la bille

- Allow vortex pin : affiche un vortex au centre qui aspire la bille et la renvoie en haut

- Dans les onglets des manches, vous pouvez configurer les paramètres suivants pour chaque manche :

  - Number of buckets : nombre de casiers cibles en bas de l'écran

  - Points : points à gagner pour chaque casier

  - Peg board layout : choisissez parmi plusieurs dispositions disponibles

  - Drop zone : indique l'endroit d'où la bille est lâchée (actif uniquement lorsque le paramètre *Allow players to vote on where to drop the marble* n'est pas activé).

L'onglet Text settings permet de modifier le texte affiché à l'écran ainsi que sur le téléphone mobile. Dans l'onglet Audio, vous pouvez sélectionner la musique jouée pendant le jeu.
