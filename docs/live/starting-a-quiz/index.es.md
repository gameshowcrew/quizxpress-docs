# Iniciar un quiz

Hay tres maneras de ejecutar su quiz:

1)  Inicie su quiz desde QuizXpress Studio (cinta QUIZ SHOW -> Run Production)

2)  Inicie QuizXpress Live haciendo clic con el botón derecho en el archivo del quiz en el Explorador de Windows (archivos con la extensión *.qx*) y seleccionando ‘Play’ en el menú.

3)  Haga clic en el icono de QuizXpress Live en el menú Inicio; a continuación se le pedirá que seleccione un archivo de quiz para cargar.
