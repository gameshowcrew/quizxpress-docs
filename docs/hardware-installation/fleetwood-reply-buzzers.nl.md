# Fleetwood Reply-buzzers

Ga als volgt te werk om Fleetwood Reply-buzzers te installeren en QuizXpress te configureren voor gebruik met de buzzers.

1.  Zet de pc/laptop aan

2.  Plaats de cd met de Reply-stuurprogramma's in de cd/dvd-speler

3.  Steek de Reply USB-ontvanger in een USB-poort

4.  Er verschijnt een venster dat meldt dat nieuwe hardware is gevonden. Geef aan dat Windows de stuurprogramma's automatisch moet zoeken.

5.  Windows installeert de stuurprogramma's automatisch.

6.  Nu kunnen we QuizXpress configureren voor gebruik met de Reply-buzzers. Start Quiz Setup (zie ook [Meerkeuze-buzzersystemen](../setup/configuring-your-hardware-the-buzzers-tab-page.md#meerkeuzebuzzersystemen)).

7.  Selecteer op het tabblad ‘Buzzers’ van Quiz Setup Fleetwood Reply CRS 940/941.

8.  Kies nu het kanaal dat de Reply-ontvanger gebruikt om naar de Reply-keypads (buzzers) te luisteren. Om het juiste kanaal te kiezen, kijkt u op de achterkant van een van de keypads die u gaat gebruiken — daar staat het kanaal vermeld waarop het keypad werkt (let op: alle gebruikte buzzers moeten op dit kanaal werken).

9.  Sluit nu Quiz Setup en start QuizXpress Buzzer Test, te vinden in het Start-menu onder QuizXpress. Wanneer u op een van de buzzers drukt, moet het bijbehorende genummerde vak op het scherm oplichten en het gekozen antwoord tonen.

10. Als de voorgaande stappen met succes zijn uitgevoerd, is QuizXpress Live klaar voor gebruik met Reply-buzzers.

!!! note

    Fleetwood Reply-buzzers werken op lithiumknoopcellen van het type CR2032. Lithiumknoopcellen CR2032 van Sony worden aanbevolen.
