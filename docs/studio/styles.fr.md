!!! note

    le style ‘Just Text’ permet de ‘superposer’ du texte à une image d’arrière-plan personnalisée que vous fournissez, par exemple lorsque vous souhaitez utiliser une mise en page conçue dans PowerPoint.*

Vous pouvez modifier le style de la diapositive en cliquant sur un style dans la galerie de styles de l’onglet de ruban DESIGN, ou en sélectionnant le style de votre choix dans la grille de propriétés (nom de la propriété : Style). La modification est immédiatement visible.

Vous pouvez organiser votre espace de travail en filtrant les styles (et les arrière-plans) que vous n’utilisez pas. Vous accédez au filtre via le bouton de lanceur de boîte de dialogue (‘dialog launcher’) de la section Style du ruban Design dans QuizXpress Studio.

![](../assets/images/image274.webp){ width="549" loading=lazy }

De nouveaux styles personnalisés peuvent être conçus dans un outil avancé nommé Style Maker. Vous trouverez cet outil dans le menu Démarrer de Windows, sous QuizXpress. Le système de styles repose sur ce que l’on appelle des images 9-patch. Dans ce système, une image de base est découpée en 9 sections (coins et parties centrales) et 8 blocs répétables qui ‘collent’ ces sections ensemble lorsque le panneau est étiré.
