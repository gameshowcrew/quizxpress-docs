# HOME → Alignment & Size, Order

![](../../assets/images/image292.webp){ width="211" loading=lazy }

La sección de alineación y tamaño dispone de varias herramientas que le permiten alinear, posicionar y dimensionar varios elementos de una diapositiva. Para ello, seleccione varios elementos de la diapositiva (por ejemplo, respuestas, imágenes o una combinación de ambos) haciendo clic en ellos uno por uno mientras mantiene pulsada la tecla Ctrl. El primer elemento seleccionado tiene tiradores de redimensionamiento blancos a su alrededor, mientras que los demás elementos seleccionados tienen tiradores de redimensionamiento negros.

Ahora puede elegir una de las siguientes opciones:

- Position: alinear a la izquierda, a la derecha, arriba, abajo, centrado vertical, centrado horizontal

- Size: igualar el ancho, igualar el alto, igualar el ancho y el alto, reducir el tamaño, aumentar el tamaño

!!! tip
    Para alinear un solo elemento, basta con arrastrarlo: las [guías inteligentes](../user-interface-overview/design-area.md#guias-inteligentes) indican cuándo está alineado con otros elementos o con la diapositiva, y se ajusta a su posición.

![](../../assets/images/image293.webp){ width="108" loading=lazy }El botón Order le permite ordenar varios elementos superpuestos en el orden z (profundidad). Puede traer un elemento al frente, enviarlo al fondo, adelantarlo un nivel o retrasarlo un nivel.
