# Gráfico en tiempo real

Puede insertar en una diapositiva un gráfico de respuestas en tiempo real. Mientras el reloj cuenta atrás, el gráfico muestra una representación en directo de todas las respuestas dadas por el público.

![](../../assets/images/image216.webp){ width="163" loading=lazy }Hay dos maneras de añadir un gráfico a una diapositiva:

1)  Elija una diapositiva con un marcador de posición de imagen/vídeo. Haga clic con el botón derecho en el marcador de posición y elija Select Chart

2)  Seleccione la pestaña INSERT de la cinta de opciones y haga clic en el botón ‘Chart’ ![](../../assets/images/image217.webp){ width="228" loading=lazy }

Una vez insertado el gráfico, la pestaña contextual CHART de la cinta de opciones se hace visible para configurar las distintas opciones.

![](../../assets/images/image218.webp){ width="605" loading=lazy }

La pestaña tiene las siguientes opciones:

- Delete: elimina el gráfico de la diapositiva

- Type: elija uno de los siguientes tipos de gráfico: Bar, Column, Pie, Donut

- Set colors: Chart color (sección exterior del gráfico), Area color (sección interior del gráfico), Title color (color del texto del título situado encima del gráfico)

- Font buttons: establecen la fuente del título y de las etiquetas.

- Legend: muestra una leyenda junto al gráfico

- Shadow: añade una sombra proyectada al gráfico

- Enable 3D: convierte el gráfico en 3D. Opcionalmente, puede establecer la profundidad y el ángulo del gráfico 3D

- Mode: elija si desea mostrar en el gráfico la distribución de las respuestas o la distribución de correctas/incorrectas/sin responder

- Data visibility: indique si desea ver los resultados en tiempo real o si los resultados deben mostrarse una vez que todos los jugadores hayan respondido.

En el panel de propiedades puede configurar otros aspectos del gráfico, como el texto y la alineación del título, el color de las etiquetas (una etiqueta contiene el número de respuestas de un segmento) y el color de los ejes.

![](../../assets/images/image219.webp){ width="465" loading=lazy }

Puede establecer el color de fondo del elemento de gráfico como transparente para crear diseños más interesantes con gráficos. Esto le permite, por ejemplo, crear diapositivas de respuesta del público en las que el gráfico se superpone a las respuestas.
