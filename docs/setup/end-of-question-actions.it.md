# Azioni di fine domanda

In questa scheda è possibile definire le azioni che vengono eseguite (e in quale ordine) al termine di una domanda (quando sono state ricevute tutte le risposte o è stata data una risposta corretta a una domanda aperta).

![](../assets/images/image345.webp){ width="604" loading=lazy }

Normalmente, se le azioni non vengono sostituite, viene eseguita una sequenza di azioni standard, ad esempio l'evidenziazione della risposta corretta e la visualizzazione delle statistiche nel pannello informativo, ecc. Quando si sostituiscono le azioni standard, le azioni configurate vengono eseguite una alla volta nell'ordine impostato ogni volta che si preme il pulsante OK sul telecomando del Quizmaster, si preme la barra spaziatrice in Live o si fa clic sul pulsante ‘Next’ in Director.

Sono disponibili le seguenti azioni da configurare:

**Show correct answer**

Questa azione evidenzia la risposta corretta sulla diapositiva e mostra un indicatore — di solito un segno di spunta, anche se può variare in base allo stile della diapositiva. È possibile saltare questa azione se si desidera mostrare la risposta corretta in un altro modo (ad esempio, con una forma o un elemento di testo sulla diapositiva).

**Show correct, incorrect, not answered bar**

Mostra il grafico delle risposte nella barra informativa superiore.

![](../assets/images/image346.webp){ width="457" loading=lazy }

**Show intermediate scores**

Apre la classifica (panoramica dei primi 20, normalmente aperta con il tasto ‘S’)

**Show response chart**

Mostra la schermata con il grafico a barre delle risposte.

**Go to next slide**

Passa alla diapositiva successiva; questa azione è sempre attiva e viene sempre eseguita per ultima.
