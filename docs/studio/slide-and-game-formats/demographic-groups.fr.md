# Demographic groups

QuizXpress offre plusieurs façons de regrouper les joueurs afin qu'ils puissent s'affronter en équipes (par exemple : les garçons contre les filles). Le type de diapositive « demographic groups » vous permet de regrouper les joueurs « à la volée » pendant un quiz.

Lorsque vous choisissez ce type de question, une fenêtre s'affiche dans laquelle vous pouvez saisir le nom du groupe/de l'équipe. Lorsque la diapositive est affichée pendant un quiz, les keypads sur lesquels on appuie pendant l'affichage de la diapositive demographic sont enregistrés pour ce groupe précis.

![](../../assets/images/image60.webp){ width="318" loading=lazy }

Sur la diapositive, nous recommandons d'afficher un texte demandant aux membres du groupe concerné d'appuyer sur leur buzzer ou leur keypad (« tous les garçons, appuyez sur votre keypad »).

Vous pouvez aussi répartir les joueurs en groupes avant un quiz dans QuizXpress Setup. Pour cela, veuillez consulter la section [QuizXpress Setup : regroupement des keypads](../../setup/setting-up-teams-the-teams-tab-page.md#regrouper-les-keypads).

Lorsque vous jouez avec des téléphones mobiles (avec l'application Smart Buzzer ou le site web buzzerpad), vous pouvez également jouer en groupes. Pour cela, veuillez consulter la section [Jouer en groupes](../../setup/setting-up-mobile-keypad-support.md#jouer-en-groupes).
