# Chrono Challenge

Le Chrono Challenge est un jeu de précision. Le principe est de compter le temps et d'appuyer sur le buzzer le plus près possible d'un certain nombre de secondes.

Options de configuration disponibles :

![](../../assets/images/image158.webp){ width="257" loading=lazy }

- Goal time est le temps, en secondes, jusqu'auquel les joueurs comptent.

- Stop counting seconds after goal time. Le temps de vote se poursuit pendant ce nombre de secondes après que le temps cible a été atteint. Par exemple, si le temps cible est de 10 secondes et que ‘stop counting seconds after goal time’ vaut cinq, le temps de vote total est de 15 secondes.

- Il existe trois façons d'attribuer les points :

  - Number of seconds. Les points sont attribués selon le nombre de secondes au bout duquel un joueur a appuyé. Plus le joueur est proche, plus il gagne de points.

  - Custom. L'animateur peut configurer les points gagnés pour chaque durée.

  - Match Mode. Les joueurs sont classés selon leur proximité du temps cible. Plus le rang d'un joueur est élevé, plus il obtient de points.

- Bonus closest player : le joueur le plus proche du temps cible gagne des points supplémentaires

- Background image : définit l'image d'arrière-plan du jeu.

- Background video : définit la vidéo d'arrière-plan du jeu.

- L'animateur peut choisir d'utiliser uniquement l'image, uniquement la vidéo, ou les deux : l'image (avant le décompte) et la vidéo (après le décompte)

- Voting music définit la musique jouée pendant le vote.

- Use custom texts. Modifie les messages par défaut affichés pendant le jeu.

  - Get your internal clock ready! : le texte affiché au début du jeu.

  - Count to (0) in : le texte affiché lorsque les joueurs sont sur le point de commencer à compter.

  - Count! : le texte affiché lorsque les joueurs commencent à compter.

  - We stopped the clock! Let’s see the results! : le texte affiché lorsque l'horloge a été arrêtée et que les temps de réponse des joueurs vont être évalués.

![](../../assets/images/image159.webp){ width="213" loading=lazy }Au début du jeu, les joueurs sont invités à se préparer à compter !

![](../../assets/images/image160.webp){ width="209" loading=lazy }![](../../assets/images/image161.webp){ loading=lazy }

Après un court compte à rebours affiché à l'écran (3-2-1), les joueurs doivent continuer à compter et appuyer sur le buzzer lorsque le temps indiqué est écoulé. Une fois écoulé le nombre de secondes défini dans les paramètres, l'horloge est arrêtée.

![](../../assets/images/image162.webp){ loading=lazy }

Les joueurs sont évalués selon l'écart entre leur réponse et le temps cible (en fonction du mode de jeu choisi).
