# Skinning

The look of the QuizXpress quiz player, QuizXpress Live, can be completely changed to your preferences or house style by creating a custom ‘skin’. QuizXpress comes with five built-in skins, which can be selected in Quiz Setup on the Screens tab (Appearance section).

For more information about skinning [click here to open the detailed Skinning documentation.](https://quizxpress.com/files/Skinning%20QuizXpress%20Live.pdf)
