# Gagner de l'argent en vendant des billets

Vous pouvez utiliser des billets électroniques avec l'application Smart Buzzer et le site web buzzerpad pour générer des revenus lors de l'organisation de quiz (en ligne). La vente de billets numériques à votre public relève cependant de votre responsabilité. Plusieurs plugins de boutique en ligne pour CMS permettent de vendre des billets sur votre boutique, ou vous pouvez utiliser des plateformes de billetterie en ligne telles que <https://www.tickettailor.com/>. Pour QuizXpress, il vous suffit d'un simple fichier texte brut contenant tous les codes de billets (un billet par ligne, insensible à la casse). Ce fichier texte doit s'appeler *tickets.txt* et doit être enregistré dans le même dossier que votre quiz. Lorsque vous lancez votre quiz, les billets sont envoyés au serveur et, lorsqu'un joueur se connecte à votre quiz, il/elle est invité(e) à saisir un code de billet qui doit correspondre à une ligne de *tickets.txt*. Chaque billet ne peut être utilisé qu'une seule fois à la fois, afin que les gens ne puissent pas partager leurs billets. Vous pouvez actualiser les billets même pendant que le quiz est en cours. Pour cela, ouvrez l'écran Director sur votre PC, activez l'onglet Mobile et repérez le bouton ‘Refresh Tickets’.
