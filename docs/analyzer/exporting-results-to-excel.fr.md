# Exporter les résultats vers Excel

Les résultats peuvent être exportés vers Excel en appelant la commande ‘Export to Excel’ du menu ‘File’. Le fichier Excel obtenu comportera au maximum quatre feuilles de calcul :

- Score : affiche le classement des scores

- Response : affiche toutes les questions, avec, pour chaque question, les réponses, les points obtenus et le total des points par équipe

- Demographic Scores (si des groupes démographiques sont présents) : affiche le classement des scores par groupe

- Demographic Responses : affiche, pour chaque question, toutes les réponses par groupe et par réponse.
