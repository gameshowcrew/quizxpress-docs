# Buzzers Fleetwood Reply

Veuillez procéder comme suit pour installer les buzzers Fleetwood Reply et configurer QuizXpress pour qu'il fonctionne avec ces buzzers.

1.  Allumez le PC/portable

2.  Insérez le CD des pilotes Reply dans le lecteur CD/DVD-ROM

3.  Branchez le récepteur USB Reply sur un port USB

4.  Une fenêtre apparaît pour indiquer qu'un nouveau matériel a été détecté. Indiquez que Windows doit rechercher automatiquement les pilotes.

5.  Windows installera les pilotes automatiquement.

6.  Nous pouvons maintenant configurer QuizXpress pour utiliser les buzzers Reply. Démarrez Quiz Setup (voir aussi [Systèmes de buzzers à choix multiples](../setup/configuring-your-hardware-the-buzzers-tab-page.md#systemes-de-buzzers-a-choix-multiples)).

7.  Sur la page de l'onglet ‘Buzzers’ de Quiz Setup, sélectionnez Fleetwood Reply CRS 940/941.

8.  Choisissez maintenant le canal que le récepteur Reply utilise pour écouter les claviers Reply (buzzers). Pour sélectionner le bon canal, regardez à l'arrière d'un des claviers qui seront utilisés — le canal sur lequel il fonctionne y est indiqué (remarque : tous les buzzers utilisés doivent fonctionner sur ce canal).

9.  Fermez maintenant Quiz Setup et démarrez QuizXpress Buzzer Test, que vous trouverez dans le menu Démarrer sous QuizXpress. Lorsque vous appuyez sur un des buzzers, la case numérotée correspondante doit s'allumer à l'écran et afficher la réponse choisie.

10. Lorsque les étapes précédentes ont été exécutées avec succès, QuizXpress Live est prêt à fonctionner avec les buzzers Reply.

!!! note

    Les buzzers Fleetwood Reply fonctionnent avec des piles bouton au lithium de type CR2032. Les piles bouton au lithium Sony CR2032 sont recommandées.
