# Pregunta de emparejamiento

En una Pairing Question, los jugadores asocian etiquetas de texto con imágenes (por ejemplo, países con banderas o marcas con logotipos). En el pulsador móvil se ve de la siguiente manera:

| ![](../../assets/images/image46.webp){ width="159" loading=lazy } | ![](../../assets/images/image47.webp){ width="161" loading=lazy } | ![](../../assets/images/image48.webp){ width="160" loading=lazy } |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------|

Para crear este tipo de pregunta, seleccione una plantilla con al menos *tres* marcadores de posición de imagen y establezca el tipo de pregunta en 'Pairing Question'. A continuación, asigne las etiquetas adecuadas a cada imagen:

![](../../assets/images/image49.webp){ loading=lazy }

También puede utilizar el Quiz Wizard.

![](../../assets/images/image50.webp){ width="390" loading=lazy }

Después, rellene las etiquetas y seleccione las imágenes correspondientes:

![](../../assets/images/image51.webp){ width="390" loading=lazy }

Haga clic en **Next** y complete el asistente para crear la pregunta de emparejamiento.

## Preguntas de zona activa

Con este tipo de pregunta, el jugador debe marcar un punto (o varios puntos) en una imagen, y la respuesta es correcta cuando ese punto (o puntos) cae dentro de la región marcada como correcta por el diseñador del quiz.

Por ejemplo, si queremos que los jugadores encuentren Francia en un mapa, elegimos una plantilla con una sola imagen:

![](../../assets/images/image52.webp){ width="602" loading=lazy }

Establezca el tipo de entrada en 'Hotspot':

![](../../assets/images/image53.webp){ width="251" loading=lazy }

A continuación, coloque la imagen de un mapa en el marcador de posición de imagen y edite las regiones de zona activa con el **Hotspot Editor** (haga clic con el botón derecho en la imagen y seleccione **Edit Hotspots**):

![](../../assets/images/image54.webp){ loading=lazy }Ahora marque el área que constituye la respuesta correcta (aquí en rojo). Las formas de región admitidas incluyen áreas rectangulares, elípticas y de forma libre.

Se pueden definir varias regiones correctas:![](../../assets/images/image55.webp){ width="602" loading=lazy }

Con varias regiones, en la aplicación Smart Buzzer se ve así:

![](../../assets/images/image56.webp){ width="185" loading=lazy }

En la pantalla del quiz, la imagen revelará la respuesta correcta de la siguiente manera:

![](../../assets/images/image57.webp){ loading=lazy }

!!! note

    cuando se utilizan varias regiones y el usuario marca más puntos que regiones correctas, su puntuación disminuirá (para evitar que se adivine al azar con muchos marcadores).
