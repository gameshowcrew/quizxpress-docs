# Menú Backstage

Al hacer clic en la pestaña FILE o al pulsar F1, aparece el menú backstage. ![](../../assets/images/image12.webp){ width="501" loading=lazy }

Desde aquí accede a las funciones globales de la aplicación, cuyos detalles se describen en varias otras pestañas:

| **New**                              | Crear un nuevo quiz y seleccionar la relación de aspecto de las diapositivas            |
|--------------------------------------|------------------------------------------------------------------------|
| **Recent**                           | Abrir archivos recientes y de ejemplo                                  |
| **Import**                           | Importar preguntas desde Excel o desde otro archivo de quiz            |
| **Export questions to Excel or PDF** | Exportar preguntas a Excel o PDF                                       |
| **Print**                            | Imprimir las diapositivas de su quiz                                   |
| **Info**                             | Acceder al archivo de ayuda, a varios recursos en línea y gestionar su licencia |
