# La vista Round scores

Se il quiz utilizza i round (ovvero se è presente una diapositiva di fine round da qualche parte), la scheda ‘Round scores’ sarà visibile in Director.

La scheda Round scores mostra il punteggio totale per round. È possibile mostrare/nascondere i punteggi di ciascun round espandendo/comprimendo i nodi dei round.
