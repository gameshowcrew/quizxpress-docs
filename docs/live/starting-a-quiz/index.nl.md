# Een quiz starten

Er zijn drie manieren om uw quiz te draaien:

1)  Start uw quiz vanuit QuizXpress Studio (lint QUIZ SHOW -> Start Productie)

2)  Start QuizXpress Live door met de rechtermuisknop op het quizbestand in Windows Verkenner te klikken (bestanden met de extensie *.qx*) en ‘Afspelen’ in het menu te kiezen.

3)  Klik op het QuizXpress Live-pictogram in het Startmenu; u wordt dan gevraagd een quizbestand te selecteren om te laden.

In QuizXpress Live worden verschillende schermen gebruikt, die in de volgende paragrafen worden beschreven.
