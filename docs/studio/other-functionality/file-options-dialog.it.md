# Finestra di dialogo FILE → Options

L'accesso a questa finestra di dialogo si trova nel menu backstage FILE:

![](../../assets/images/image298.webp){ width="605" loading=lazy }

La scheda ‘Target device’ di questa finestra di dialogo consente di impostare il rapporto dello schermo di destinazione e la qualità dell'immagine del quiz. L'opzione *ratio* configura il rapporto larghezza/altezza delle diapositive in modo che corrisponda al dispositivo su cui verrà presentato il quiz:

La sezione dei dettagli ‘Quiz Author’ mostra la cronologia del file del quiz: chi lo ha creato originariamente e chi lo ha modificato per ultimo. Questi dettagli vengono utilizzati, ad esempio, quando un file di quiz è scaduto e all'utente finale vengono presentati i dati di contatto per ottenere un aggiornamento recente. I propri dati di autore del quiz possono essere inseriti nella finestra di dialogo ‘Options’ (disponibile nella barra multifunzione HOME).

Infine, la scheda ‘Advanced’ consente di impostare proprietà avanzate per il quiz. ‘QX3 compatible video rendering’ significa che il sistema utilizza il sistema video presente in QX3. Potrebbe essere utile perché può offrire prestazioni migliori su sistemi di fascia bassa come i netbook. Lo svantaggio è che supporta solo il formato AVI e non è possibile utilizzare effetti video. Questa impostazione si applica all'intero quiz, quindi fare attenzione a non utilizzare altri formati video nel quiz (in caso contrario, all'avvio di QuizXpress Live viene generato un avviso). *Raramente sarà necessario attivare questa funzione.*
