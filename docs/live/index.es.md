# Dirigir el show con QuizXpress Live

Para dirigir un show con QuizXpress, puede utilizar dispositivos físicos como los mandos o pulsadores de QuizXpress, o bien teléfonos móviles para que los jugadores participen a través de una red Wi-Fi local o de internet. Si juega por internet con jugadores en ubicaciones remotas, puede transmitir el quiz mediante un servicio de streaming, como YouTube o Zoom. Puede obtener más información sobre la transmisión de quizzes en la guía QuizXpress Online Streaming, disponible en nuestro sitio web.

También es posible utilizar una solución híbrida con mandos/pulsadores y la aplicación QuizXpress Smart Buzzer.
