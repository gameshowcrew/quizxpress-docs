# HOME → Mededelingen

Soms wilt u dat elke vraag wordt voorafgegaan door een dia met het vraagnummer en de vraagtekst van de vraag die volgt. Dit kan in QuizXpress Studio met het commando ‘Genereer statische slides’ (Question Banners), te vinden in het menu ‘Bewerken’. Dit commando genereert automatisch vóór elke quizdia van het type ‘Vraag’ een quizdia van het type ‘Billboard’. Elke gegenereerde billboarddia bevat de volgende tekst: Vraag \<vraagnummer van de volgende vraag>: \<vraagtekst van de volgende vraag>.
