# Wager

Avec les questions Wager, les joueurs peuvent miser (un pourcentage de) leurs points sur la question qui suivra la diapositive de mise. Lorsque le type d’une question est défini sur ‘Wager’, la fenêtre ci-dessous s’affiche. Pendant un quiz, les joueurs misent (un pourcentage de) leurs points en fonction de ce qu’ils pensent savoir sur un sujet. Sur la diapositive elle-même, vous pouvez modifier le texte ou le design pour faire référence au sujet de la question qui suivra (par exemple : ‘La prochaine question porte sur le sport, combien de points souhaitez-vous miser ?’).
