# Problèmes de connexion des buzzers

Si un buzzer/une télécommande clignotant(e) s’affiche sur l’écran d’accueil de QuizXpress Live, cela indique que les buzzers ne sont pas correctement connectés. Pour résoudre ce problème :

- Ouvrez l’application Quiz Setup et vérifiez que le type de buzzer sélectionné sur la page ‘Buzzers’ correspond aux buzzers que vous utilisez réellement. Pour les buzzers Fleetwood Reply, veillez à définir le bon canal de la station de base et les ID des télécommandes utilisées.

Comme indiqué précédemment, vous pouvez utiliser l’application Buzzer Test, disponible dans le menu Démarrer de QuizXpress, pour vérifier que les buzzers sont correctement configurés. Cette application est également utile pour tester la portée de vos buzzers lorsque vous êtes sur le lieu de production.

!!! note

    Windows 7 avec la dernière révision des buzzers sans fil BuzzTM nécessite une procédure particulière. Contactez-nous si vous avez besoin d’aide. Sous Windows 7, cette révision des buzzers est reconnue comme un concentrateur USB, alors qu’elle devrait utiliser un périphérique USB HID (comme une souris ou un clavier). Vous devez le définir manuellement.*

## Utiliser les télécommandes Fleetwood Reply Systems

Pour éviter les problèmes, testez toujours l’ensemble du système avant de l’utiliser. Pour les grandes salles, procurez-vous les plans à l’avance et décidez de l’emplacement du matériel. Éloignez le matériel Reply des autres appareils radio, des haut-parleurs et des gros objets métalliques. Le récepteur doit être placé le plus haut possible dans la salle afin d’établir une ligne de vue dégagée vers les télécommandes. Les murs peuvent affecter la portée des télécommandes. Soyez attentif à la présence de routeurs Wi-Fi dans la salle, car ils peuvent affecter la portée des appareils Reply. Pour plus d’informations sur la bonne installation de ce système de télécommandes, consultez le manuel d’utilisation du Fleetwood Reply Mini, disponible dans la section téléchargement de notre site.

## Utiliser les buzzers filaires Sony sous Windows Vista

La révision suivante des buzzers **filaires** Sony ne fonctionne pas sous Windows Vista : SCEH-0005. Contactez-nous si vous avez besoin d’aide avec ces buzzers.

Toutes les versions sans fil des buzzers Sony fonctionnent avec Windows. Pour Windows 7 et versions ultérieures, une procédure particulière peut être nécessaire, selon la révision de vos buzzers. Consultez l’Annexe C pour la procédure d’installation de la dernière révision des buzzers Sony sous Windows Vista et Windows 7.

## Grandes installations avec des buzzers Sony

Si nécessaire, les récepteurs peuvent être éloignés de l’ordinateur à l’aide de câbles USB actifs. De cette façon, des « îlots » de personnes peuvent être créés autour d’un récepteur, ce qui permet à de plus grands groupes de participer. QuizXpress a été testé avec jusqu’à 12 buzzers Sony BuzzTM, mais jusqu’à 20 buzzers ont été utilisés sur le terrain. Avec des buzzers filaires, il n’y a aucune limite : des utilisateurs ont utilisé QuizXpress avec jusqu’à 120 buzzers filaires BuzzTM sur une infrastructure USB standard.
