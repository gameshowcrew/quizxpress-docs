# Requisitos del sistema

| Componente       | Requisito                                                                                     |
|------------------|-----------------------------------------------------------------------------------------------|
| Sistema operativo | Windows 10 o Windows 11                                                                      |
| Espacio libre en disco | ~1 GB, se prefiere un disco SSD                                                         |
| Memoria          | 8 GB como mínimo, 16 GB recomendados                                                          |
| Tarjeta de vídeo | Tarjeta de vídeo compatible con DirectX 9C                                                    |
| Tarjeta de sonido | Sirve cualquier tarjeta de sonido estándar                                                   |
| CPU              | Para un buen rendimiento con vídeos HD, recomendamos un procesador i5 a 2,4 GHz o superior.   |

Para instalar el software, ejecute el paquete de instalación QuizXpress8.exe. En el correo electrónico que recibió con su clave de licencia encontrará un enlace a la sección de descargas de nuestro sitio web.

![](../assets/images/image2.webp){ width="321" loading=lazy }

El proceso de instalación en sí es sencillo. Lea detenidamente el acuerdo de licencia y, una vez que esté de acuerdo, marque la casilla ‘I agree…’ y haga clic en ‘Install’.
