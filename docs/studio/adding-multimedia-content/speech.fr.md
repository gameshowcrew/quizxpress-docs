# Synthèse vocale

Vous pouvez ajouter de la synthèse vocale à vos diapositives de quiz. QuizXpress utilise le synthétiseur vocal de Windows pour lire à voix haute les textes que vous indiquez. Vous pouvez par exemple créer une question où les paroles d’une chanson sont lues à voix haute et où le public doit deviner l’artiste ou la chanson.

Pour insérer un élément vocal, sélectionnez l’onglet de ruban INSERT et cliquez sur le bouton ‘Speech’ :

![](../../assets/images/image203.webp){ width="428" loading=lazy }

Vous pouvez ensuite saisir le texte à prononcer :

![](../../assets/images/image204.webp){ width="425" loading=lazy }

Une fois l’élément vocal créé, vous pouvez le modifier à l’aide des commandes de l’onglet de ruban contextuel.

![](../../assets/images/image205.webp){ width="595" loading=lazy }
