# Quizzes bilingües

Puede crear quizzes para un público bilingüe. Para ello, QuizXpress Studio le permite introducir las preguntas y las respuestas en un idioma principal (Primary) y un idioma secundario (Secondary).

Para introducir el contenido en dos idiomas, seleccione una diapositiva y asegúrese de que la ventana Properties esté visible. A continuación, establezca la propiedad *Language* en Primary o Secondary.

![](../assets/images/image249.webp){ width="317" loading=lazy }

![](../assets/images/image250.webp){ width="65" loading=lazy }

Tras establecer el idioma en Secondary, aparece una pestaña junto a la diapositiva que le permite cambiar entre el idioma Primary y el Secondary haciendo clic en la pestaña correspondiente.

En cuanto introduce texto en el idioma secundario, se guarda en el quiz. Al alternar entre Primary y Secondary verá ambos idiomas.

Puede traducir automáticamente un quiz a otro idioma. Para ello, haga clic en el botón Translate de la pestaña de cinta HOME:

![](../assets/images/image251.webp){ loading=lazy }

En QuizXpress Live!, las diapositivas de ambos idiomas se presentan en pantalla al mismo tiempo: el idioma Primary a la izquierda y el Secondary a la derecha.

![](../assets/images/image252.webp){ width="603" loading=lazy }

!!! note

    si ha creado un quiz bilingüe, aun así puede ejecutarlo en un solo idioma. Para ello, pase el argumento de línea de comandos -language=0\|1\|2 a Quiz Show.exe (el reproductor de quiz): 0 lo ejecuta en modo bilingüe, 1 en el idioma principal y 2 en el idioma secundario. Lo más sencillo es crear un acceso directo de Windows y establecer allí el argumento **-language** correcto.*

Si desea quitar el idioma secundario de una diapositiva, haga clic con el botón derecho en la diapositiva y elija Language > Reset.
