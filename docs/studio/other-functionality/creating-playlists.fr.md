# Créer des playlists

Vous pouvez créer et enregistrer des playlists contenant plusieurs quiz. Grâce aux playlists, vous pouvez créer plusieurs quiz plus courts et les combiner en un seul quiz plus long.

Pour créer une playlist, cliquez sur le bouton External du ruban HOME, puis choisissez ‘Make playlist’.

![](../../assets/images/image305.webp){ width="474" loading=lazy }

En cliquant sur le bouton ‘Add’, vous pouvez ajouter plusieurs quiz à la liste. Après avoir ajouté les quiz, vous pouvez modifier leur ordre en sélectionnant un quiz dans la liste et en appuyant sur les boutons ‘Up’ et ‘Down’.

Le bouton ‘Save’ enregistre la playlist sur le disque. Les playlists ont l'extension de fichier .qxp.

Au démarrage de QuizXpress Live, le lecteur de quiz, vous pouvez sélectionner soit un fichier de quiz (extension .qx), soit une playlist (extension .qxp). Lorsque vous sélectionnez une playlist, tous les quiz qu'elle contient sont joués les uns après les autres comme s'il s'agissait d'un seul grand quiz. Les scores sont conservés d'un quiz à l'autre.

Vous pouvez également sélectionner une playlist dans l'Explorateur Windows, faire un clic droit dessus et choisir ‘Edit playlist’ pour la modifier avec l'éditeur de playlists, ou choisir ‘Open with > QuizXpress Live’ pour démarrer le lecteur de quiz avec la playlist.
