# HOME → Normalize volume

El comando ‘Normalize volume’, disponible en el grupo ‘Tools’ de la pestaña HOME, hace que todos los sonidos del quiz se reproduzcan con el mismo volumen. QuizXpress mide el volumen de cada sonido y ajusta su ganancia hacia un volumen objetivo que usted elige. Los archivos de sonido en sí no se modifican.

![Normalize volume en la pestaña HOME de la cinta de opciones](../../assets/images/normalize-home-tools.webp){ width="220" loading=lazy }

Consulte [Normalizar el volumen](../adding-multimedia-content/sound.md#normalizar-el-volumen) para una descripción completa, incluido cómo normalizar un solo sonido.
