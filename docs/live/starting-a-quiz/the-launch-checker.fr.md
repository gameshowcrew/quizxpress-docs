# Le vérificateur de lancement

Avant le début de votre show, QuizXpress Live vérifie plusieurs conditions, par exemple si les vidéos externes du quiz sont toujours disponibles, si divers répertoires sont accessibles et si tous les fichiers audio personnalisés sont bien présents. Cela évite les mauvaises surprises pendant le quiz.

Lorsque des problèmes sont détectés, la fenêtre suivante apparaît (les messages d'avertissement réels peuvent différer) :

![](../../assets/images/image401.webp){ width="591" loading=lazy }

Vous pouvez décider de poursuivre le quiz (en cliquant sur « Ignore ») ou de l'arrêter pour corriger les problèmes (en cliquant sur « Quit »). Poursuivre le show alors que des avertissements ou des erreurs sont présents peut entraîner des problèmes ou un comportement inattendu pendant le quiz.
