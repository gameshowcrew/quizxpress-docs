# Cuadro de diálogo FILE → Options

La entrada a este cuadro de diálogo se encuentra en el menú FILE de la vista Backstage:

![](../../assets/images/image298.webp){ width="605" loading=lazy }

La pestaña ‘Target device’ de este cuadro de diálogo le permite establecer la relación de aspecto de pantalla y la calidad de imagen de su quiz. La opción *ratio* configura la relación entre ancho y alto de sus diapositivas para que coincida con el dispositivo en el que presentará su quiz:

La sección de datos ‘Quiz Author’ muestra el historial del archivo de quiz: quién lo creó originalmente y quién lo modificó por última vez. Estos datos se utilizan, por ejemplo, cuando un archivo de quiz ha caducado y al usuario final se le presentan los datos de contacto para obtener una actualización reciente. Sus propios datos de autor del quiz se pueden introducir en el cuadro de diálogo ‘Options’ (disponible en la cinta HOME).

Por último, la pestaña ‘Advanced’ le permite establecer propiedades avanzadas para el quiz. ‘QX3 compatible video rendering’ significa que el sistema utiliza el sistema de vídeo que existía en QX3. Quizá le convenga utilizarlo porque puede ofrecer mejor rendimiento en sistemas de gama baja como los netbooks. El inconveniente es que solo admite el formato AVI y no se pueden usar efectos de vídeo. Este ajuste se aplica a todo el quiz, así que tenga cuidado de no usar ningún otro formato de vídeo en su quiz (si lo hace, se genera una advertencia al iniciar QuizXpress Live). *Rara vez necesitará activar esta función.*
