# Requisiti di sistema

| Componente       | Requisito                                                                                     |
|------------------|-----------------------------------------------------------------------------------------------|
| Sistema operativo | Windows 10 o Windows 11                                                                      |
| Spazio libero su disco | ~1 GB, si preferisce un disco SSD                                                       |
| Memoria          | 8 GB minimo, 16 GB consigliati                                                                |
| Scheda video     | Scheda video compatibile con DirectX 9C                                                       |
| Scheda audio     | Va bene qualsiasi scheda audio standard                                                       |
| CPU              | Per buone prestazioni con i video HD, si consiglia un processore i5 a 2,4 GHz o superiore.    |

Per installare il software, eseguire il pacchetto di installazione QuizXpress8.exe. Un collegamento alla sezione download del nostro sito web si trova nell'e-mail ricevuta con la chiave di licenza.

![](../assets/images/image2.webp){ width="321" loading=lazy }

Il processo di installazione è semplice. Leggere attentamente il contratto di licenza e, una volta accettato, selezionare la casella ‘I agree…’ e fare clic su ‘Install’.
