# Creare playlist

È possibile creare e salvare playlist che contengono più quiz. Utilizzando le playlist, è possibile creare diversi quiz più brevi e combinarli in un unico quiz più lungo.

Per creare una playlist, fare clic sul pulsante External della barra multifunzione HOME, quindi scegliere ‘Make playlist’.

![](../../assets/images/image305.webp){ width="474" loading=lazy }

Facendo clic sul pulsante ‘Add’ è possibile aggiungere più quiz all'elenco. Dopo aver aggiunto i quiz, è possibile modificarne l'ordine selezionando un quiz nell'elenco e premendo i pulsanti ‘Up’ e ‘Down’.

Il pulsante ‘Save’ salva la playlist su disco. Le playlist hanno l'estensione di file .qxp.

All'avvio di QuizXpress Live, il lettore di quiz, è possibile selezionare un file di quiz (estensione .qx) oppure una playlist (estensione .qxp). Quando si seleziona una playlist, tutti i quiz in essa contenuti vengono riprodotti uno dopo l'altro come se fossero un unico grande quiz. I punteggi vengono mantenuti tra un quiz e l'altro.

In alternativa, è possibile selezionare una playlist in Esplora risorse di Windows, fare clic con il pulsante destro del mouse e scegliere ‘Edit playlist’ per modificarla con l'editor di playlist, oppure scegliere ‘Open with > QuizXpress Live’ per avviare il lettore di quiz con la playlist.
