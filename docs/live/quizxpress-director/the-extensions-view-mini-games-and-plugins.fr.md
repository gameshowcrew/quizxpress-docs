# La vue Extensions (mini-jeux et plugins)

La vue « Extensions » est votre point d’accès aux mini-jeux QuizXpress inclus dans votre licence. Depuis cette vue, vous pouvez lancer des mini-jeux à la volée à tout moment pendant votre quiz, lorsque le compte à rebours ne tourne pas et n’est pas en pause. Vous pouvez aussi insérer des mini-jeux dans votre quiz lors de sa création. Vous pouvez en savoir plus sur les mini-jeux disponibles dans [Mini-jeux](../../studio/mini-games/index.md).

Reportez-vous à [Majority Rules](../../studio/slide-and-game-formats/majority-rules.md) pour plus d’informations sur l’insertion de mini-jeux dans votre quiz.

Trois actions sont possibles sur un plugin installé : configurer, lancer et terminer. « Configure » ouvre une fenêtre pour modifier les paramètres du plugin. « Launch » démarre le plugin sur l’écran principal du quiz pour les participants. Le bouton « End » arrête un plugin et vous ramène à l’écran normal du quiz.

![](../../assets/images/image452.webp){ loading=lazy }

Lorsque vous cliquez sur le bouton « Configurations », vous constatez que vous pouvez créer, supprimer ou renommer une configuration. Les configurations disponibles sont affichées dans la liste des plugins, à côté de chaque plugin, pour que vous puissiez choisir. Vous pouvez aussi cloner la configuration actuellement sélectionnée. Appuyez sur le bouton Configure pour modifier les détails de la configuration sélectionnée. La configuration sélectionnée pour un plugin est celle utilisée lorsque vous lancez le plugin.

![](../../assets/images/image453.webp){ width="605" loading=lazy }

Une fois en cours d’exécution, le plugin peut afficher des boutons supplémentaires dans le panneau de gauche, vous donnant accès à des fonctions spécifiques du plugin.

En général, un bouton Next se trouve dans le panneau de gauche et vous fait avancer dans le jeu (vous pouvez aussi utiliser la barre d’espace ou le bouton suivant de la télécommande de présentation).
