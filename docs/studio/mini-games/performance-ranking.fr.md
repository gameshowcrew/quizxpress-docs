# Performance ranking

Avec le module Performance ranking, vous pouvez organiser des concours de talents et de karaoké. Le public/les joueurs peuvent noter la prestation de l'un des autres joueurs.

Les options de configuration disponibles sont :

> ![](../../assets/images/image172.webp){ width="401" loading=lazy }

- Show announcement screen : activez cette option pour afficher un écran d'annonce avant la prestation.

- Background image (announcement screen section) : sélectionnez un arrière-plan pour l'écran d'annonce.

- Announcement text : le texte à afficher dans l'annonce. Pour inclure le nom du joueur qui va se produire, ajoutez {0}, qui sera remplacé par le nom du joueur sélectionné.

- Play video section : activez cette option pour afficher une vidéo pendant la prestation, puis sélectionnez un fichier vidéo à lire. Généralement utilisé pour afficher une vidéo de karaoké.

<!-- -->

- Background image (voting screen section) : choisissez l'image d'arrière-plan affichée sur l'écran de vote

<!-- -->

- Header text : choisissez le texte affiché sur l'écran de vote. Pour inclure le nom du joueur qui s'est produit, ajoutez {0}, qui sera remplacé par le nom du joueur sélectionné.

<!-- -->

- Title/Points/Color fields : saisissez les libellés affichés sur l'écran de vote pour indiquer la qualité de la prestation. Chaque libellé est associé à un nombre de points ainsi qu'à une couleur.

- Sound tab : configurez la musique jouée avant le début du vote, pendant le vote et après la fin du vote.

Au démarrage du plugin Performance ranking, une fenêtre s'ouvre dans laquelle l'un des joueurs doit être sélectionné comme joueur qui sera jugé par les autres.

Lorsque l'on appuie sur le bouton ‘Start Voting’ dans le panneau de gauche de QuizXpress Director, la prestation commence et les joueurs peuvent commencer à donner leur avis. En bas à gauche de l'écran de vote s'affichent le temps écoulé depuis le début de la prestation ainsi que le nombre de joueurs ayant déjà voté.

Lorsque l'on appuie sur le bouton ‘End Voting’ dans le panneau de gauche, les joueurs ne peuvent plus voter et le score final s'affiche à l'écran.

Si le paramètre ‘Play video’ est activé, le bouton affiche d'abord ‘Start Video’. Un appui lance une vidéo ou vous permet d'en sélectionner une, selon les paramètres. Ensuite, le bouton devient ‘Start Voting’.

Une fois le processus de vote terminé, un appui sur le bouton ‘Start Voting’ répète l'ensemble du processus. Un autre joueur peut alors monter sur scène et donner le meilleur de lui-même !
