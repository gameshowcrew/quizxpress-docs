# Images

## Insérer une image

Plusieurs formats de diapositive contiennent des espaces réservés pour une image :

| ![](../../assets/images/image185.webp){ width="288" loading=lazy } | ![](../../assets/images/image186.webp){ width="291" loading=lazy } |
|---------------------------------------------------------------------------|---------------------------------------------------------------------------------|

Pour remplir l'espace réservé avec une ‘vraie’ image, cliquez sur l'espace réservé pour le sélectionner. L'onglet de ruban contextuel ‘PICTURE’ apparaît alors :

![](../../assets/images/image187.webp){ width="605" loading=lazy }

Vous pouvez ici cliquer sur ‘Select Picture’ pour ouvrir un explorateur de fichiers et sélectionner sur le disque n'importe quel format de fichier image pris en charge. Ensuite, vous pouvez définir les propriétés de l'image et appliquer des effets ou des transformations statiques. Vous pouvez également glisser-déposer des images (et des vidéos) directement depuis l'Explorateur Windows sur un espace réservé image (ou sur l'arrière-plan de la diapositive pour définir l'image d'arrière-plan).

Les images peuvent aussi avoir une représentation textuelle sous forme de libellé. Vous pouvez définir le libellé en cliquant avec le bouton droit sur l'image et en sélectionnant “Set Label” dans le menu. Ce libellé est utilisé, par exemple, lorsqu'une question avec image est présentée dans l'application Smart Buzzer. Si vous choisissez de ne pas afficher les images sur le téléphone (pour le mode Wi-Fi, voir 4.2.1 et pour le mode serveur, voir 5.7.8.3), le libellé sera affiché à la place sur le téléphone.

Vous pouvez également cliquer avec le bouton droit sur l'espace réservé pour afficher les options :

Vous pouvez ici choisir d'insérer une image, une vidéo ou un graphique. Lorsque vous avez une mise en page avec plusieurs images, les images peuvent aussi servir de réponses à la question. Dans ce cas, vous pouvez définir une image comme bonne réponse, indiquer l'ordre des images pour une question à réponses ordonnées, ou définir le pourcentage de justesse pour une question avec plusieurs images en réponse.

Vous pouvez aussi générer des images avec l'IA. Pour plus d'informations, reportez-vous à 3.8.4.

Pour plus d'informations sur les autres paramètres des images, reportez-vous à [Picture properties](../user-interface-overview/advanced-properties-grid.md#proprietes-des-images).

## Recadrage

Lorsque vous cliquez avec le bouton droit sur une image, la commande ‘Crop…’ apparaît dans le menu contextuel. Elle ouvre l'éditeur **Crop Image**, qui vous permet de sélectionner la partie de l'image à présenter dans votre quiz :

![](../../assets/images/image188.webp){ loading=lazy }

Le résultat est :

![](../../assets/images/image189.webp){ loading=lazy }

Notez que l'image *originale* n'est pas conservée après le recadrage, mais si le résultat ne vous plaît pas, vous pouvez toujours annuler le recadrage (au cours de la même session).

## Texte en image

Cette fonction est particulièrement utile pour créer des questions d'association ou concevoir des cartes de Bingo : vous pouvez générer des images à partir de texte directement dans Studio. Cliquez avec le bouton droit sur l'image et sélectionnez ‘Text to Image’ dans le menu contextuel :

![](../../assets/images/image190.webp){ width="591" loading=lazy }

Vous pouvez mettre en forme le texte avec diverses options et, une fois terminé, cliquer sur OK pour remplacer l'espace réservé image de votre diapositive par l'image générée :

![](../../assets/images/image191.webp){ loading=lazy }

## Appliquer des effets

L'une des propriétés d'une image dans une question est ‘Effect’. Lorsqu'une valeur est choisie pour cette propriété dans la grille de propriétés, l'effet choisi est appliqué à l'image pendant toute la durée de la question. Au début de la question, l'effet est appliqué à pleine intensité, de sorte qu'il peut être très difficile de voir ce que représente l'image. À mesure que le temps de la question s'écoule vers 0, l'image revient lentement à son état d'origine. Vous pouvez prévisualiser les effets en sélectionnant l'image et en cliquant sur ‘Preview’.
