# Voz

Puede añadir voz generada por ordenador a las diapositivas de su quiz. QuizXpress utiliza el sintetizador de voz de Windows para leer en voz alta los fragmentos de texto que usted especifique. Por ejemplo, puede crear una pregunta en la que se lea en voz alta la letra de una canción y el público deba adivinar el artista o la canción.

Para insertar un elemento de voz, seleccione la pestaña INSERT de la cinta de opciones y haga clic en el botón ‘Speech’:

![](../../assets/images/image203.webp){ width="428" loading=lazy }

A continuación, podrá introducir el texto que se va a pronunciar:

![](../../assets/images/image204.webp){ width="425" loading=lazy }

Una vez creado el elemento de voz, puede modificarlo mediante los controles de la pestaña contextual de la cinta de opciones.

![](../../assets/images/image205.webp){ width="595" loading=lazy }
