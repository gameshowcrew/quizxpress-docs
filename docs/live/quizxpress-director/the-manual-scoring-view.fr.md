# La vue Manual Scoring

Cette vue vous aide à ajouter/retirer rapidement des points pour une ou plusieurs équipes, par exemple pour des activités qui se déroulent en dehors de QuizXpress. L’écran se présente ainsi :

![](../../assets/images/image448.webp){ loading=lazy }

Sélectionnez un ou plusieurs joueurs dans la liste de gauche, puis touchez l’un des boutons préassignés (vous pouvez modifier l’assignation avec Settings). Avec l’interrupteur « Show on quiz screen », vous décidez si la modification de points doit être affichée au public. Vous pouvez annuler la dernière modification avec le bouton Undo, et utiliser le bouton Assign pour ajouter ou retirer un nombre de points quelconque.
