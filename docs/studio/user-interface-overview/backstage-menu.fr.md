# Menu Backstage

Lorsque vous cliquez sur l’onglet FILE ou appuyez sur F1, le menu backstage apparaît. ![](../../assets/images/image12.webp){ width="501" loading=lazy }

Vous accédez ici aux fonctionnalités globales de l’application, dont les détails sont disponibles dans plusieurs autres onglets :

| **New**                              | Créer un nouveau quiz et choisir le format d’image des diapositives            |
|--------------------------------------|------------------------------------------------------------------------|
| **Recent**                           | Ouvrir des fichiers récents et des exemples                                          |
| **Import**                           | Importer des questions depuis Excel ou depuis un autre fichier de quiz                  |
| **Export questions to Excel or PDF** | Exporter les questions vers Excel ou PDF                                        |
| **Print**                            | Imprimer les diapositives de votre quiz                                                 |
| **Info**                             | Accéder au fichier d’aide, à diverses ressources en ligne et gérer votre licence |
