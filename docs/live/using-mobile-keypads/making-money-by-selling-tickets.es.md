# Ganar dinero vendiendo entradas

Puede utilizar entradas electrónicas con la aplicación Smart Buzzer y el sitio web buzzerpad para generar ingresos al organizar quizzes (en línea). Sin embargo, la venta de entradas digitales a su público es responsabilidad suya. Existen varios plugins de tienda web para CMS que permiten vender entradas en su tienda web, o puede utilizar plataformas de venta de entradas en línea como <https://www.tickettailor.com/>. Para QuizXpress, lo único que necesita es un sencillo archivo de texto sin formato con todos los códigos de entrada (una entrada por línea, sin distinguir mayúsculas de minúsculas). Este archivo de texto debe llamarse *tickets.txt* y debe guardarse en la misma carpeta que su quiz. Al iniciar su quiz, las entradas se envían al servidor y, cuando un jugador se conecta a su quiz, se le solicita un código de entrada que debe coincidir con una línea de *tickets.txt*. Cada entrada solo puede utilizarse una vez de forma simultánea, de modo que las personas no puedan compartir entradas. Puede actualizar las entradas incluso mientras el quiz está en marcha. Para ello, abra la pantalla Director en su PC, active la pestaña Mobile y localice el botón ‘Refresh Tickets’.
