# Quiz bilingues

Vous pouvez créer des quiz pour un public bilingue. Pour cela, QuizXpress Studio vous permet de saisir les questions et les réponses dans une langue principale (Primary) et une langue secondaire (Secondary).

Pour saisir le contenu dans deux langues, sélectionnez une diapositive et assurez-vous que la fenêtre Properties est affichée. Réglez ensuite la propriété *Language* sur Primary ou Secondary.

![](../assets/images/image249.webp){ width="317" loading=lazy }

![](../assets/images/image250.webp){ width="65" loading=lazy }

Après avoir réglé la langue sur Secondary, un onglet apparaît à côté de la diapositive et vous permet de passer de la langue Primary à la langue Secondary en cliquant sur l’onglet correspondant.

Dès que vous saisissez du texte dans la langue secondaire, il est enregistré dans le quiz. En passant d’une langue à l’autre, vous voyez les deux langues.

Vous pouvez traduire automatiquement un quiz dans une autre langue. Pour cela, cliquez sur le bouton Translate de l’onglet de ruban HOME :

![](../assets/images/image251.webp){ loading=lazy }

Dans QuizXpress Live!, les diapositives des deux langues sont présentées à l’écran en même temps : la langue Primary à gauche et la langue Secondary à droite.

![](../assets/images/image252.webp){ width="603" loading=lazy }

!!! note

    si vous avez créé un quiz bilingue, vous pouvez quand même le jouer en une seule langue. Pour cela, transmettez l’argument de ligne de commande -language=0\|1\|2 à Quiz Show.exe (le lecteur de quiz) : 0 lance le quiz en mode bilingue, 1 dans la langue principale et 2 dans la langue secondaire. Le plus simple est de créer un raccourci Windows et d’y définir le bon argument **-language**.*

Si vous souhaitez supprimer la langue secondaire d’une diapositive, cliquez avec le bouton droit sur la diapositive et choisissez Language > Reset.
