# Minigame

QuizXpress propose une variété de minijeux. Les minijeux relèveront votre émission de jeu ou votre soirée quiz en proposant autre chose que des questions de culture générale. Ces jeux permettent de gagner ou de perdre des points.

Les minijeux peuvent être lancés manuellement (à la demande) depuis QuizXpress Director (le panneau de contrôle de l'animateur de quiz, nous y reviendrons plus tard), utilisés en insérant une diapositive de type « Minigame » dans le fichier de quiz, ou exécutés de façon autonome depuis le lanceur de minijeux.

![](../../assets/images/image63.webp){ width="109" loading=lazy }Pour insérer un minijeu dans votre quiz, sélectionnez la disposition de diapositive « minigame » dans la galerie de dispositions de l'onglet de ruban INSERT :

L'étape suivante consiste à choisir le jeu dans la liste des jeux disponibles :

![](../../assets/images/image64.webp){ width="260" loading=lazy }

Une nouvelle diapositive est insérée ; elle lancera le minijeu dans QuizXpress Live! lorsque le quiz arrivera à cette diapositive. Chaque diapositive de minijeu peut avoir sa propre configuration et son propre habillage. Pour configurer un minijeu, faites un clic droit sur la diapositive et cliquez sur « Configure… » ou cliquez sur « Configure » dans le ruban QUESTION :

![](../../assets/images/image65.webp){ width="605" loading=lazy }

La boîte de dialogue de configuration de ce minijeu s'affiche alors. Vous pouvez aussi charger et enregistrer des configurations de minijeux afin de les réutiliser d'un quiz à l'autre. [Minijeux](../mini-games/index.md) donne un aperçu de tous les minijeux actuellement disponibles et de leurs options de jeu.

Pour tester votre minijeu, vous pouvez soit exécuter votre quiz complet, soit utiliser la fonction d'aperçu de Studio en appuyant sur F5 (ou en faisant un clic droit sur le minijeu et en choisissant « Preview »). Le minijeu se lance alors dans une fenêtre séparée. Utilisez la barre d'espace pour naviguer entre les différents écrans.

Vous pouvez également lancer des minijeux à la volée pendant un quiz depuis QuizXpress Director. Veuillez consulter [L'affichage Round scores](../../live/quizxpress-director/the-round-scores-view.md) pour plus d'informations.

Enfin, vous pouvez lancer un minijeu de façon autonome (sans exécuter de quiz dans le lecteur de quiz) depuis le lanceur de minijeux. Le lanceur de minijeux peut être démarré depuis le menu Démarrer de Windows (section QuizXpress) ou depuis Studio.

![](../../assets/images/image66.webp){ width="270" loading=lazy }

Au démarrage, un aperçu de tous les minijeux pouvant être lancés s'affiche :

![](../../assets/images/image67.webp){ loading=lazy }

En faisant un clic droit sur une vignette, vous pouvez configurer le minijeu et même créer et enregistrer différentes configurations (qui apparaîtront comme de nouvelles vignettes distinctes). Lorsque vous lancez un jeu qui nécessite une interaction des joueurs sur des keypads mobiles, un écran de connexion avec un code PIN et un code QR est présenté afin que les buzzers mobiles puissent se connecter. Vous pouvez par exemple utiliser le lanceur de minijeux pour organiser un jeu rapide afin d'offrir une boisson gratuite.
