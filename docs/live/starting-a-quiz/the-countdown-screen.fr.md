# L’écran du compte à rebours

Après l’écran d’enregistrement des keypads, une vidéo de compte à rebours est diffusée pour créer du suspense. Si vous ne souhaitez pas voir cette vidéo avant le début du quiz, décochez « Show 3-2-1 Quiz countdown screen » sur la page « Screens » de Quiz Setup. Vous pouvez interrompre cet écran en appuyant sur la barre d’espace pendant la vidéo.
