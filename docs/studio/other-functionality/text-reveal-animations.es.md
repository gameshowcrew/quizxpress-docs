# Animaciones de revelado de texto

Para todos los elementos de pregunta y respuesta puede definir cómo aparecen en la pantalla:

- Show direct/None (predeterminado)

- Word by Word

- Letter by Letter

![](../../assets/images/image285.webp){ width="563" loading=lazy }

En las propiedades avanzadas de los textos de pregunta o respuesta, puede ajustar la animación con las propiedades de retardo de inicio y velocidad:

![](../../assets/images/image286.webp){ width="327" loading=lazy }

Puede usar esta función si desea leer la pregunta en voz alta sin revelarla de inmediato, o para despistar a los jugadores mostrando las respuestas directamente mientras la pregunta aparece poco a poco (los jugadores podrían elegir la respuesta equivocada haciendo suposiciones sobre la pregunta).

Si desea previsualizar el revelado del texto, pulse F5 para mostrar una vista previa de la diapositiva a pantalla completa.
