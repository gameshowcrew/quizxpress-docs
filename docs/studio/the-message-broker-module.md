# The Message Broker module

Message Broker is an optional QuizXpress plugin that connects your quiz to external devices and applications. QuizXpress events can trigger MIDI messages, for example to change DMX lighting when an answer is correct. External programs can also control the quiz, or listen for quiz events, over UDP, TCP or Telnet.

![How Message Broker connects QuizXpress to external devices](../assets/images/mb-overview-diagram.webp){ loading=lazy }

Message Broker is configured from QuizXpress Director while a quiz is running: press 'D' and open the 'Extensions' tab.

For the full documentation, see [Message Broker](../advanced/message-broker/index.md) in the Advanced section.

!!! note
    Message Broker is a licensed add-on for QuizXpress and requires a one-time purchase.
