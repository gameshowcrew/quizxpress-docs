# Pairing question

In una Domanda di Abbinamento, i giocatori associano etichette di testo a immagini (ad esempio paesi a bandiere o marchi a loghi). Sul buzzer mobile appare così:

| | ![](../../assets/images/image46.webp){ width="159" loading=lazy } | ![](../../assets/images/image47.webp){ width="161" loading=lazy } | ![](../../assets/images/image48.webp){ width="160" loading=lazy } | |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------|

Per creare questo tipo di domanda, selezionare un modello con almeno *tre* segnaposto per immagini e impostare la ‘Tipologia Domanda’ su ‘Domanda di Abbinamento’. Quindi assegnare l'etichetta appropriata a ciascuna immagine:

![](../../assets/images/image49.webp){ loading=lazy }

In alternativa, è possibile usare il Quiz Wizard.

![](../../assets/images/image50.webp){ width="390" loading=lazy }

Quindi compilare le etichette e selezionare le immagini corrispondenti:

![](../../assets/images/image51.webp){ width="390" loading=lazy }

Fare clic su **Avanti >** e completare la procedura guidata per creare la Domanda di Abbinamento.

## Domande Hotspot { #hotspot-questions }

Con questo tipo di domanda, il giocatore deve contrassegnare un punto (o più punti) su un'immagine, e la risposta è corretta quando quel punto (o quei punti) ricade nell'area contrassegnata come corretta dall'autore del quiz.

Ad esempio, se si vuole che i giocatori trovino la Francia su una mappa, si sceglie un modello con una sola immagine:

![](../../assets/images/image52.webp){ width="602" loading=lazy }

Impostare la ‘Modalità Input’ su ‘Hotspot’:

![](../../assets/images/image53.webp){ width="251" loading=lazy }

Quindi inserire l'immagine di una mappa nel segnaposto e modificare le aree hotspot con l'**Editor Hotspot** (fare clic con il pulsante destro del mouse sull'immagine e selezionare **Modifica Hotspot**):

![](../../assets/images/image54.webp){ loading=lazy }Ora contrassegnare l'area che costituisce la risposta corretta (qui in rosso). Le forme di area supportate comprendono aree rettangolari, ellittiche e a mano libera.

È possibile definire più aree corrette:![](../../assets/images/image55.webp){ width="602" loading=lazy }

Con più aree, nell'app Smart Buzzer appare così:

![](../../assets/images/image56.webp){ width="185" loading=lazy }

Sullo schermo del quiz l'immagine rivelerà la risposta corretta in questo modo:

![](../../assets/images/image57.webp){ loading=lazy }

!!! note

Quando si usano più aree e l'utente contrassegna più punti di quante siano le aree corrette, il suo punteggio diminuisce (per evitare risposte tirate a caso con molti indicatori).
