# HOME → Options

La boîte de dialogue des options de QuizXpress Studio se trouve sous Tools->Options. Elle comporte trois pages :

***Onglet Slide preferences :***

Cette page permet de définir diverses propriétés utilisées par défaut pour chaque nouvelle diapositive que vous créez. Par exemple, régler ‘Answer time’ sur 40 secondes ici garantit que le temps de réponse de chaque nouvelle diapositive est fixé à 40 secondes. Remarque : les modifications effectuées ici ne s'appliquent qu'aux nouvelles diapositives, pas aux existantes !

***Onglet Language :***

Cet onglet permet de définir la langue de l'interface utilisateur de QuizXpress Studio et de tous les autres outils QuizXpress (enregistrée dans le fichier de paramètres de QuizXpress).

***Onglet Author* :**

Vous pouvez ici définir les informations vous concernant qui seront intégrées au quiz en tant qu'auteur original du quiz.

***Onglet Other :***

Vous pouvez ici définir les seuils d'intégration/de liaison du contenu audio et vidéo, basculer entre trois styles d'interface utilisateur différents, et définir une option permettant au panneau des miniatures d'afficher des informations supplémentaires, comme le numéro de la question tel qu'il apparaît dans QuizXpress Live.
