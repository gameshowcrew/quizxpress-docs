# Notes de l’animateur de quiz

Les notes peuvent être saisies dans la zone de texte Notes. Si la section Notes n’est pas affichée, allez dans le menu VIEW et cochez ‘Notes’.

Les notes peuvent être utilisées par l’animateur de quiz pour donner au public des informations sur la question ou les réponses. Elles peuvent faire partie de l’export PDF d’un quiz. Elles sont également affichées dans QuizXpress Director et dans l’application Director.
