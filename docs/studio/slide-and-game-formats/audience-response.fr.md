# Audience Response

Il s'agit d'un type de question qui permet de sonder les opinions du public. Les réponses données à une question de type audience response sont enregistrées mais n'ont aucun impact sur les scores. Après une question audience response, vous pouvez afficher un graphique avec la touche « C » pour montrer la répartition des réponses données. Vous pouvez également insérer un Chart sur la diapositive, qui affiche le nombre de réponses pour chaque réponse « en temps réel » pendant le compte à rebours ou, au choix, à la fin du compte à rebours.
