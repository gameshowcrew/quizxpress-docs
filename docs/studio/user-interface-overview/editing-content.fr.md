# Modifier le contenu

Pour modifier le contenu, cliquez sur les éléments de la diapositive et changez les propriétés de l’élément sélectionné dans le ruban ou dans le volet des propriétés.

Pour modifier la question et toutes les réponses, utilisez l’entrée ‘Edit...’ du menu contextuel de la diapositive (faites un clic droit sur la diapositive et sélectionnez ‘Edit...’). Le formulaire ‘Edit question’ s’affiche. Vous pouvez aussi double-cliquer sur la diapositive.

![](../../assets/images/image21.webp){ width="333" loading=lazy }

Dans ce formulaire, vous modifiez facilement la question et les réponses en une seule fois.

Par ailleurs, Studio propose deux vues pour modifier le contenu : Graphical Mode et Table Mode. Vous pouvez choisir l’un des modes dans le ruban VIEW.

![](../../assets/images/image22.webp){ width="85" loading=lazy }

## Graphical Mode

Le mode graphique affiche une représentation graphique de la diapositive dans la zone de conception. C’est une vue « tel écran, tel résultat » : vous voyez la diapositive exactement telle qu’elle apparaîtra dans le lecteur de quiz. Remarque : appuyez sur F5 ou sur le bouton Preview Slide du ruban pour un aperçu plein écran de la diapositive.

## Table Mode

En mode tableau, vous voyez un aperçu de toutes les diapositives dans un tableau. Vous voyez le type de diapositive, la question, les réponses, la bonne réponse et les notes (le cas échéant, selon le type de diapositive), qui peuvent être modifiés commodément dans une seule vue.

![](../../assets/images/image23.webp){ width="593" loading=lazy }

![](../../assets/images/image24.webp){ width="193" loading=lazy }

Vous pouvez afficher et modifier d’autres propriétés fréquemment utilisées dans des colonnes en faisant un clic droit dans le tableau.

Cliquez sur le sous-menu Columns et choisissez les propriétés que vous souhaitez voir apparaître dans le tableau.

En plus de pouvoir modifier les valeurs dans un tableau, il est également utile de voir d’un coup d’œil toutes les valeurs de toutes les questions, ce qui facilite la vérification que tout est réglé comme prévu.

L’option ‘Size to fit’ ajuste la largeur des colonnes pour que tout le contenu soit lisible.

### Import Export en mode tableau

Vous pouvez importer et exporter le contenu du tableau vers Excel.

Un export produit un fichier Excel avec des colonnes pour la question, toutes les réponses, la bonne réponse et les notes de la diapositive.

| Q   | A1  | A2  | A3  | A4  | A5  | A6  | CORRECT | NOTES |     |
|-----|-----|-----|-----|-----|-----|-----|---------|-------|-----|

Les autres colonnes ne sont actuellement pas exportées.

Si vous importez un fichier contenant les colonnes ci-dessus, le contenu du tableau sera remplacé un pour un.

Import Export depuis la vue tableau vous permet de remplacer facilement le contenu *existant* à l’aide de données Excel. Tout le reste de la mise en forme et la structure du quiz restent intacts. Seuls la question, les réponses, la bonne réponse et les notes sont remplacées.

QuizXpress propose également une fonctionnalité d’import et d’export Excel plus avancée, qui permet d’importer un quiz entier depuis Excel, y compris diverses propriétés et la conception du quiz elle-même. Pour plus de détails, voir [Import of Excel format](../import-and-export-of-questions.md#import-au-format-excel)
