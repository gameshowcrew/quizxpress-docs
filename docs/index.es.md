# Manual de usuario de QuizXpress 8.6

Este es el manual de usuario de QuizXpress 8.6, un conjunto de software profesional para crear quizzes personalizados y de gran aspecto que se juegan en directo con grupos (grandes) de personas mediante mandos inalámbricos, pulsadores o dispositivos móviles. El software puede utilizarse para diversos fines, entre ellos:

- Fiestas de empresa y eventos corporativos

- Quizzes de pub

- Quiz Rooms

- Eventos personales como bodas, fiestas en casa, quizzes navideños, etc.

- Reuniones

- Educación y formación

- Ferias comerciales

- Eventos de recaudación de fondos

- Marketing

- Quizzes en el aula

- Reuniones virtuales

Como verá en este manual, el software es fácil de usar, tiene una interfaz de usuario intuitiva y un amplio conjunto de funciones que le permiten dirigir cualquier tipo de formato de concurso. Aunque hay muchos programas de quizzes y concursos en el mercado, QuizXpress destaca en muchos aspectos gracias a características únicas como:

- Un entorno gráfico de diseño de quizzes, completo y fácil de usar. No se necesita ningún otro software, como Microsoft PowerPoint.

- Salida gráfica de alta calidad: la mayoría de los juegos de quiz se crean como aplicaciones estándar de Windows. Aunque pueden ofrecer unos gráficos agradables, no pueden aprovechar los efectos gráficos avanzados que solo están disponibles para aplicaciones DirectX aceleradas por GPU como QuizXpress. QuizXpress admite muchas resoluciones y proporciones de pantalla diferentes, de modo que puede presentar sus quizzes de forma profesional en cualquier proyector, pantalla de TV o monitor.

- Muy personalizable: cuando dirige un concurso profesional para promocionar su producto o servicio, quiere que sus gráficos sean coherentes con la imagen corporativa de su empresa. QuizXpress le permite personalizar casi todos los aspectos de su presentación mediante un concepto llamado ‘skinning’.

- Juego avanzado: QuizXpress admite muchos modos diferentes para sus preguntas, como dedo más rápido, último en pie, preguntas abiertas, preguntas de respuesta del público, preguntas de apuesta, preguntas de regla de la mayoría, etc. QuizXpress también admite la opción de dividir a su público en directo en grupos demográficos que compiten entre sí, haciéndolo aún más interesante para su audiencia.

- Compatibilidad con una amplia gama de dispositivos de hardware inalámbricos, como distintos tipos de mandos y pulsadores, dispositivos móviles, marcadores y dispositivos LED RGB (por ejemplo, pulseras que dan respuesta durante el quiz).

- Un conjunto único de minijuegos/módulos que puede combinar con el contenido de su quiz para crear una noche de concurso entretenida para su público.

- Compatibilidad con Bingo de Trivia, de Números y de Emojis (disponible como módulo opcional) mediante la aplicación móvil QuizXpress Smart Buzzer o la aplicación para navegador.

- Aplicaciones móviles gratuitas para dispositivos iOS y Android, que permiten tipos de pregunta más avanzados con respuestas numéricas, de primera letra o de texto completo, además de un mando móvil basado en web para cuando no es posible o deseable instalar una aplicación.

- La aplicación web de pulsador de QuizXpress disponible en [www.buzzerpad.com](http://www.buzzerpad.com) y [www.buzzerpad.eu](http://www.buzzerpad.eu).

El software consta de las siguientes partes:

- *QuizXpress Studio*, el software que le ayuda a diseñar sus quizzes en una interfaz de usuario intuitiva

- *QuizXpress Live*, el software que ejecuta el concurso ‘en directo’ y se conecta a los pulsadores/mandos

- *QuizXpress Setup*, el software que se utiliza para configurar diversas opciones del concurso

- *QuizXpress Director* (parte de QuizXpress Live y una aplicación móvil), que se utiliza para controlar el concurso en marcha.

- *QuizXpress Solo,* el software utilizado para ejecutar un concurso independiente en un stand de una feria comercial.

- *QuizXpress Analyzer,* el software utilizado para analizar y visualizar los datos útiles recopilados durante un concurso.

- *Smart Buzzer,* el mando móvil, disponible como aplicación para Android e iOS o ejecutándolo desde el sitio web buzzerpad.

- *Minigame Launcher,* la aplicación que le permite ejecutar de forma independiente cualquiera de los minijuegos compatibles.
