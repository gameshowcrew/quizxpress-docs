# Vista Object List

Il modulo Object List può essere attivato o disattivato nella barra multifunzione View:

![](../../assets/images/image19.webp){ width="485" loading=lazy }

Quando questo strumento è attivo, compare una finestra mobile che mostra l’elenco di tutti gli oggetti della diapositiva del quiz corrente. Quando si seleziona un elemento nell’elenco, viene selezionato anche l’elemento visivo sulla diapositiva (e viceversa). È possibile selezionare più elementi e trascinarli nell’elenco per riordinare il loro ordine Z (ordine visivo davanti/dietro). È anche possibile fare doppio clic su una voce dell’elenco per richiamare l’azione ‘Edit’ predefinita dell’elemento. Ad esempio, per modificare il testo della domanda, basta fare doppio clic sull’elemento della domanda nell’elenco.
