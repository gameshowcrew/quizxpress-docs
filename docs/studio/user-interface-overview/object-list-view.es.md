# Vista Object List

El formulario Object List se puede activar o desactivar en la cinta de opciones View:

![](../../assets/images/image19.webp){ width="485" loading=lazy }

Cuando esta herramienta está activada, aparece una ventana flotante con una lista de todos los objetos de la diapositiva de quiz actual. Al seleccionar un elemento de la lista, también se selecciona el elemento visual de la diapositiva (y viceversa). Puede seleccionar varios elementos y arrastrar y soltar elementos en la lista para reordenar su orden Z (orden visual delante/detrás). También puede hacer doble clic en una entrada de la lista para invocar la acción ‘Edit’ predeterminada del elemento. Por ejemplo, para editar el texto de la pregunta, basta con hacer doble clic en el elemento de la pregunta en la lista.
