# La pantalla Welcome

Cuando se inicia la aplicación, la primera pantalla que aparece es la pantalla Welcome, que se muestra en la captura siguiente. Varios elementos de la pantalla Welcome pueden personalizarse mediante Quiz Setup; los elementos personalizables están marcados visualmente en la captura.

1.  Un texto de encabezado.

2.  Un logotipo que se muestra junto al texto de encabezado.

3.  La película o imagen de introducción que se muestra.

4.  Las imágenes que se muestran en la presentación de diapositivas.

5.  Un texto de pie de página (si establece un texto de pie de página, se mostrará sobre una franja azul)

Para pasar a la siguiente pantalla (la pantalla de registro de pulsadores), pulse el botón situado en la parte inferior derecha de la pantalla o pulse la barra espaciadora del teclado.

!!! note

    Si ve un icono de pulsador/mando parpadeante en la parte inferior derecha de la pantalla, significa que el sistema no ha encontrado el receptor inalámbrico. En ese caso, compruebe que el hardware esté correctamente conectado y que la configuración de pulsadores sea correcta en Quiz Setup.*
