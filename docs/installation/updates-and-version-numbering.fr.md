# Mises à jour et numérotation des versions

Pour vérifier votre version de QuizXpress, vous pouvez ouvrir la boîte À propos dans QuizXpress Studio. Elle affiche des informations sur la version actuellement installée :

| ![](../assets/images/image7.webp){ width="293" loading=lazy } | Un numéro de version QuizXpress comporte 4 chiffres, par exemple 8.5.0.4, composés d'un numéro majeur, d'un numéro mineur, d'un numéro de build et d'un numéro de révision. Le numéro majeur ne change que pour les mises à jour importantes ; le numéro mineur indique les différentes versions au sein de la version majeure. Le numéro de build et la révision distinguent les correctifs (corrections de bogues). QuizXpress Studio recherche des mises à jour en ligne au démarrage. |
|-------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

Si une version plus récente est disponible sur notre site web, vous en serez informé :

![](../assets/images/image8.webp){ width="592" loading=lazy }

Pour passer à une nouvelle version, cliquez simplement sur le lien de téléchargement dans la barre d'état de QuizXpress Studio afin de télécharger la dernière version :

> ![](../assets/images/image9.webp){ width="279" loading=lazy }

Une fois le téléchargement terminé, le programme d'installation démarre. Il n'est pas nécessaire de désinstaller la version actuellement installée.

Lors d'une mise à niveau, votre clé de licence, vos paramètres spéciaux, vos quiz et autres personnalisations sont conservés, car ils sont stockés en dehors du dossier d'installation de QuizXpress. Vous pourrez toujours ouvrir vos anciens quiz. Toutefois, lorsque vous partagez votre quiz avec d'autres personnes, assurez-vous qu'elles disposent de la même version.

Les notes de version de QuizXpress se trouvent dans le fichier *ReleaseNotes.txt* du dossier d'installation. Vous pouvez ouvrir ce fichier depuis Studio via *FILE->Info->Release Notes* ou depuis l'entrée QuizXpress du menu Démarrer de Windows.
