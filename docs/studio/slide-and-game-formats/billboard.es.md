# Billboard

Una diapositiva de quiz ‘Billboard’ es una diapositiva de quiz sin interacción de los jugadores. Es simplemente una pantalla estática que suele usarse para anuncios o explicaciones. Puede diseñar una diapositiva de quiz Billboard igual que diseña una pregunta normal, utilizando textos, colores, imágenes, sonidos y vídeos.

Aplicaciones útiles de un Billboard son:

- Anuncios (rondas/finalización de rondas/anuncios de puntuaciones intermedias)

- Explicación adicional de la respuesta correcta a una pregunta anterior

- Información de marketing o mensajes de ventas

- Mostrar una vista previa de una próxima pregunta de opción múltiple para que el público pueda prepararse.

- Mostrar un vídeo o una imagen antes de una pregunta que el público necesite observar con atención.
