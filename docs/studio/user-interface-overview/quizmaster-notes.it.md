# Note del conduttore del quiz

Le note possono essere inserite nella casella di testo Notes. Se la sezione Notes non è visibile, andare al menu VIEW e spuntare ‘Notes’.

Le note possono essere utilizzate dal conduttore del quiz per fornire al pubblico alcune informazioni sulla domanda o sulle risposte. Possono far parte dell’esportazione PDF di un quiz. Vengono inoltre mostrate in QuizXpress Director e nell’app Director.
