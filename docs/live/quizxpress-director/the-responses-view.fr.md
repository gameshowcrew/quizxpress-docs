# La vue Responses

La vue « Responses » offre un aperçu « en temps réel » des réponses reçues par le système. Vous pouvez voir le numéro de keypad, le nom de l’équipe/du joueur, la réponse donnée et l’heure (si la place à l’écran le permet). Il s’agit d’une vue en lecture seule, sans rien à configurer ; elle vous aide pendant le show de quiz, par exemple pour voir quelle réponse manque encore. Pendant un mini-jeu, vous pouvez aussi voir ici quel choix les joueurs ont fait pendant le jeu (ou quels joueurs n’ont pas encore fait de choix).
