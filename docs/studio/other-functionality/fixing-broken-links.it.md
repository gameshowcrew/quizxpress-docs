# Correggere i collegamenti interrotti

Quando si collegano contenuti audio e video, il quiz contiene solo il percorso del file esterno. Se si sposta il file esterno, QuizXpress non sarà più in grado di individuarlo, con conseguente collegamento interrotto. Dopo il caricamento di un quiz, Studio esegue un'attività in background per verificare che tutti i file multimediali a cui si fa riferimento siano ancora presenti. Quando rileva almeno un collegamento interrotto, presenta un modulo che elenca tutti i collegamenti mancanti:

![](../../assets/images/image304.webp){ width="568" loading=lazy }

In questo modulo è possibile risolvere rapidamente il problema (i file collegati devono naturalmente essere ancora disponibili da qualche parte sul computer). Se tutti i file sono ancora disponibili in una cartella principale, è possibile lasciare che il sistema li cerchi utilizzando il pulsante Locate. Se i file sono sparsi sul disco, sarà necessario individuarli manualmente, una voce alla volta. Dopo aver corretto tutti i percorsi, fare clic su Apply per applicare le modifiche alle diapositive.
