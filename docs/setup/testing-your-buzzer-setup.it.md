# Verificare la configurazione dei buzzer

È possibile utilizzare l'applicazione Buzzer Test, presente nel menu Start di Windows sotto QuizXpress, per verificare che i buzzer siano collegati e configurati correttamente. Questa applicazione mostra una griglia di indicatori; quando viene ricevuto un evento da un buzzer, mostra le informazioni sul pulsante premuto. Questa applicazione è utile anche per verificare la portata dei buzzer in una sala grande.

![](../assets/images/image347.webp){ loading=lazy }

Per uscire dall'applicazione Buzzer Test, premere il tasto *Escape* oppure utilizzare la combinazione di tasti standard di Windows *Alt+F4*. Buzzer Test è disponibile anche nel menu *Tools* di QuizXpress Studio. All'avvio di Buzzer Test, lo sfondo è grigio scuro durante la connessione all'hardware dei buzzer; quando la connessione riesce, lo sfondo diventa bianco e, in caso di problemi con l'hardware, lo sfondo diventa rosso.

È inoltre possibile usare Buzzer Test per controllare il livello della batteria dei buzzer.

![](../assets/images/image348.webp){ width="315" loading=lazy }

Nel modulo delle opzioni, premere il pulsante **Check battery level**, quindi accendere ogni buzzer premendo il grande pulsante a cupola. Il livello della batteria verrà mostrato nella griglia dei buzzer.
