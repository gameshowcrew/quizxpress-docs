# Configurare il game show con QuizXpress Setup

Il capitolo precedente descriveva come progettare un quiz in QuizXpress Studio. Il passo successivo è ‘eseguire’ il quiz in QuizXpress Live. Prima di farlo, tuttavia, potrebbe essere necessario modificare alcuni aspetti del game show — ad esempio, il tipo di hardware utilizzato, i nomi delle squadre, i suoni dei buzzer, le didascalie della schermata di benvenuto, le immagini della presentazione, ecc.

Il programma Quiz Setup si trova nel menu Start di Windows o nel menu External Tools di Studio (barra multifunzione Home).

Quiz Setup consente di gestire più file di impostazioni. Nell'elenco a sinistra dell'interfaccia utente sono visibili i file di configurazione disponibili. Quello in **grassetto** è il file attivo, ovvero le sue impostazioni verranno utilizzate durante l'esecuzione di un quiz in produzione. È possibile cambiare il file attivo facendo clic con il pulsante destro del mouse su di esso e selezionando ‘Activate’ dal menu contestuale. Per caricare un file in modifica, fare doppio clic su di esso oppure selezionare ‘Load’ dal menu contestuale.

Facendo clic su ‘Reset’, il sistema ripristina la configurazione predefinita. Si noti che sarà sempre necessario selezionare un sistema di buzzer prima di poter utilizzare qualsiasi funzionalità.

Facendo clic sul pulsante Save, il file di impostazioni corrente viene salvato su disco.

Facendo clic sul pulsante **Save As…**, il file di impostazioni corrente può essere salvato con un nome diverso.

I pulsanti Import ed Export consentono di esportare (salvare) le impostazioni attualmente caricate in un file. Questo file può poi essere importato in QuizXpress Setup su un altro computer, permettendo un trasferimento semplice e sicuro delle impostazioni. Si noti che le cartelle a cui il file di impostazioni fa riferimento devono essere presenti sul computer che importa le impostazioni (altrimenti verranno mostrati degli avvisi all'avvio di un game show con le impostazioni importate).
