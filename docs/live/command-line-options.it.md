# Opzioni della riga di comando

Le seguenti opzioni della riga di comando sono disponibili all’avvio di QuizXpress Live:

| Riga di comando                  | Spiegazione                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| \-*nosnapshot*                   | Per consentire il ripristino, QuizXpress Live tiene traccia di tutti i tipi di dati generati durante un quiz (scelte delle squadre, punteggi, domanda corrente, ecc.). Questo insieme di dati è chiamato ‘snapshot’. Se un quiz viene interrotto per un motivo imprevisto, al riavvio QuizXpress Live legge tutti i dati dallo snapshot di quel quiz, in modo che il quiz possa proseguire dal punto in cui era stato interrotto. L’opzione –nosnapshot non scrive alcun file snapshot. |
| \-*quickstart*                   | Salta le schermate di benvenuto e del conto alla rovescia                                                                                                                                                                                                                                                                                                                                                                                                                   |
| *-windowed*                      | Avvia l’applicazione in una finestra normale, in modo da poter continuare a usare altre applicazioni                                                                                                                                                                                                                                                                                                                                                                        |
| *-noborder*                      | Da usare in combinazione con –windowed; funziona in modalità finestra ma senza barra del titolo/bordo, quindi appare come la modalità schermo intero esclusiva pur essendo in realtà una normale modalità finestra. È possibile attivare questa modalità anche premendo il tasto M durante lo show.                                                                                                                                                                       |
| \-*showfps*                      | Mostra il numero di fotogrammi al secondo (per misurare le prestazioni)                                                                                                                                                                                                                                                                                                                                                                                                     |
| \-*singleuser*                   | Avvia QuizXpress Live in modalità utente singolo; questa opzione viene usata quando lo show viene avviato da QuizXpress Solo                                                                                                                                                                                                                                                                                                                                                |
| \-*scorefile=\<file>*           | Nome del file dei punteggi, che memorizza tutti i dati rilevanti del quiz (scelte per squadra, punteggi per squadra, informazioni sui tempi, ecc.)                                                                                                                                                                                                                                                                                                                          |
| *-startwith=\<0..n>*            | Avvia il quiz dalla domanda indicata, ad es. –startwith=5 per partire dalla quinta domanda                                                                                                                                                                                                                                                                                                                                                                                  |
| *-autorun*                       | Simula un pubblico                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| *-autoexit*                      | Chiude automaticamente l’applicazione dopo la schermata dei punteggi (da usare in combinazione con *–autorun*)                                                                                                                                                                                                                                                                                                                                                              |
| *-screen=\<devicename>*         | Avvia l’applicazione sul dispositivo di output indicato                                                                                                                                                                                                                                                                                                                                                                                                                     |
| *-settingsfile=\<settingsfile>* | Carica le impostazioni dal file di impostazioni indicato. Consente di passare facilmente da una configurazione all’altra (ad esempio composizioni diverse delle squadre)                                                                                                                                                                                                                                                                                                    |
| *-preload*                       | Opzione (avanzata) per precaricare/pre-renderizzare tutte le diapositive all’avvio. Necessaria solo se si riscontrano rallentamenti durante il quiz e il PC dispone di memoria sufficiente                                                                                                                                                                                                                                                                                   |

Ad esempio, per avviare QuizXpress Live in modalità finestra a schermo intero, è possibile usare il comando seguente (da avviare da un file batch o da una finestra di comando):

“Quiz Show.exe” –windowed –noborder c:\myquizzes\quiz1.qx
