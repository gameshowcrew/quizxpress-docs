# Pulsadores Fleetwood Reply

Proceda de la siguiente manera para instalar los pulsadores Fleetwood Reply y configurar QuizXpress para que funcione con ellos.

1.  Encienda el PC/portátil

2.  Inserte el CD de controladores de Reply en la unidad de CD/DVD-ROM

3.  Conecte el receptor USB de Reply a un puerto USB

4.  Aparecerá una ventana indicando que se ha encontrado hardware nuevo. Indique que Windows debe buscar los controladores automáticamente.

5.  Windows instalará los controladores automáticamente.

6.  Ahora podemos configurar QuizXpress para que utilice los pulsadores Reply. Inicie Quiz Setup (consulte también [Sistemas de pulsadores de opción múltiple](../setup/configuring-your-hardware-the-buzzers-tab-page.md#sistemas-de-pulsadores-de-opcion-multiple)).

7.  En la pestaña ‘Buzzers’ de Quiz Setup, seleccione Fleetwood Reply CRS 940/941.

8.  Ahora elija el canal que utiliza el receptor Reply para escuchar los mandos (pulsadores) Reply. Para seleccionar el canal correcto, mire la parte posterior de uno de los mandos que se van a utilizar: allí se indica el canal en el que funciona (nota: todos los pulsadores utilizados deben funcionar en este canal).

9.  Ahora cierre Quiz Setup e inicie QuizXpress Buzzer Test, que se encuentra en el menú Inicio, en QuizXpress. Al pulsar uno de los pulsadores, debería iluminarse la casilla numerada correspondiente en la pantalla y mostrarse la respuesta elegida.

10. Cuando los pasos anteriores se hayan realizado correctamente, QuizXpress Live está listo para funcionar con pulsadores Reply.

!!! note

    Los pulsadores Fleetwood Reply funcionan con pilas de litio de tipo CR2032. Se recomiendan las pilas de litio Sony CR2032.
