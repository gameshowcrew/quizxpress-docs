# La vue Analyzer

QuizXpress Director affiche l’historique complet de toutes les questions jouées jusqu’à présent. Pour chaque question, vous pouvez voir, pour chaque joueur, la réponse donnée, si elle était correcte ou incorrecte, et combien de points ont été gagnés ou perdus — un outil très pratique pour que l’animateur de quiz prouve qu’il a toujours raison !
