# El módulo Message Broker

Message Broker es un complemento opcional de QuizXpress que conecta su quiz con dispositivos y aplicaciones externos. Los eventos de QuizXpress pueden activar mensajes MIDI, por ejemplo para cambiar la iluminación DMX cuando una respuesta es correcta. Los programas externos también pueden controlar el quiz o escuchar sus eventos mediante UDP, TCP o Telnet.

![Cómo Message Broker conecta QuizXpress con dispositivos externos](../assets/images/mb-overview-diagram.webp){ loading=lazy }

Message Broker se configura desde QuizXpress Director mientras se ejecuta un quiz: pulse 'D' y abra la pestaña 'Extensions'.

Para consultar la documentación completa, vea [Message Broker](../advanced/message-broker/index.md) en la sección Advanced.

!!! note
    Message Broker es un complemento con licencia de QuizXpress y requiere una compra única.
