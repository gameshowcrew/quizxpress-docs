# La vue Questions

L’onglet « Questions » offre un aperçu de toutes les questions du quiz chargé. Vous pouvez voir les miniatures de toutes les diapositives et, si vous sélectionnez une question, la question, les réponses et la documentation s’affichent dans le volet de droite (notez qu’il ne s’agit pas d’une représentation graphique complète).

![](../../assets/images/image442.webp){ width="582" loading=lazy }

La barre d’outils permet d’effectuer les actions suivantes :

- **Go to question : accéder à une question précise (possible uniquement lorsqu’aucune question n’est en cours de compte à rebours). Pour cela, cliquez sur une autre question dans la liste, puis sur « Go to question ».**

- **Go to end : accéder à la fin du quiz (possible uniquement lorsqu’aucune question n’est en cours de compte à rebours). Un clic sur ce bouton affiche l’aperçu des scores finaux.**

- **Edit question : modification immédiate de la question sélectionnée (corriger l’orthographe, changer la bonne réponse, etc.)**

- **Edit timing** : ajuster le chronométrage de vos questions (durée du compte à rebours)

- **Layout Horizontal/Vertical : basculer entre une disposition horizontale et verticale**

La liste des questions indique visuellement les questions déjà visitées (en vert) ainsi que la question en cours (en jaune).

Lorsque la diapositive sélectionnée est une diapositive de mini-jeu, vous pouvez double-cliquer sur cette entrée pour modifier « à la volée » la configuration enregistrée. Un exemple d’utilisation : un quiz comportant plusieurs mini-jeux Wheel of Fortune servant à distribuer une série de lots aux gagnants des manches : une fois un lot attribué, vous pouvez vouloir le retirer de la Wheel of Fortune suivante si vous n’avez qu’un exemplaire de ce lot.
