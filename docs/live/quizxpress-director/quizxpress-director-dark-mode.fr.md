# Mode sombre de QuizXpress Director

Pour réduire la fatigue visuelle lorsque vous utilisez QuizXpress dans un lieu souvent sombre, Director peut être réglé en mode sombre. Pour cela, faites un clic droit sur le panneau de gauche de Director et sélectionnez « Dark mode » :

![](../../assets/images/image467.webp){ loading=lazy }

!!! note

    vous devrez rouvrir Director pour que ce paramètre prenne effet.
