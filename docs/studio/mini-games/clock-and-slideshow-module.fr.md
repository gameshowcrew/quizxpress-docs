# Clock and slideshow module

Ce module peut afficher une horloge numérique (ou un compte à rebours), un diaporama d'images avec de superbes effets de transition, ou un mélange des deux.

Options de configuration :

Sur la première page, vous pouvez configurer l'affichage de l'horloge, du diaporama ou des deux (auquel cas l'horloge s'affiche à intervalle configurable pendant une durée déterminée)

Pour l'horloge, vous pouvez configurer les options suivantes :

- Announcement : texte affiché à l'écran au-dessus de l'horloge

- Mode – Clock : l'heure est affichée à l'écran

- Mode – Timer : un minuteur décompte à partir de la durée indiquée jusqu'à 00:00:00

- Background Image : image affichée en arrière-plan

- Timer expires sound : son joué à l'expiration du minuteur

- Clock ticking sound : son joué pendant que l'horloge tourne, ou

- A playlist folder : le dossier dans lequel le module joue au hasard des fichiers MP3 pendant que l'horloge tourne. (Notez que lorsque vous utilisez l'horloge *intégrée au* quiz, ce dossier doit également exister sur le PC sur lequel vous exécutez votre quiz.)

Sur la dernière page, vous pouvez configurer le diaporama en sélectionnant un dossier dans lequel les images sont puisées, ainsi que les informations de durée.
