# Course de chevaux virtuelle

Dans le jeu de course de chevaux, chaque joueur parie sur un cheval à l'aide de son appareil portable, puis une course se déroule avec un résultat aléatoire. Des points sont ajoutés en fonction du résultat de la course.

Le module Virtual Horserace propose les options de configuration suivantes :

- Background image : sélectionnez l'image d'arrière-plan affichée sur l'écran où les joueurs choisissent le cheval gagnant

- Header : texte affiché sur l'écran où les joueurs choisissent le cheval gagnant. Number of horses : choisissez le nombre de chevaux qui participent à la course

- Track : choisissez différentes longueurs de piste qui durent environ 30, 50 ou 90 secondes

- Points to win : points qui peuvent être gagnés pour les différents classements

- Distant finish – close finish : choisissez ici si les chevaux doivent terminer groupés ou espacés

- Show mini map during the race with horse positions : affiche un petit aperçu dans le coin supérieur droit pendant une course de chevaux, indiquant les positions des chevaux

- Horse names : vous pouvez saisir ici les noms des chevaux

- Onglet Billboards : quatre panneaux d'affichage se trouvent à côté de la piste de course. Vous pouvez choisir vos propres images à afficher sur ces panneaux

- Forced winner : vous pouvez indiquer quel cheval va gagner

Vous trouverez ci-dessous une image du jeu de course de chevaux en action.

Pour passer par les différentes étapes de la course de chevaux (les joueurs choisissent un cheval, rendez-vous au départ, lancement de la course), il suffit d'appuyer sur le bouton ‘Next’ dans le panneau de gauche.
