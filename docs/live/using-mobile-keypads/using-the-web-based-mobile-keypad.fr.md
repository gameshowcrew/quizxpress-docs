# Utiliser le keypad mobile web

Le keypad web peut être utilisé lorsque vous disposez d'une connexion internet et que vous ne souhaitez pas que vos joueurs téléchargent l'application Smart Buzzer. Les joueurs peuvent simplement rejoindre le quiz avec un navigateur web standard en suivant les étapes ci-dessous :

- Dans Quiz Setup, sur l'onglet mobile, vous avez indiqué le serveur utilisé. Par exemple [www.buzzerpad.com](http://www.buzzerpad.com)

- Le nom du serveur ainsi qu'un code PIN à 5 chiffres sont affichés à l'écran dans QuizXpress Live!

- Les joueurs se rendent manuellement sur [www.buzzerpad.com](http://www.buzzerpad.com) et saisissent le code PIN affiché ainsi que leur nom de joueur

- Vous pouvez aussi appuyer sur « Q » lorsqu'un quiz est lancé pour afficher à l'écran un QR code que les joueurs peuvent scanner. Le scan du code les conduit automatiquement au site buzzerpad et renseigne le code PIN à leur place ; ils n'ont plus qu'à saisir un nom de joueur unique.

En haut à droite du keypad s'affiche l'ID du keypad. Sous l'ID figure le code PIN du quiz. Actuellement, deux serveurs sont disponibles : un en Europe de l'Ouest (buzzerpad.eu) et un aux États-Unis, dans la région centrale (buzzerpad.com). Nous vous recommandons d'utiliser le serveur le plus proche de votre situation géographique/fuseau horaire, pour la rapidité et pour les fenêtres de maintenance des serveurs. Vous pouvez configurer le serveur à utiliser dans Quiz Setup, sur l'onglet Mobile.
