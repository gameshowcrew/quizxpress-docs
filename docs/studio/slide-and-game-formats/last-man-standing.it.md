# Last man standing

Con le domande ‘Ultimo Uomo’ tutti possono rispondere, ma i giocatori che danno una risposta errata vengono immediatamente esclusi dalle domande successive, fino a quando rimane un solo vincitore. Quando rimane un solo giocatore, il quiz passa alla prima diapositiva di fine round che incontra oppure alla fine del quiz. Le diapositive di tipo ‘Fine Round’ segnano la fine di un round Ultimo Uomo. Tutti i giocatori rientrano in gioco nella diapositiva successiva alla diapositiva ‘Fine Round’. Se non è presente alcuna diapositiva ‘Fine Round’, il quiz passa alla schermata finale dei punteggi quando rimane un solo giocatore.

!!! note

    Quando tutti i giocatori sbagliano una domanda Ultimo Uomo, tutti i giocatori restano in gioco.
