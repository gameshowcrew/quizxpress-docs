# Modo oscuro de QuizXpress Director

Para reducir la fatiga visual al utilizar QuizXpress en un local donde suele haber poca luz, Director puede configurarse en modo oscuro. Para ello, haga clic con el botón derecho en el panel izquierdo de Director y seleccione “Dark mode”:

![](../../assets/images/image467.webp){ loading=lazy }

!!! note

    deberá volver a abrir Director para que este ajuste surta efecto.
