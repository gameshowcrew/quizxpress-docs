# Running the show with QuizXpress Live

To run a show with QuizXpress, you can use physical devices like the QuizXpress keypads or buzzers, or use mobile phones to let players play through local Wi-Fi or the internet. If you're playing over the internet with players at remote locations, you can stream the quiz through a streaming service, such as YouTube or Zoom. You can read more about streaming quizzes in the QuizXpress Online Streaming guide, available on our website.

It is also possible to use a hybrid solution with keypads/buzzers as well as the QuizXpress Smart Buzzer app.
