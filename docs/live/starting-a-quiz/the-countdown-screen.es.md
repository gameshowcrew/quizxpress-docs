# La pantalla de cuenta atrás

Después de la pantalla de registro de mandos, se muestra un vídeo de cuenta atrás para crear algo de suspense. Si no desea ver este vídeo antes de que empiece el quiz, desmarque la opción ‘Show 3-2-1 Quiz countdown screen’ en la página ‘Screens’ de Quiz Setup. Puede finalizar la pantalla pulsando la barra espaciadora durante el vídeo.
